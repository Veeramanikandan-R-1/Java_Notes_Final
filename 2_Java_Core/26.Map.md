# Java Map — HashMap & TreeMap

A **Map stores data as key-value pairs**.

Think of it like a JavaScript object / `Map`:

```text
Key        Value
101   →    "John"
102   →    "Alice"
103   →    "Bob"
```

### Important Map rules

* Keys must be **unique**
* Values can be duplicated
* Each key maps to one value
* Map is **not** part of the `Collection` interface

---

# 1. HashMap

`HashMap` is the most commonly used Map.

```java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {

        Map<Integer, String> users = new HashMap<>();

        users.put(101, "John");
        users.put(102, "Alice");
        users.put(103, "Bob");

        System.out.println(users);

        System.out.println(users.get(102)); // Alice

        users.put(102, "David"); // replaces Alice

        System.out.println(users.get(102)); // David
    }
}
```

### Key point

If you add the **same key again**, the old value is replaced:

```java
users.put(101, "John");
users.put(101, "David");
```

Result:

```text
101 → David
```

### HashMap characteristics

```text
HashMap
 ├── Unique keys       ✅
 ├── Duplicate values  ✅
 ├── Maintains order   ❌
 ├── Fast lookup        ✅
 └── Allows one null key + multiple null values
```

Typical performance:

```text
put()     → O(1) average
get()     → O(1) average
remove()  → O(1) average
```

---

# 2. TreeMap

`TreeMap` stores entries in **sorted order of keys**.

```java
import java.util.Map;
import java.util.TreeMap;

public class Main {
    public static void main(String[] args) {

        Map<Integer, String> users = new TreeMap<>();

        users.put(103, "Bob");
        users.put(101, "John");
        users.put(102, "Alice");

        System.out.println(users);
    }
}
```

Output:

```text
{101=John, 102=Alice, 103=Bob}
```

Even though we inserted:

```text
103 → 101 → 102
```

TreeMap sorts by **key**:

```text
101 → 102 → 103
```

### TreeMap characteristics

```text
TreeMap
 ├── Unique keys       ✅
 ├── Sorted by key     ✅
 ├── Duplicate values  ✅
 ├── null key           ❌
 └── Operations        O(log n)
```

---

# HashMap vs TreeMap

| Feature     | HashMap             | TreeMap          |
| ----------- | ------------------- | ---------------- |
| Order       | No guaranteed order | Sorted by key    |
| `get()`     | O(1) average        | O(log n)         |
| `put()`     | O(1) average        | O(log n)         |
| Null key    | ✅                   | ❌                |
| Performance | Faster              | Slower           |
| Use when    | Fast lookup         | Need sorted keys |

### Simple rule to remember

```text
Need fast key → value lookup?
        ↓
    HashMap

Need keys automatically sorted?
        ↓
    TreeMap
```

### Common Spring Boot usage

You'll frequently see:

```java
Map<Long, User> users = new HashMap<>();
```

For example, quickly finding a user by ID:

```java
User user = users.get(101L);
```

**Most important for you:** Learn `HashMap` very well. It is one of the most frequently used Java Collections in real-world Spring Boot applications and interviews.
