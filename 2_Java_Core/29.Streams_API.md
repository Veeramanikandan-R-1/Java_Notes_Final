# Java Streams API — Map, Filter, Reduce

A **Stream** lets you process a collection of data in a clean, functional style.

Think of it like JavaScript array methods:

```text
JavaScript                  Java
------------------------------------------------
array.map()            →    stream().map()
array.filter()         →    stream().filter()
reduce()               →    stream().reduce()
```

---

## 1. `map()` — Transform each element

`map()` takes every element and **converts it into something else**.

### Example

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        List<String> names = List.of("John", "Alice", "Bob");

        List<Integer> lengths = names.stream()
                .map(name -> name.length())
                .toList();

        System.out.println(lengths);
    }
}
```

Output:

```text
[4, 5, 3]
```

Flow:

```text
John  → 4
Alice → 5
Bob   → 3
```

So:

```java
.map(name -> name.length())
```

means **transform String → Integer**.

---

# 2. `filter()` — Select elements

`filter()` keeps only elements that satisfy a condition.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        List<Integer> numbers = List.of(10, 15, 20, 25, 30);

        List<Integer> result = numbers.stream()
                .filter(n -> n > 20)
                .toList();

        System.out.println(result);
    }
}
```

Output:

```text
[25, 30]
```

Flow:

```text
10 ❌
15 ❌
20 ❌
25 ✅
30 ✅
```

---

# 3. `reduce()` — Combine into one result

`reduce()` combines multiple elements into **one value**.

For example, calculate the sum:

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        List<Integer> numbers = List.of(10, 20, 30, 40);

        int sum = numbers.stream()
                .reduce(0, (total, n) -> total + n);

        System.out.println(sum);
    }
}
```

Output:

```text
100
```

Flow:

```text
0 + 10 = 10
10 + 20 = 30
30 + 30 = 60
60 + 40 = 100
```

Here:

```java
.reduce(0, (total, n) -> total + n)
```

* `0` → initial value
* `total` → accumulated result
* `n` → current element

# Combining them ⭐

This is where Streams become powerful.

**Find the sum of squares of numbers greater than 10:**

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        List<Integer> numbers = List.of(5, 10, 15, 20);

        int result = numbers.stream()
                .filter(n -> n > 10)       // 15, 20
                .map(n -> n * n)           // 225, 400
                .reduce(0, Integer::sum);  // 625

        System.out.println(result);
    }
}
```

Flow:

```text
[5, 10, 15, 20]
       ↓ filter
[15, 20]
       ↓ map
[225, 400]
       ↓ reduce
625
```

### Remember

```text
filter → SELECT
map    → TRANSFORM
reduce → COMBINE
```

One important point: **Streams don't modify the original collection**. They create a processing pipeline and produce a result.

For Spring Boot, you'll commonly use Streams when processing lists of entities/DTOs—for example, filtering users, converting entities to DTOs, or calculating totals.

---

In Java, a Stream can be used only once because it is designed to process data through a single pipeline. After a terminal operation such as `forEach()`, the stream is consumed and cannot be reused.

### Why does your code throw an error?

```
Stream<Integer> stream = listObj.stream();

stream.forEach(a -> System.out.println(a)); // Works
stream.forEach(a -> System.out.println(a)); // IllegalStateException
```

- First `forEach()` — processes all elements and consumes the stream.
- Second `forEach()` — throws `IllegalStateException: stream has already been operated upon or closed`.

### How to use `forEach()` multiple times

Option 1: Create a new stream each time (recommended)

```
List<Integer> listObj = Arrays.asList(3, 5, 2, 1, 4, 6);

listObj.stream().forEach(a -> System.out.println(a));
listObj.stream().forEach(a -> System.out.println(a));
```

Option 2: Use a loop if you don't need Stream operations

```
for (Integer a : listObj) {
    System.out.println(a);
}

for (Integer a : listObj) {
    System.out.println(a);
}
```

### Interview point

- Intermediate operations: `filter()`, `map()`, `sorted()` — build the pipeline; they are generally lazy.
- Terminal operations: `forEach()`, `collect()`, `count()`, `reduce()` — execute the pipeline and consume the stream.
- A collection can create multiple streams, but a single stream instance cannot be reused.

## mapToInt

In Java Streams, `mapToInt()` converts elements into an `IntStream`, and `sum()` calculates their total.

### Example

```
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> list = Arrays.asList(3, 5, 2, 1, 4, 6);

        int sum = list.stream()
                      .mapToInt(Integer::intValue)
                      .sum();

        System.out.println("Sum: " + sum); // Sum: 21
    }
}
```

### How it works

1. `list.stream()` — creates a stream of `Integer` objects.
2. `mapToInt(Integer::intValue)` — converts them into primitive `int` values.
3. `sum()` — adds all values and returns an `int`.

Shorter alternative:

```
int sum = list.stream()
              .mapToInt(a -> a)
              .sum();
```

Interview point: `mapToInt()` returns an `IntStream`, which provides numeric operations such as `sum()`, `average()`, `min()`, and `max()`.

## Java `parallelStream()`

`parallelStream()` processes collection elements in parallel using multiple threads, which can improve performance for large datasets when the work can be safely parallelized.

### Example: `parallelStream()` with `sum()`

```
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> list = Arrays.asList(3, 5, 2, 1, 4, 6);

        int sum = list.parallelStream()
                       .mapToInt(Integer::intValue)
                       .sum();

        System.out.println("Sum: " + sum); // 21
    }
}
```

### `stream()` vs `parallelStream()`

| Feature       | `stream()`                                                   | `parallelStream()`                       |
| ------------- | ------------------------------------------------------------ | ---------------------------------------- |
| Processing    | Sequential by default                                        | Parallel                                 |
| Threads       | Typically one                                                | Multiple worker threads                  |
| Performance   | Good for small tasks                                         | Can help with large, CPU-intensive tasks |
| Order         | Encounter order is generally preserved by ordered operations | Processing order is not guaranteed       |
| Thread safety | Depends on operations                                        | Shared mutable state needs extra care    |

### Example: Observe thread names

```
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> list = Arrays.asList(1, 2, 3, 4, 5);

        list.parallelStream().forEach(n ->
            System.out.println(n + " - " + Thread.currentThread().getName())
        );
    }
}
```

Output may vary because multiple threads can process elements concurrently.

### Important points

- `parallelStream()` typically uses Java's ForkJoin common pool.
- Avoid modifying shared variables or collections inside parallel operations without proper synchronization.
- Parallel processing can be slower for small datasets because of thread coordination overhead.
- Use `forEachOrdered()` when you need to preserve encounter order in the output.
- use it only if data has no dependency, don't use it for sort

Interview tip: Use `parallelStream()` when the workload benefits from parallel execution, and measure performance rather than assuming it will always be faster.
