# Java Streams API — Map, Filter, Reduce

A **Stream** lets you process a collection of data in a clean, functional style.

Think of it like JavaScript array methods:

```text
JavaScript                  Java
------------------------------------------------
array.map()            →    stream().map()
array.filter()         →    stream().filter()
reduce()               →    stream().reduce()
```

---

## 1. `map()` — Transform each element

`map()` takes every element and **converts it into something else**.

### Example

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        List<String> names = List.of("John", "Alice", "Bob");

        List<Integer> lengths = names.stream()
                .map(name -> name.length())
                .toList();

        System.out.println(lengths);
    }
}
```

Output:

```text
[4, 5, 3]
```

Flow:

```text
John  → 4
Alice → 5
Bob   → 3
```

So:

```java
.map(name -> name.length())
```

means **transform String → Integer**.

---

# 2. `filter()` — Select elements

`filter()` keeps only elements that satisfy a condition.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        List<Integer> numbers = List.of(10, 15, 20, 25, 30);

        List<Integer> result = numbers.stream()
                .filter(n -> n > 20)
                .toList();

        System.out.println(result);
    }
}
```

Output:

```text
[25, 30]
```

Flow:

```text
10 ❌
15 ❌
20 ❌
25 ✅
30 ✅
```

---

# 3. `reduce()` — Combine into one result

`reduce()` combines multiple elements into **one value**.

For example, calculate the sum:

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        List<Integer> numbers = List.of(10, 20, 30, 40);

        int sum = numbers.stream()
                .reduce(0, (total, n) -> total + n);

        System.out.println(sum);
    }
}
```

Output:

```text
100
```

Flow:

```text
0 + 10 = 10
10 + 20 = 30
30 + 30 = 60
60 + 40 = 100
```

Here:

```java
.reduce(0, (total, n) -> total + n)
```

* `0` → initial value
* `total` → accumulated result
* `n` → current element

---

# Combining them ⭐

This is where Streams become powerful.

**Find the sum of squares of numbers greater than 10:**

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        List<Integer> numbers = List.of(5, 10, 15, 20);

        int result = numbers.stream()
                .filter(n -> n > 10)       // 15, 20
                .map(n -> n * n)           // 225, 400
                .reduce(0, Integer::sum);  // 625

        System.out.println(result);
    }
}
```

Flow:

```text
[5, 10, 15, 20]
       ↓ filter
[15, 20]
       ↓ map
[225, 400]
       ↓ reduce
625
```

### Remember

```text
filter → SELECT
map    → TRANSFORM
reduce → COMBINE
```

One important point: **Streams don't modify the original collection**. They create a processing pipeline and produce a result.

For Spring Boot, you'll commonly use Streams when processing lists of entities/DTOs—for example, filtering users, converting entities to DTOs, or calculating totals.
