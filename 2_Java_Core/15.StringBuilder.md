## StringBuilder — Mutable Strings

`StringBuilder` is a Java class used to create and modify strings **without creating a new String object for every modification**.

```java
StringBuilder sb = new StringBuilder("Java");
```

### 1. Why do we need `StringBuilder`?

`String` is **immutable**:

```java
String str = "Java";

str = str + " Spring";
str = str + " Boot";
```

Each modification creates a **new String object**.

`StringBuilder` is **mutable**:

```java
StringBuilder sb = new StringBuilder("Java");

sb.append(" Spring");
sb.append(" Boot");

System.out.println(sb);
// Java Spring Boot
```

The same `StringBuilder` object is modified.

---

## 2. Common APIs

### `append()`

Adds content at the end.

```java
StringBuilder sb = new StringBuilder("Java");

sb.append(" Spring");
sb.append(" Boot");

System.out.println(sb);
// Java Spring Boot
```

You can append almost any type:

```java
sb.append(10);
sb.append(true);
```

---

### `insert()`

Inserts content at a specific index.

```java
StringBuilder sb = new StringBuilder("Java");

sb.insert(4, " Spring");

System.out.println(sb);
// Java Spring
```

---

### `delete()`

Deletes characters from `start` to `end - 1`.

```java
StringBuilder sb = new StringBuilder("Java Spring");

sb.delete(4, 11);

System.out.println(sb);
// Java
```

---

### `deleteCharAt()`

Removes one character.

```java
StringBuilder sb = new StringBuilder("Java");

sb.deleteCharAt(1);

System.out.println(sb);
// Jva
```

---

### `reverse()`

Reverses the characters.

```java
StringBuilder sb = new StringBuilder("Java");

sb.reverse();

System.out.println(sb);
// avaJ
```

Very commonly used in **DSA palindrome/reverse-string problems**.

---

### `setCharAt()`

Changes a character.

```java
StringBuilder sb = new StringBuilder("Java");

sb.setCharAt(0, 'K');

System.out.println(sb);
// Kava
```

---

### `length()`

```java
StringBuilder sb = new StringBuilder("Java");

System.out.println(sb.length());
// 4
```

---

### `toString()`

Converts `StringBuilder` → `String`.

```java
StringBuilder sb = new StringBuilder("Java");

String str = sb.toString();

System.out.println(str);
```

This is important when an API expects a `String`.

---

## String vs StringBuilder

| `String`                         | `StringBuilder`                 |
| -------------------------------- | ------------------------------- |
| Immutable                        | **Mutable**                     |
| Modification creates new objects | Modifies existing object        |
| Good for fixed text              | Good for frequent modifications |
| Thread-safe due to immutability  | Not synchronized                |
| `+` commonly used                | `append()` commonly used        |

### Example: Building a string in a loop

❌ Avoid repeatedly concatenating with `String`:

```java
String result = "";

for (int i = 0; i < 5; i++) {
    result += i;
}
```

✅ Prefer `StringBuilder`:

```java
StringBuilder result = new StringBuilder();

for (int i = 0; i < 5; i++) {
    result.append(i);
}

System.out.println(result);
// 01234
```

This is more efficient when there are **many modifications**.

### ⭐ Interview point

```text
String       → Immutable
StringBuilder → Mutable, not synchronized, generally preferred for single-threaded string manipulation
StringBuffer  → Mutable, synchronized/thread-safe, generally slower
```

For your **DSA + Spring Boot** learning, remember these `StringBuilder` methods first:

**`append()` → `insert()` → `delete()` → `deleteCharAt()` → `reverse()` → `setCharAt()` → `toString()`**.
