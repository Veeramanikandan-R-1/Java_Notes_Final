## Enums in Java

An `enum` is a special Java type used when a variable should have a **fixed set of predefined values**.

Think of it like a restricted set of constants.

For example, an order can only be:

```text
PENDING
SHIPPED
DELIVERED
CANCELLED
```

Instead of using strings:

```java
String status = "PENDING";
```

use:

```java
OrderStatus status = OrderStatus.PENDING;
```

This gives **type safety**.

---

# 1. Enum Basics

### Simple enum

```java
enum OrderStatus {
    PENDING,
    SHIPPED,
    DELIVERED,
    CANCELLED
}
```

Complete working example:

```java
enum OrderStatus {
    PENDING,
    SHIPPED,
    DELIVERED,
    CANCELLED
}

public class Main {
    public static void main(String[] args) {

        OrderStatus status = OrderStatus.PENDING;

        System.out.println(status);
    }
}
```

Output:

```text
PENDING
```

### Comparing enums

Use `==`:

```java
if (status == OrderStatus.PENDING) {
    System.out.println("Order is pending");
}
```

Enums are objects, so `==` is safe for comparing enum constants.

---

# 2. Enum Methods

Every enum automatically gets some useful methods.

### `values()`

Returns all enum constants.

```java
enum OrderStatus {
    PENDING,
    SHIPPED,
    DELIVERED
}

public class Main {
    public static void main(String[] args) {

        for (OrderStatus status : OrderStatus.values()) {
            System.out.println(status);
        }
    }
}
```

Output:

```text
PENDING
SHIPPED
DELIVERED
```

---

### `valueOf()`

Converts a String into the corresponding enum constant.

```java
OrderStatus status = OrderStatus.valueOf("SHIPPED");

System.out.println(status);
```

Output:

```text
SHIPPED
```

⚠️ It is case-sensitive:

```java
OrderStatus.valueOf("shipped"); // ❌ IllegalArgumentException
```

---

### `name()`

Returns the enum constant's name.

```java
OrderStatus status = OrderStatus.PENDING;

System.out.println(status.name());
```

Output:

```text
PENDING
```

---

### `ordinal()`

Returns the zero-based position.

```java
System.out.println(OrderStatus.PENDING.ordinal());   // 0
System.out.println(OrderStatus.SHIPPED.ordinal());   // 1
System.out.println(OrderStatus.DELIVERED.ordinal()); // 2
```

⚠️ **Don't use `ordinal()` as a database ID**, because changing enum order changes the ordinal.

# 3. Enum Constructors ⭐

Enums can have constructors.

The important point:

> **You cannot directly create an enum object using `new`.**

```java
OrderStatus status = new OrderStatus(); // ❌
```

Instead, Java creates the enum constants and calls the constructor internally.

### Example

```java
enum OrderStatus {

    PENDING("Order received"),
    SHIPPED("Order shipped"),
    DELIVERED("Order delivered");

    private String message;

    OrderStatus(String message) {
        this.message = message;
    }

    public String getMessage() {
        return message;
    }
}

public class Main {
    public static void main(String[] args) {

        OrderStatus status = OrderStatus.SHIPPED;

        System.out.println(status);
        System.out.println(status.getMessage());
    }
}
```

Output:

```text
SHIPPED
Order shipped
```

### What's happening?

When Java initializes:

```java
PENDING("Order received")
SHIPPED("Order shipped")
DELIVERED("Order delivered")
```

it effectively calls:

```text
OrderStatus("Order received")
OrderStatus("Order shipped")
OrderStatus("Order delivered")
```

The constructor is **implicitly private**.

You cannot write:

```java
public OrderStatus(...) // ❌
```

Enum constructors cannot be `public` or `protected`.

# 4. Enum with Methods ⭐

Enums can contain normal methods.

```java
enum OrderStatus {

    PENDING("Order is waiting"),
    SHIPPED("Order is on the way"),
    DELIVERED("Order delivered");

    private final String message;

    OrderStatus(String message) {
        this.message = message;
    }

    public String getMessage() {
        return message;
    }

    public boolean isCompleted() {
        return this == DELIVERED;
    }
}

public class Main {
    public static void main(String[] args) {

        OrderStatus status = OrderStatus.DELIVERED;

        System.out.println(status.getMessage());
        System.out.println(status.isCompleted());
    }
}
```

Output:

```text
Order delivered
true
```

Notice:

```java
this == DELIVERED
```

`this` represents the current enum constant.

---

# 5. Enum Can Have Static Methods

Just like normal classes:

```java
enum OrderStatus {
    PENDING,
    SHIPPED,
    DELIVERED;

    public static OrderStatus getDefaultStatus() {
        return PENDING;
    }
}

public class Main {
    public static void main(String[] args) {

        OrderStatus status = OrderStatus.getDefaultStatus();

        System.out.println(status);
    }
}
```

Output:

```text
PENDING
```

# 6. Enum in Spring Boot ⭐

You'll frequently see enums in DTOs/entities/services.

For example:

```java
public enum Role {
    ADMIN,
    USER,
    MANAGER
}
```

Then:

```java
public class User {
    private String name;
    private Role role;

    public User(String name, Role role) {
        this.name = name;
        this.role = role;
    }
}
```

Usage:

```java
User user = new User("John", Role.ADMIN);
```

This is much safer than:

```java
User user = new User("John", "admin");
```

because `"admni"` could accidentally be passed with a String, while:

```java
Role.ADMIN
```

must be a valid enum value.

## Quick Interview Summary

| Concept                | Meaning                                |
| ---------------------- | -------------------------------------- |
| `enum`                 | Fixed set of constants                 |
| `values()`             | Gets all enum constants                |
| `valueOf()`            | String → enum                          |
| `name()`               | Gets constant name                     |
| `ordinal()`            | Gets zero-based position               |
| Constructor            | Initializes data for each constant     |
| Methods                | Enums can have instance/static methods |
| `new`                  | ❌ Cannot create enum manually          |
| Constructor visibility | Implicitly `private`                   |

### Remember this pattern ⭐

```java
enum Status {

    ACTIVE("User is active"),
    INACTIVE("User is inactive");

    private final String message;

    Status(String message) {
        this.message = message;
    }

    public String getMessage() {
        return message;
    }
}
```

This **enum + constructor + field + getter + methods** pattern is very common in real Java/Spring Boot applications.
