## File Handling — NIO & Files API

Since you're moving from **React → Java/Spring Boot**, think of Java NIO as the modern API for working with files and directories.

### 1. What is NIO?

**NIO = New I/O**

Java provides two main approaches:

| Old I/O           | NIO                      |
| ----------------- | ------------------------ |
| `java.io.File`    | `java.nio.file.Path`     |
| `FileInputStream` | `Files` API              |
| More cumbersome   | Cleaner & modern         |
| Older API         | Preferred in modern Java |

For Spring Boot applications, you'll commonly use:

```java
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.Files;
```

---

# 2. `Path`

`Path` represents the **location of a file or directory**.

```java
Path path = Path.of("data/users.txt");

System.out.println(path);
```

You can also use:

```java
Path path = Paths.get("data/users.txt");
```

`Path.of()` is the newer/simple approach.

### Useful methods

```java
Path path = Path.of("data/users.txt");

System.out.println(path.getFileName()); // users.txt
System.out.println(path.getParent());   // data
System.out.println(path.toAbsolutePath());
```

---

# 3. `Files` API

`Files` is the main utility class for performing file operations.

```java
import java.nio.file.Files;
```

It provides methods for:

* Create
* Read
* Write
* Copy
* Move
* Delete
* Check existence
* Create directories

---

## 4. Create a File

```java
import java.nio.file.*;

public class Main {
    public static void main(String[] args) throws Exception {

        Path path = Path.of("data/test.txt");

        Files.createDirectories(path.getParent());
        Files.createFile(path);

        System.out.println("File created");
    }
}
```

`createDirectories()` creates the directory if it doesn't exist.

---

# 5. Write to a File

The easiest way:

```java
Path path = Path.of("data/test.txt");

Files.writeString(path, "Hello Java!");
```

If you read the file:

```java
String content = Files.readString(path);

System.out.println(content);
```

Output:

```text
Hello Java!
```

### Important

By default:

```java
Files.writeString(path, "Hello");
```

creates the file if necessary and **replaces existing content**.

To append:

```java
Files.writeString(
    path,
    "Hello\n",
    StandardOpenOption.CREATE,
    StandardOpenOption.APPEND
);
```

---

# 6. Read a File

### Read entire file as String

```java
String content = Files.readString(path);
```

### Read all lines

```java
List<String> lines = Files.readAllLines(path);

for (String line : lines) {
    System.out.println(line);
}
```

For example, if file contains:

```text
John
David
Mike
```

then:

```java
List<String> lines = Files.readAllLines(path);
```

gives:

```text
["John", "David", "Mike"]
```

---

# 7. Check File Exists

```java
if (Files.exists(path)) {
    System.out.println("File exists");
}
```

Also:

```java
Files.isRegularFile(path);
Files.isDirectory(path);
```

Example:

```java
if (Files.isDirectory(path)) {
    System.out.println("It's a directory");
}
```

---

# 8. Copy a File

```java
Path source = Path.of("data/test.txt");
Path destination = Path.of("data/backup.txt");

Files.copy(source, destination);
```

If destination already exists:

```java
Files.copy(
    source,
    destination,
    StandardCopyOption.REPLACE_EXISTING
);
```

---

# 9. Move / Rename

Move:

```java
Path source = Path.of("data/test.txt");
Path destination = Path.of("data/archive/test.txt");

Files.createDirectories(destination.getParent());

Files.move(source, destination);
```

Rename is essentially a move:

```java
Files.move(
    Path.of("data/old.txt"),
    Path.of("data/new.txt")
);
```

---

# 10. Delete

```java
Files.delete(path);
```

If the file doesn't exist, it throws an exception.

Safer:

```java
Files.deleteIfExists(path);
```

---

# 11. List Files in a Directory

```java
Path directory = Path.of("data");

try (var stream = Files.list(directory)) {
    stream.forEach(System.out::println);
}
```

This is important: `Files.list()` returns a **Stream**, so use try-with-resources.

---

# 12. Walk Directory Tree

Suppose:

```text
data/
 ├── users.txt
 ├── products.txt
 └── backup/
      └── old.txt
```

To recursively find everything:

```java
try (var stream = Files.walk(Path.of("data"))) {
    stream.forEach(System.out::println);
}
```

`Files.list()` → current directory only.

`Files.walk()` → recursively traverses subdirectories.

---

# 13. Complete Working Example

```java
import java.nio.file.*;
import java.util.List;

public class FileExample {

    public static void main(String[] args) throws Exception {

        Path directory = Path.of("data");
        Path file = directory.resolve("users.txt");

        // Create directory
        Files.createDirectories(directory);

        // Write
        Files.writeString(file, "John\nDavid\nMike");

        // Read
        String content = Files.readString(file);
        System.out.println("Content:");
        System.out.println(content);

        // Read lines
        List<String> lines = Files.readAllLines(file);
        System.out.println("\nUsers:");

        for (String line : lines) {
            System.out.println(line);
        }

        // Check existence
        System.out.println("\nExists: " + Files.exists(file));

        // Copy
        Path backup = directory.resolve("users-backup.txt");
        Files.copy(file, backup, StandardCopyOption.REPLACE_EXISTING);

        // Delete backup
        Files.deleteIfExists(backup);

        // List directory
        System.out.println("\nFiles:");

        try (var stream = Files.list(directory)) {
            stream.forEach(System.out::println);
        }
    }
}
```

---

# 14. Very Important: `resolve()`

You'll frequently see this in real Java/Spring Boot code:

```java
Path directory = Path.of("uploads");

Path file = directory.resolve("photo.jpg");
```

Result:

```text
uploads/photo.jpg
```

Instead of manually doing:

```java
Path file = Path.of("uploads/photo.jpg");
```

`resolve()` is safer and cleaner for constructing paths.

---

# 15. Exception Handling

Most `Files` operations throw:

```java
IOException
```

Example:

```java
try {
    String content = Files.readString(Path.of("data/test.txt"));
    System.out.println(content);
} catch (IOException e) {
    System.out.println("Failed to read file: " + e.getMessage());
}
```

In Spring Boot, you'll commonly handle this inside a service:

```java
@Service
public class FileService {

    public String readFile(String filename) throws IOException {
        Path path = Path.of("uploads", filename);
        return Files.readString(path);
    }
}
```

## 16. NIO Classes You Should Remember

For your Spring Boot journey, focus on these:

```text
java.nio.file
       │
       ├── Path       → represents file/directory path
       ├── Files      → operations on files
       ├── Paths      → creates Path
       └── StandardOpenOption
                         → CREATE, APPEND, etc.
```

### Most commonly used methods

```java
Files.exists()
Files.createFile()
Files.createDirectories()
Files.readString()
Files.readAllLines()
Files.writeString()
Files.copy()
Files.move()
Files.delete()
Files.deleteIfExists()
Files.list()
Files.walk()
```

### Interview-level takeaway

> **`Path` represents where the file is, while `Files` performs operations on that file.**

Think of it similar to:

```text
Path  → reference/location
Files → operations
```

For Spring Boot, **`Path` + `Files` is the modern approach you should prefer over the old `java.io.File` API**.

## File Handling using `java.io`

The main class is:

```java
import java.io.File;
```

### 1. Create / Check a File

```java
import java.io.File;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {

        File file = new File("test.txt");

        if (file.createNewFile()) {
            System.out.println("File created");
        } else {
            System.out.println("File already exists");
        }

        System.out.println(file.exists());
    }
}
```

---

### 2. Write to File — `FileWriter`

```java
import java.io.FileWriter;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {

        FileWriter writer = new FileWriter("test.txt");

        writer.write("Hello Java\n");
        writer.write("Hello Spring Boot");

        writer.close();
    }
}
```

### Append instead of overwrite

```java
FileWriter writer = new FileWriter("test.txt", true);

writer.write("\nNew line");

writer.close();
```

`true` → append mode.

---

### 3. Read File — `FileReader`

```java
import java.io.FileReader;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws IOException {

        FileReader reader = new FileReader("test.txt");

        int ch;

        while ((ch = reader.read()) != -1) {
            System.out.print((char) ch);
        }

        reader.close();
    }
}
```

`read()` returns `-1` when the end of file is reached.

---

## 4. Better Reading — `BufferedReader`

Instead of reading character by character:

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {

        BufferedReader reader =
                new BufferedReader(new FileReader("test.txt"));

        String line;

        while ((line = reader.readLine()) != null) {
            System.out.println(line);
        }

        reader.close();
    }
}
```

This is much more practical.

---

## 5. Try-with-resources

You don't need to manually call `close()`:

```java
try (BufferedReader reader =
         new BufferedReader(new FileReader("test.txt"))) {

    String line;

    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }

} catch (IOException e) {
    e.printStackTrace();
}
```

Java automatically closes the resource.

---

## 6. Copy File

Using `FileInputStream` + `FileOutputStream`:

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {

        try (
            FileInputStream input =
                    new FileInputStream("source.txt");

            FileOutputStream output =
                    new FileOutputStream("copy.txt")
        ) {

            byte[] buffer = new byte[1024];
            int bytesRead;

            while ((bytesRead = input.read(buffer)) != -1) {
                output.write(buffer, 0, bytesRead);
            }
        }
    }
}
```

## 8. Important `java.io` Classes

For interviews and Spring Boot basics, remember:

```text
java.io
   │
   ├── File              → file/directory information
   ├── FileReader        → read characters
   ├── FileWriter        → write characters
   ├── BufferedReader    → efficiently read text
   ├── BufferedWriter    → efficiently write text
   ├── FileInputStream   → read bytes
   └── FileOutputStream  → write bytes
```

### NIO vs traditional I/O

```text
Old Java I/O                  Modern Java NIO

File                          Path
FileReader                    Files
FileWriter                    Files
FileInputStream               Files
FileOutputStream              Files
```

**For modern Spring Boot development, you'll generally encounter `java.nio.file.Path` + `Files` more often.** But understanding `java.io` is important because you'll see `File`, streams, `MultipartFile`, and older code frequently.
