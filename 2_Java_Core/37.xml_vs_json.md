### XML vs JSON

Both XML and JSON are data formats used to store and exchange data between applications.

1\. XML Example

```
<student>
    <id>101</id>
    <name>Arun</name>
    <age>25</age>
</student>
```

2\. JSON Example

```
{
    "id": 101,
    "name": "Arun",
    "age": 25
}
```

### Key Differences

| Feature     | XML                              | JSON                                                  |
| ----------- | -------------------------------- | ----------------------------------------------------- |
| Full form   | Extensible Markup Language       | JavaScript Object Notation                            |
| Structure   | Tags                             | Key-value pairs                                       |
| Syntax      | More verbose                     | Lightweight                                           |
| Readability | Relatively complex               | Easy to read                                          |
| Data types  | Primarily text-based             | Supports string, number, boolean, array, object, null |
| Parsing     | XML Parser                       | JSON Parser                                           |
| Data size   | Generally larger                 | Generally smaller                                     |
| Usage       | Configuration, document exchange | REST APIs, web applications                           |

### In Java Spring Boot

- JSON: Commonly used for REST API request and response bodies.
- XML: Used in configuration and applications that require XML-based data exchange.

In short: JSON is lightweight and commonly preferred for modern REST APIs, whereas XML is useful when structured document formats and XML-specific features are required.
