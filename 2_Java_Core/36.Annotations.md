## Annotations in Java

Annotations provide metadata (extra information) about classes, methods, variables, and other program elements. They usually begin with `@`.

### Common annotations

| Annotation             | Purpose                                                                         |
| ---------------------- | ------------------------------------------------------------------------------- |
| `@Override`            | Indicates a method overrides a parent method.                                   |
| `@Deprecated`          | Marks an API as outdated or discouraged.                                        |
| `@SuppressWarnings`    | Suppresses specified compiler warnings.                                         |
| `@FunctionalInterface` | Ensures an interface has exactly one abstract method.                           |
| `@SafeVarargs`         | Suppresses certain heap-pollution warnings for varargs methods or constructors. |

### Example: `@Override`

```
class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Bark");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.sound();
    }
}
```

Output:

```
Bark
```

If you misspell `sound()` in `Dog`, the compiler reports an error because of `@Override`.

### Custom annotations

You can create your own annotation using `@interface`.

```
@interface MyAnnotation {
    String value();
}
```

Usage: `@MyAnnotation("Example")`

### Spring Boot example

- `@RestController` — Defines a REST controller.
- `@GetMapping` — Maps HTTP GET requests.
- `@Autowired` — Requests dependency injection.
- `@Service` — Marks a service-layer component.

Remember: Annotations provide metadata. Their effect depends on how the compiler, runtime, or framework processes them.
