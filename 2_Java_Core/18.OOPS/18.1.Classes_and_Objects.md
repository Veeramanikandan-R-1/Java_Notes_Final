## OOP: Classes and Objects

Think of **Class = blueprint** and **Object = actual thing created from that blueprint**.

Since you know React/JavaScript, you can roughly compare it to a **class definition + instances created from it**.

### 1. Class

A **class** defines the properties (data) and methods (behavior) that its objects will have.

```java
class Car {
    String brand;
    int speed;

    void drive() {
        System.out.println(brand + " is driving");
    }
}
```

Here:

* `Car` → class
* `brand`, `speed` → instance variables / fields
* `drive()` → instance method

The class itself is just the **definition/blueprint**.

---

### 2. Object

An **object** is an actual instance of a class.

We create an object using `new`:

```java
Car car1 = new Car();
```

Break it down:

```text
Car        car1        =       new Car();
↑           ↑                  ↑
type        reference          creates object
```

You can then assign values and call methods:

```java
car1.brand = "BMW";
car1.speed = 100;

car1.drive();
```

Output:

```text
BMW is driving
```

---

### 3. Multiple Objects

One class can create many independent objects.

```java
Car car1 = new Car();
car1.brand = "BMW";
car1.speed = 100;

Car car2 = new Car();
car2.brand = "Audi";
car2.speed = 120;
```

Conceptually:

```text
             Car class
          ┌──────────────┐
          │ brand        │
          │ speed        │
          │ drive()      │
          └──────────────┘
             /        \
            /          \
       car1 object    car2 object
       BMW, 100       Audi, 120
```

Changing `car1` doesn't change `car2`.

---

### 4. Complete Example

```java
class User {
    String name;
    int age;

    void introduce() {
        System.out.println("I am " + name + ", age " + age);
    }
}

public class Main {
    public static void main(String[] args) {

        User user1 = new User();
        user1.name = "John";
        user1.age = 25;

        User user2 = new User();
        user2.name = "David";
        user2.age = 30;

        user1.introduce();
        user2.introduce();
    }
}
```

Output:

```text
I am John, age 25
I am David, age 30
```

### 5. Important Java Concept: Reference

This is important:

```java
User user1 = new User();
```

`new User()` creates the **object in heap memory**.

`user1` is a **reference variable** that refers to that object.

```text
user1 ───────────► User object
                   name = null
                   age  = 0
```

So don't think `user1` itself is the object. It **holds a reference to the object**.

---

### Class vs Object

| Class                                 | Object                         |
| ------------------------------------- | ------------------------------ |
| Blueprint                             | Actual instance                |
| Logical definition                    | Runtime entity                 |
| Doesn't represent a specific user/car | Represents a specific user/car |
| `class User {}`                       | `new User()`                   |
| Defines fields & methods              | Contains actual field values   |

### Interview point ⭐

> **A class defines the structure and behavior; an object is a runtime instance of that class.**

For Spring Boot, this concept is fundamental because you'll constantly work with **classes, objects, DTOs, entities, services, controllers, and repositories**.
