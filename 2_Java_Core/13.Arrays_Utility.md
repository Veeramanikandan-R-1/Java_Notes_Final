## Arrays Utility — `Arrays` class

Java provides `java.util.Arrays` with static utility methods for working with arrays.

```java
import java.util.Arrays;
```

### 1. `Arrays.sort()`

Sorts an array in **ascending order**.

```java
int[] arr = {5, 2, 8, 1, 3};

Arrays.sort(arr);

System.out.println(Arrays.toString(arr));
// [1, 2, 3, 5, 8]
```

**Important:** `sort()` modifies the original array.

---

### 2. `Arrays.binarySearch()`

Searches for an element using **Binary Search**.

⚠️ **Array must be sorted first.**

```java
int[] arr = {1, 3, 5, 7, 9};

int index = Arrays.binarySearch(arr, 5);

System.out.println(index);
// 2
```

If element is not found:

```java
int index = Arrays.binarySearch(arr, 6);

System.out.println(index);
// -4
```

The negative result follows:

```text
-(insertion point) - 1
```

Here `6` would be inserted at index `3`:

```text
-(3) - 1 = -4
```

**Complexity:** `O(log n)`

---

### 3. `Arrays.fill()`

Fills **all elements** with the given value.

```java
int[] arr = new int[5];

Arrays.fill(arr, 10);

System.out.println(Arrays.toString(arr));
// [10, 10, 10, 10, 10]
```

You can also fill a specific range:

```java
int[] arr = {1, 2, 3, 4, 5};

Arrays.fill(arr, 1, 4, 100);

System.out.println(Arrays.toString(arr));
// [1, 100, 100, 100, 5]
```

Range is **start inclusive, end exclusive**.

---

### 4. `Arrays.copyOf()`

Creates a **new array** with the specified length.

```java
int[] arr = {1, 2, 3};

int[] copy = Arrays.copyOf(arr, 5);

System.out.println(Arrays.toString(copy));
// [1, 2, 3, 0, 0]
```

If the new size is smaller:

```java
int[] copy = Arrays.copyOf(arr, 2);

System.out.println(Arrays.toString(copy));
// [1, 2]
```

So:

```text
copyOf(original, newLength)
```

It creates a **new array**, so changing `copy` doesn't change the original array.

---

### 5. `Arrays.equals()`

Compares two arrays **element by element**.

```java
int[] a = {1, 2, 3};
int[] b = {1, 2, 3};

System.out.println(Arrays.equals(a, b));
// true
```

Different order:

```java
int[] a = {1, 2, 3};
int[] b = {3, 2, 1};

System.out.println(Arrays.equals(a, b));
// false
```

⚠️ Don't use `==` for comparing array contents:

```java
a == b                 // compares references
Arrays.equals(a, b)   // compares contents
```

---

## Quick Interview Cheat Sheet

| Method                  | Purpose             | Complexity   |
| ----------------------- | ------------------- | ------------ |
| `Arrays.sort()`         | Sort array          | `O(n log n)` |
| `Arrays.binarySearch()` | Search sorted array | `O(log n)`   |
| `Arrays.fill()`         | Fill elements       | `O(n)`       |
| `Arrays.copyOf()`       | Create resized copy | `O(n)`       |
| `Arrays.equals()`       | Compare contents    | `O(n)`       |

### One combined example

```java
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {

        int[] arr = {5, 2, 8, 1, 3};

        Arrays.sort(arr);
        System.out.println(Arrays.toString(arr));
        // [1, 2, 3, 5, 8]

        System.out.println(Arrays.binarySearch(arr, 5));
        // 3

        int[] copy = Arrays.copyOf(arr, 7);
        System.out.println(Arrays.toString(copy));
        // [1, 2, 3, 5, 8, 0, 0]

        Arrays.fill(copy, 5, 7, 10);
        System.out.println(Arrays.toString(copy));
        // [1, 2, 3, 5, 8, 10, 10]

        System.out.println(Arrays.equals(arr, copy));
        // false
    }
}
```

**Most important to remember:** `Arrays` methods are **static**, so you call them as `Arrays.method(...)`, not by creating an `Arrays` object.
