## Java Wrapper Classes

Java has **primitive types**:

```java
int
double
boolean
char
```

But many Java APIs/collections work with **objects**, not primitives.

Wrapper classes provide an **object representation of primitives**.

```text
Primitive       Wrapper
-------------------------
int       →    Integer
double    →    Double
boolean   →    Boolean
char      →    Character
```

---

## 1. Integer

Wrapper for `int`.

```java
int a = 10;

Integer b = 10;
```

`Integer` is an object, so it provides useful methods:

```java
Integer num = 100;

System.out.println(num.toString());  // "100"
System.out.println(Integer.parseInt("123")); // 123
```

A common use is collections:

```java
import java.util.List;
import java.util.ArrayList;

List<Integer> numbers = new ArrayList<>();

numbers.add(10);
numbers.add(20);
```

You **cannot** use:

```java
List<int> numbers; // ❌
```

---

## 2. Double

Wrapper for `double`.

```java
double price = 99.99;

Double value = 99.99;
```

Useful methods:

```java
Double.parseDouble("99.99"); // 99.99
```

---

## 3. Boolean

Wrapper for `boolean`.

```java
boolean active = true;

Boolean status = true;
```

Example:

```java
Boolean value = Boolean.parseBoolean("true");

System.out.println(value); // true
```

---

## 4. Character

Wrapper for `char`.

```java
char grade = 'A';

Character letter = 'A';
```

Useful methods:

```java
Character.isLetter('A'); // true
Character.isDigit('5');  // true
Character.toUpperCase('a'); // A
```

---

# 5. Autoboxing ⭐

**Primitive → Wrapper object automatically.**

```java
int num = 10;

Integer obj = num; // Autoboxing
```

Java automatically converts:

```text
int → Integer
```

Equivalent conceptually to:

```java
Integer obj = Integer.valueOf(num);
```

Another example:

```java
List<Integer> numbers = new ArrayList<>();

numbers.add(10); // int → Integer automatically
```

---

# 6. Unboxing ⭐

**Wrapper object → Primitive automatically.**

```java
Integer obj = 10;

int num = obj; // Unboxing
```

Conceptually:

```java
int num = obj.intValue();
```

Example:

```java
Integer a = 10;
Integer b = 20;

int result = a + b; // Unboxing happens automatically

System.out.println(result); // 30
```

Java effectively does:

```text
Integer → int → addition → int
```

---

## ⚠️ Important: `null`

Wrapper objects can be `null`, primitives cannot.

```java
Integer num = null;

int value = num; // ❌ NullPointerException
```

Because Java tries to **unbox** `null` into `int`.

---

## Quick Summary

| Primitive | Wrapper     | Example             |
| --------- | ----------- | ------------------- |
| `int`     | `Integer`   | `Integer n = 10`    |
| `double`  | `Double`    | `Double d = 10.5`   |
| `boolean` | `Boolean`   | `Boolean b = true`  |
| `char`    | `Character` | `Character c = 'A'` |

**Remember:**

```text
Autoboxing:  primitive → wrapper
             int → Integer

Unboxing:    wrapper → primitive
             Integer → int
```

### ⭐ Why this matters in Spring Boot

You'll frequently encounter wrapper types in **DTOs, entities, collections, and API request/response models**:

```java
public class User {
    private Integer age;
    private Boolean active;
}
```

Here `Integer`/`Boolean` can represent **`null`**, which is often useful when a field is optional or not supplied.
