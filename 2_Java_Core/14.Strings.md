## Strings — String APIs

In Java, `String` is a **class** (`java.lang.String`) used to represent text.

```java
String name = "Java";
```

### 1. `length()`

Returns number of characters.

```java
String str = "Hello";

System.out.println(str.length());
// 5
```

---

### 2. `charAt()`

Returns character at a given index.

```java
String str = "Java";

System.out.println(str.charAt(0)); // J
System.out.println(str.charAt(2)); // v
```

⚠️ Index starts from `0`.

---

### 3. `substring()`

Extracts part of a string.

```java
String str = "Hello World";

System.out.println(str.substring(6));
// World

System.out.println(str.substring(0, 5));
// Hello
```

`substring(start, end)` → **start inclusive, end exclusive**.

---

### 4. `equals()` / `equalsIgnoreCase()`

Compare **string contents**.

```java
String a = "Java";
String b = "java";

System.out.println(a.equals(b));
// false

System.out.println(a.equalsIgnoreCase(b));
// true
```

⚠️ Don't use `==` to compare String contents.

```java
a == b       // reference comparison
a.equals(b)  // content comparison
```

---

### 5. `contains()`

Checks whether a string contains another string.

```java
String str = "Spring Boot";

System.out.println(str.contains("Boot"));
// true
```

Returns `boolean`.

---

### 6. `startsWith()` / `endsWith()`

```java
String str = "SpringBoot";

System.out.println(str.startsWith("Spring"));
// true

System.out.println(str.endsWith("Boot"));
// true
```

Very useful for validation.

---

### 7. `indexOf()` / `lastIndexOf()`

Finds the position of a character/string.

```java
String str = "Java Programming";

System.out.println(str.indexOf("a"));
// 1

System.out.println(str.lastIndexOf("a"));
// 3
```

Returns `-1` if not found.

---

### 8. `toUpperCase()` / `toLowerCase()`

```java
String str = "Java";

System.out.println(str.toUpperCase());
// JAVA

System.out.println(str.toLowerCase());
// java
```

---

### 9. `trim()` / `strip()`

Removes whitespace from beginning and end.

```java
String str = "   Java   ";

System.out.println(str.trim());
// "Java"

System.out.println(str.strip());
// "Java"
```

**Java 11+:** prefer `strip()` because it handles Unicode whitespace better.

---

### 10. `replace()` / `replaceAll()`

`replace()` → literal replacement.

```java
String str = "Java is good";

System.out.println(str.replace("good", "great"));
// Java is great
```

`replaceAll()` → uses **regex**.

```java
String str = "Java123";

System.out.println(str.replaceAll("\\d", ""));
// Java
```

---

### 11. `split()`

Splits a string into an array.

```java
String str = "Java,Spring,React";

String[] arr = str.split(",");

System.out.println(arr[0]); // Java
System.out.println(arr[1]); // Spring
System.out.println(arr[2]); // React
```

Very commonly used when processing input.

---

### 12. `isEmpty()` / `isBlank()`

```java
String a = "";
String b = "   ";

System.out.println(a.isEmpty());
// true

System.out.println(b.isBlank());
// true
```

**Java 11+:** `isBlank()` considers whitespace-only strings blank.

---

### 13. `concat()`

Joins strings.

```java
String a = "Hello ";
String b = "Java";

System.out.println(a.concat(b));
// Hello Java
```

Usually `+` is simpler:

```java
String result = a + b;
```

---

### 14. `String.valueOf()`

Converts primitive values to String.

```java
int age = 25;

String str = String.valueOf(age);

System.out.println(str);
// "25"
```

Useful when converting different types to text.

---

### 15. `join()`

Joins multiple strings with a delimiter.

```java
String result = String.join(", ", "Java", "Spring", "React");

System.out.println(result);
// Java, Spring, React
```

---

## ⭐ Important: String is Immutable

Once a `String` object is created, its value **cannot be changed**.

```java
String str = "Java";

str.toUpperCase();

System.out.println(str);
// Java
```

Why? `toUpperCase()` creates a **new String**.

```java
str = str.toUpperCase();

System.out.println(str);
// JAVA
```

This is a very important Java interview concept.

# Java — String Constant Pool

## 1. What is the String Constant Pool?

The String Constant Pool (SCP) is a memory area in the Java heap where Java reuses string literals to avoid creating duplicate `String` objects.

Main purpose: Save memory by reusing existing strings.

## 2. How it works

```
String s1 = "Java";
String s2 = "Java";
String s3 = new String("Java");
```

- `s1`: References the pooled `"Java"` object.
- `s2`: References the same pooled object as `s1`.
- `s3`: References a separate `String` object created in the heap.

## 3. Example with output

```
public class Main {
    public static void main(String[] args) {
        String s1 = "Java";
        String s2 = "Java";
        String s3 = new String("Java");

        System.out.println(s1 == s2);
        System.out.println(s1 == s3);
        System.out.println(s1.equals(s3));
    }
}
```

Output:

```
true
false
true
```

Explanation:

- `s1 == s2` → `true`: Both reference the same object.
- `s1 == s3` → `false`: They reference different objects.
- `s1.equals(s3)` → `true`: Their string contents are equal.

## 4. Important points

1. Identical string literals are reused from the String Constant Pool.
2. `new String("Java")` creates a separate object.
3. Use `==` to compare object references.
4. Use `.equals()` to compare string contents.
5. `intern()` returns the canonical pooled reference for a string.

Example:

```
String s1 = new String("Java");
String s2 = s1.intern();

System.out.println(s2 == "Java"); // true
```

## 5. Interview answer

The String Constant Pool is a JVM mechanism that stores and reuses string literals to reduce memory consumption by avoiding duplicate objects.

### `toString()` in Java

- `toString()` is a method of the `Object` class.
- It returns a string representation of an object.
- By default, it returns a value containing the class name and hash code.
- We override it to display meaningful object data.

Example:

```
class Student {
    String name = "Ravi";
    int age = 25;

    @Override
    public String toString() {
        return "Name: " + name + ", Age: " + age;
    }
}

public class Main {
    public static void main(String[] args) {
        Student s = new Student();
        System.out.println(s);
    }
}
```

Output:

```
Name: Ravi, Age: 25
```

Remember:

- `System.out.println(s)` automatically calls `s.toString()`.
- Override `toString()` to print meaningful object information instead of the default representation.
