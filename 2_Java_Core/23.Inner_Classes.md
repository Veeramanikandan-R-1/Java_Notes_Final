Since you already know React, think of **Inner Classes** as Java classes defined **inside another class/method**. They are useful when a helper class is tightly coupled to the outer class.

## 1. Nested Class — Static Nested Class

A **static class inside another class**.

```java
class Outer {
    static class Nested {
        void print() {
            System.out.println("Inside Nested class");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        Outer.Nested obj = new Outer.Nested();
        obj.print();
    }
}
```

### Important

* `Nested` is `static`.
* It **doesn't need an object of `Outer`**.
* It can directly access only **static members** of `Outer`.

```java
class Outer {
    static int x = 10;

    static class Nested {
        void show() {
            System.out.println(x); // ✅
        }
    }
}
```

Think:

```text
Outer
 └── static Nested
```

# 2. Inner Class — Non-static Nested Class

Technically, a non-static nested class is called an **Inner Class**.

```java
class Outer {
    int x = 10;

    class Inner {
        void show() {
            System.out.println(x);
        }
    }
}

public class Main {
    public static void main(String[] args) {

        Outer outer = new Outer();

        Outer.Inner inner = outer.new Inner();

        inner.show();
    }
}
```

### Why `outer.new Inner()`?

Because an inner class is associated with an **instance of the outer class**.

```java
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
```

It can access **instance members** of the outer class:

```java
class Outer {
    private int x = 100;

    class Inner {
        void show() {
            System.out.println(x); // ✅
        }
    }
}
```

### Static Nested vs Inner

|                              | Static Nested        | Inner               |
| ---------------------------- | -------------------- | ------------------- |
| `static`                     | ✅                    | ❌                   |
| Needs Outer object           | ❌                    | ✅                   |
| Access outer instance fields | ❌ directly           | ✅                   |
| Creation                     | `new Outer.Nested()` | `outer.new Inner()` |

# 3. Local Class

A **class declared inside a method/block**.

```java
class Calculator {

    void calculate() {

        class Helper {
            int add(int a, int b) {
                return a + b;
            }
        }

        Helper helper = new Helper();

        System.out.println(helper.add(10, 20));
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        calculator.calculate();
    }
}
```

Output:

```text
30
```

### Key points

* Scope is limited to the method/block.
* Cannot be used outside that method.
* Useful for a **small helper implementation** used only inside one method.
* Can access local variables only if they are **final or effectively final**.

```java
void test() {
    int x = 10; // effectively final

    class Helper {
        void show() {
            System.out.println(x); // ✅
        }
    }
}
```

If you later do:

```java
x = 20;
```

then the local class cannot capture `x`.

# 4. Anonymous Class

An **anonymous class has no class name**.

It is commonly used when you need a **one-time implementation** of an interface or abstract class.

### Example with Interface

```java
interface Payment {
    void pay();
}

public class Main {
    public static void main(String[] args) {

        Payment payment = new Payment() {
            @Override
            public void pay() {
                System.out.println("Payment successful");
            }
        };

        payment.pay();
    }
}
```

Output:

```text
Payment successful
```

Here:

```java
new Payment() {
    @Override
    public void pay() {
        ...
    }
};
```

creates an **anonymous class implementing `Payment`**.

There is no class name such as:

```java
class CreditCardPayment implements Payment
```

because we need this implementation only once.

## Anonymous Class with Abstract Class

```java
abstract class Animal {
    abstract void sound();
}

public class Main {
    public static void main(String[] args) {

        Animal animal = new Animal() {
            @Override
            void sound() {
                System.out.println("Dog barks");
            }
        };

        animal.sound();
    }
}
```

# 5. Anonymous Class vs Lambda

Since you're learning Spring Boot, this distinction is useful.

For a **functional interface** (only one abstract method), you can usually replace an anonymous class with a lambda.

### Anonymous class

```java
Runnable task = new Runnable() {
    @Override
    public void run() {
        System.out.println("Running");
    }
};
```

### Lambda

```java
Runnable task = () -> {
    System.out.println("Running");
};
```

Lambda is generally cleaner.

But anonymous classes are still useful when you need:

* multiple method implementations
* additional fields/methods
* more complex one-off behavior
* extending an abstract class

# 6. All Types — Easy Mental Model

```text
Nested / Inner Classes
│
├── Static Nested Class
│      └── class inside class + static
│
├── Inner Class
│      └── non-static class inside class
│
├── Local Class
│      └── class inside method/block
│
└── Anonymous Class
       └── class without a name
```

### Most important for your Spring Boot journey

You will **frequently encounter anonymous classes**, especially older Java code and interfaces.

You'll also see **static nested classes** quite often.

**Local classes are relatively uncommon** in typical Spring Boot application code.

### Interview one-liner

> **A nested class is a class declared inside another class. A static nested class doesn't require an outer object, while a non-static inner class does. A local class is declared inside a method, and an anonymous class is a nameless one-time implementation of a class/interface.**
