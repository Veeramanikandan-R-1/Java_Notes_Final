# How to create a Spring Boot app in VS Code on Windows

Since you already have React.js experience and are learning Java Spring Boot, let's create a working Spring Boot project from scratch using VS Code.

## Step 1: Install the prerequisites

Make sure you have these installed on Windows.

| Software                   | Purpose                                                                |
| -------------------------- | ---------------------------------------------------------------------- |
| JDK 21                     | Run Java applications                                                  |

| Extension Pack for Java    | Java support                                                           |
| Spring Boot Extension Pack | Create and run Spring Boot apps                                        |
| Maven                      | Build and manage dependencies; the project can include a Maven Wrapper |

## Step 4: Understand the project structure

Your generated project should look similar to this:

demo/ ├── src/ │   ├── main/ │   │   ├── java/ │   │   │   └── com/springapp/demo/ │   │   │       └── DemoApplication.java │   │   └── resources/ │   │       └── application.properties │   └── test/ ├── mvnw ├── mvnw\.cmd └── pom.xml

- `DemoApplication.java` — application entry point.
- `application.properties` — application configuration.
- `pom.xml` — Maven dependencies and build configuration.
- `mvnw.cmd` — Windows Maven Wrapper, so you can build without installing Maven separately.

## Step 5: Create your first REST API

Inside `src/main/java/com/springapp/demo/`, create a file named `HelloController.java`.

```
package com.springapp.demo;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello! Spring Boot is working.";
    }
}
```

Keep the package name consistent with your generated project. If you change it, make sure the controller remains under the main application's package.

## Step 6: Run the application

Open the VS Code terminal in the project root — the folder containing `pom.xml` — and run:

```
.\mvnw.cmd spring-boot:run
```

Wait until the terminal shows that the application has started. The default port is `8080`.

Open this URL in your browser:

[http://localhost:8080/hello](http://localhost:8080/hello?utm_source=chatgpt.com)

Expected response:

```
Hello! Spring Boot is working.
```

To stop the application, press `Ctrl + C` in the terminal.

## Step 7: Common issues

| Problem                             | What to do                                                                        |
| ----------------------------------- | --------------------------------------------------------------------------------- |
| `release version 21 not supported`  | Check that Maven is using JDK 21: run `.\mvnw.cmd -v`.                            |
| Port 8080 already in use            | Stop the other application or set `server.port=8081` in `application.properties`. |
| `Spring Initializr` command missing | Install the Spring Boot Extension Pack.                                           |
| Dependencies are not downloading    | Check your internet connection and Maven output.                                  |
