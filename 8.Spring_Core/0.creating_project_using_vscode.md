# How to create a Spring Boot app in VS Code on Windows

Since you already have React.js experience and are learning Java Spring Boot, let's create a working Spring Boot project from scratch using VS Code.

## Step 1: Install the prerequisites

Make sure you have these installed on Windows.

| Software                   | Purpose                                                                |
| -------------------------- | ---------------------------------------------------------------------- |
| JDK 21                     | Run Java applications                                                  |
| VS Code                    | Code editor                                                            |
| Extension Pack for Java    | Java support                                                           |
| Spring Boot Extension Pack | Create and run Spring Boot apps                                        |
| Maven                      | Build and manage dependencies; the project can include a Maven Wrapper |

You previously had Java 11 and JDK 21 installed. Use JDK 21 for this setup.

# How to install Maven on Windows for Spring Boot

Since you're setting up Java and Spring Boot in VS Code, follow these steps to install Apache Maven 3.9.x on Windows.

## Step 1: Verify Java is installed

Open PowerShell or the VS Code terminal and run:

```
java -version
javac -version
```

Confirm that both commands work and show JDK 21.

## Step 2: Download Maven

1. Open the official Apache Maven website: [Download Apache Maven](https://maven.apache.org/download.cgi?utm_source=chatgpt.com).
2. Find the Binary zip archive under the Files section.
3. Download a file named similar to `apache-maven-3.9.x-bin.zip`.

Make sure you download the binary ZIP, not the source archive.

## Step 3: Extract the ZIP file

1. Right-click the downloaded ZIP file and select Extract All.
2. Move the extracted folder to:

```
C:\Program Files\Apache\maven
```

Your final folder structure should look like this:

C:\Program Files\Apache\maven\ ├── bin\ │   ├── mvn.cmd │   └── mvn ├── boot\ ├── conf\ └── lib\\

Ensure `mvn.cmd` exists inside the `bin` folder. If you downloaded Maven 3.9.16, the extracted folder may initially be named `apache-maven-3.9.16`; rename or move it to match the path above.

## Step 4: Configure environment variables

1. Search Windows for Edit the system environment variables.
2. Click Environment Variables.
3. Under System variables, click New.

Enter:

```
Variable name: MAVEN_HOME
Variable value: C:\Program Files\Apache\maven
```

4. Under System variables, select `Path` → Edit → New.
5. Add:

```
%MAVEN_HOME%\bin
```

6\. Click OK to save all changes.

Maven uses its `bin` directory in `PATH` to make the `mvn` command available from any terminal.&#x20;

## Step 5: Verify Maven installation

Close and reopen VS Code, then execute these commands in the terminal:

```
mvn -version
```

Expected output will look similar to:

```
Apache Maven 3.9.16
Maven home: C:\Program Files\Apache\maven
Java version: 21...
Java home: C:\Program Files\Java\jdk-21...
```

The exact version and paths may differ. Check that Maven uses the JDK you intend to use.

## Step 6: Build your Spring Boot project

Open the terminal in your Spring Boot project directory (where `pom.xml` exists).

```
mvn clean install
```

Or, if your project includes a Maven Wrapper, you can use:

```
.\mvnw.cmd clean install
```

Important: You don't need a separate Maven installation to build a project that includes a working Maven Wrapper.

If `mvn` is not recognized, check that the `Path` entry is correct and open a new terminal. For your Spring Boot setup, the next thing to verify is that `mvn -version` shows Java 21, not Java 11.

Apache Maven 3.9.16 supports JDK 21 and is a good choice for your Spring Boot development. The latest stable Maven release listed by Apache is 3.10.0.&#x20;

| Maven 3.10.0          | Yes                                              | Latest stable option   |
| Maven 3.8.x and older | Generally works, but older versions are outdated | Avoid for new projects |

Download: [Official Apache Maven downloads](https://maven.apache.org/download.cgi?utm_source=chatgpt.com)

After installation, run:

```
mvn -version
```

Confirm the output shows both your Maven version and `Java version: 21`.

Important: Maven's Java compatibility is different from your project's Java compilation version. To compile your Spring Boot application for Java 21, ensure your `pom.xml` sets the appropriate Java version, for example:

```
<properties>
    <java.version>21</java.version>
</properties>
```

For Spring Boot, use a compatible Spring Boot release and its managed Maven plugin/dependency versions.

## Step 4: Understand the project structure

Your generated project should look similar to this:

demo/ ├── src/ │   ├── main/ │   │   ├── java/ │   │   │   └── com/springapp/demo/ │   │   │       └── DemoApplication.java │   │   └── resources/ │   │       └── application.properties │   └── test/ ├── mvnw ├── mvnw\.cmd └── pom.xml

- `DemoApplication.java` — application entry point.
- `application.properties` — application configuration.
- `pom.xml` — Maven dependencies and build configuration.
- `mvnw.cmd` — Windows Maven Wrapper, so you can build without installing Maven separately.

## Step 5: Create your first REST API

Inside `src/main/java/com/springapp/demo/`, create a file named `HelloController.java`.

```
package com.springapp.demo;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello! Spring Boot is working.";
    }
}
```

Keep the package name consistent with your generated project. If you change it, make sure the controller remains under the main application's package.

## Step 6: Run the application

Open the VS Code terminal in the project root — the folder containing `pom.xml` — and run:

```
.\mvnw.cmd spring-boot:run
```

Wait until the terminal shows that the application has started. The default port is `8080`.

Open this URL in your browser:

[http://localhost:8080/hello](http://localhost:8080/hello?utm_source=chatgpt.com)

Expected response:

```
Hello! Spring Boot is working.
```

To stop the application, press `Ctrl + C` in the terminal.

## Step 7: Common issues

| Problem                             | What to do                                                                        |
| ----------------------------------- | --------------------------------------------------------------------------------- |
| `release version 21 not supported`  | Check that Maven is using JDK 21: run `.\mvnw.cmd -v`.                            |
| Port 8080 already in use            | Stop the other application or set `server.port=8081` in `application.properties`. |
| `Spring Initializr` command missing | Install the Spring Boot Extension Pack.                                           |
| Dependencies are not downloading    | Check your internet connection and Maven output.                                  |
