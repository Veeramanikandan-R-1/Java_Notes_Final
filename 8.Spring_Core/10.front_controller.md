### How Front Controller (DispatcherServlet) works in Spring Boot

`DispatcherServlet` acts as the central entry point for incoming HTTP requests.

Let's understand the flow step by step.

Example: Client requests `/students`.

### Request flow

1. Client sends request
   ```
   GET /students
   ```
2. DispatcherServlet receives request

   All incoming Spring MVC requests are handled by DispatcherServlet.
3. HandlerMapping identifies the controller

   Spring checks which controller method matches `/students`.
4. HandlerAdapter invokes the controller

   It executes the appropriate controller method.
5. Controller processes the request

   Controller calls the Service layer, which may call the Repository layer.
6. Response is generated
   - For `@RestController`: Response is serialized into JSON (or another configured format).
   - For `@Controller`: A view may be resolved and rendered.
7. DispatcherServlet sends the response

   The HTTP response is returned to the client.

### Example

```
@RestController
public class StudentController {

    @GetMapping("/students")
    public String getStudents() {
        return "Student List";
    }
}
```

When the client calls `/students`, the output is:

```
Student List
```

### Important Spring MVC components

| Component            | Responsibility                               |
| -------------------- | -------------------------------------------- |
| DispatcherServlet    | Receives requests                            |
| HandlerMapping       | Finds the matching controller                |
| HandlerAdapter       | Invokes controller methods                   |
| Controller           | Handles application requests                 |
| ViewResolver         | Resolves views (when applicable)             |
| HttpMessageConverter | Converts request/response bodies (e.g. JSON) |

Interview answer: DispatcherServlet is the Front Controller in Spring MVC. It receives incoming HTTP requests, delegates them to the appropriate controller through HandlerMapping and HandlerAdapter, and returns the generated response to the client.
