# Spring Core — Bean Scopes: Request & Session

These scopes are relevant to **web applications** because they depend on an HTTP request/session.

| Scope     | Lifetime         | New object when                |
| --------- | ---------------- | ------------------------------ |
| `request` | One HTTP request | Every new HTTP request         |
| `session` | One HTTP session | Every new user/browser session |

---

# 1. Request Scope

`@RequestScope` means:

> Spring creates **one bean instance for each HTTP request**.

```text
Request 1 → RequestBean #1
Request 2 → RequestBean #2
Request 3 → RequestBean #3
```

Even if the same user sends 3 requests, there are 3 different instances.

### Example

```java
package com.springapp.demo;

import org.springframework.stereotype.Component;
import org.springframework.web.context.annotation.RequestScope;

import java.util.UUID;

@Component
@RequestScope
public class RequestData {

    private final String id = UUID.randomUUID().toString();

    public String getId() {
        return id;
    }
}
```

Controller:

```java
package com.springapp.demo;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class UserController {

    private final RequestData requestData;

    public UserController(RequestData requestData) {
        this.requestData = requestData;
    }

    @GetMapping("/request")
    public String request() {
        return requestData.getId();
    }
}
```

Now call:

```text
GET /request
```

Response:

```text
abc-123
```

Call again:

```text
GET /request
```

Response:

```text
xyz-456
```

Different IDs → **different bean instances**.

### Real-world use

Request-specific data such as:

```text
Request ID
Temporary request data
Request-specific context
```

# 2. Session Scope

`@SessionScope` means:

> Spring creates **one bean instance for an HTTP session**.

Think of a user's login session.

```text
User A / Browser
       │
       ├── Request 1 ─┐
       ├── Request 2 ─┤
       ├── Request 3 ─┤
       │              ↓
       │       Same SessionBean
       │
       └── Session ends
```

### Example

```java
package com.springapp.demo;

import org.springframework.stereotype.Component;
import org.springframework.web.context.annotation.SessionScope;

@Component
@SessionScope
public class UserSession {

    private String username;

    public void setUsername(String username) {
        this.username = username;
    }

    public String getUsername() {
        return username;
    }
}
```

Controller:

```java
package com.springapp.demo;

import org.springframework.web.bind.annotation.*;

@RestController
public class UserController {

    private final UserSession userSession;

    public UserController(UserSession userSession) {
        this.userSession = userSession;
    }

    @GetMapping("/login/{name}")
    public String login(@PathVariable String name) {
        userSession.setUsername(name);
        return "Logged in as " + name;
    }

    @GetMapping("/user")
    public String user() {
        return userSession.getUsername();
    }
}
```

### Test

First:

```text
GET /login/John
```

Response:

```text
Logged in as John
```

Then:

```text
GET /user
```

Response:

```text
John
```

The second request can access the value because both requests belong to the **same HTTP session**.

# Request vs Session

The easiest way to remember:

```text
REQUEST
──────────────
Request 1 → Object A
Request 2 → Object B
Request 3 → Object C
```

```text
SESSION
──────────────
Request 1 ─┐
Request 2 ─┼→ Same Object A
Request 3 ─┘
```

### React analogy

Think of:

```text
Request Scope
≈ temporary data for one API call

Session Scope
≈ state maintained for a user's session
```

But remember: Spring's session scope is tied to the **server-side HTTP session**, not React state.

---

## Important Interview Point

`@RequestScope` and `@SessionScope` are specialized versions of:

```java
@Scope("request")
```

and:

```java
@Scope("session")
```

You will normally use the clearer annotations:

```java
@RequestScope
@SessionScope
```

### All four scopes you've learned

```text
Singleton
   → One instance per Spring container

Prototype
   → New instance every getBean()

Request
   → One instance per HTTP request

Session
   → One instance per HTTP session
```

**For Spring Boot REST applications, Singleton is by far the most common scope. Request and Session are used when you specifically need HTTP request/session-specific state.**
