### Create Spring Boot project in VS Code

1. Open **Extensions** → `Ctrl + Shift + X`
2. Search:
   **Spring Boot Extension Pack**
3. Install the one from **VMware**.

Then:

1. Press `Ctrl + Shift + P`
2. Search:
   **Spring Initializr: Create a Maven Project**
3. Select **Maven**
4. Select **Java**
5. Select the latest stable Spring Boot version offered by the wizard
6. Select **JDK 21**
7. Group:

   ```text
   com.example
   ```
8. Artifact:

   ```text
   spring-learning
   ```
9. Packaging:

   ```text
   Jar
   ```
10. Select dependencies:

* **Spring Web**
* You can add others later.

11. Choose a folder to create the project.
12. Open the generated project in VS Code.

You should get:

```text
spring-learning
├── pom.xml
└── src
    └── main
        ├── java
        │   └── com.example.springlearning
        │       └── SpringLearningApplication.java
        └── resources
            └── application.properties
```

### Run it

Open:

```text
SpringLearningApplication.java
```

You'll see **Run | Debug** above `main()`.

Click **Run**.

Or terminal:

```bash
mvn spring-boot:run
```

You should see something like:

```text
Tomcat started on port 8080
Started SpringLearningApplication
```

Then your Spring Boot application is running at:

```text
http://localhost:8080
```

**For your current learning:** once this is running, we can use this project to practice **ApplicationContext → Bean → Dependency Injection → Bean Lifecycle** instead of using a separate plain Java project.

---

running the project

For a **Spring Boot** app, there are 3 common ways to run it.

### 1. Using Maven — recommended

Open terminal in the folder containing `pom.xml`:

```bash
mvn spring-boot:run
```

If Maven Wrapper exists:

```bash
./mvnw spring-boot:run
```

On Windows:

```bash
mvnw.cmd spring-boot:run
```

---

### 2. Run the main class

Your Spring Boot application normally has:

```java
@SpringBootApplication
public class MyApplication {

    public static void main(String[] args) {
        SpringApplication.run(MyApplication.class, args);
    }
}
```

In VS Code/IntelliJ, click **Run ▶** next to `main()`.

---

### 3. Run the JAR

First build:

```bash
mvn clean package
```

Then:

```bash
java -jar target/my-app-0.0.1-SNAPSHOT.jar
```

### What happens when it starts?

```text
main()
   ↓
SpringApplication.run()
   ↓
Create ApplicationContext
   ↓
Find @Component / @Service / @Repository / @Controller
   ↓
Create & inject Beans
   ↓
Start embedded server (usually port 8080)
```

For your current **Spring Core learning**, I recommend running with:

```bash
mvn spring-boot:run
```

and then we can see **exactly when the ApplicationContext and Beans are created**.
