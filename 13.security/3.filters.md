### **Important Spring Security Filters – Short Notes**

1\. `SecurityContextHolderFilter` – Loads the SecurityContext for the current request.

2\. `CorsFilter` – Handles Cross-Origin Resource Sharing (CORS) requests.

3\. `CsrfFilter` – Validates CSRF tokens to prevent Cross-Site Request Forgery attacks.

4\. `UsernamePasswordAuthenticationFilter` – Handles username and password authentication through form login.

5\. `BasicAuthenticationFilter` – Handles HTTP Basic authentication using the Authorization header.

6\. `BearerTokenAuthenticationFilter` – Extracts and validates Bearer tokens, commonly JWTs.

7\. `LogoutFilter` – Handles user logout and clears authentication-related information.

8\. `AnonymousAuthenticationFilter` – Assigns anonymous authentication when no authenticated user exists.

9\. `ExceptionTranslationFilter` – Converts security exceptions into HTTP responses, such as 401 and 403.

10\. `AuthorizationFilter` – Checks whether the authenticated user has permission to access a requested resource.

**Remember:**

- Authentication: Who are you?
- Authorization: What are you allowed to access?
- `BasicAuthenticationFilter`: Basic authentication.
- `AuthorizationFilter`: Access permission checking.
