## Servlet Example – Static and Dynamic Pages

A Servlet can generate both static and dynamic HTML responses.

### 1. Static Page

A static page displays fixed content. The response doesn't change based on user input or request data.

Example:

```
import java.io.*;
import jakarta.servlet.*;
import jakarta.servlet.http.*;
import jakarta.servlet.annotation.WebServlet;

@WebServlet("/static")
public class StaticServlet extends HttpServlet {

    protected void doGet(HttpServletRequest req,
                         HttpServletResponse res)
                         throws IOException {

        res.setContentType("text/html");

        PrintWriter out = res.getWriter();

        out.println("<h1>Welcome to Java</h1>");
        out.println("<p>This is a static page</p>");
    }
}
```

URL:

```
http://localhost:8080/MyApp/static
```

### 2. Dynamic Page

A dynamic page generates content based on user input, request parameters or database data.

Example:

```
import java.io.*;
import jakarta.servlet.*;
import jakarta.servlet.http.*;
import jakarta.servlet.annotation.WebServlet;

@WebServlet("/dynamic")
public class DynamicServlet extends HttpServlet {

    protected void doGet(HttpServletRequest req,
                         HttpServletResponse res)
                         throws IOException {

        res.setContentType("text/html");

        String name = req.getParameter("name");

        PrintWriter out = res.getWriter();

        out.println("<h1>Welcome " + name + "</h1>");
    }
}
```

URL:

```
http://localhost:8080/MyApp/dynamic?name=Arun
```

Output:

```
Welcome Arun
```

### 3. Static vs Dynamic

| Static                                | Dynamic                                        |
| ------------------------------------- | ---------------------------------------------- |
| Fixed content                         | Content changes based on input/data            |
| Same response generally               | Response can differ per request                |
| No request-specific processing needed | Request data or business logic may be involved |
| Example: Welcome page                 | Example: User profile page                     |

Important points:

- `doGet()` handles HTTP GET requests.
- `HttpServletRequest` reads client request data.
- `HttpServletResponse` sends the response.
- `PrintWriter` writes HTML content.
- `setContentType()` specifies the response format.

Note: This example uses Jakarta Servlet (`jakarta.servlet`), suitable for modern Jakarta EE-based servlet containers such as Tomcat 10+. For Tomcat 9, use `javax.servlet` imports instead.
