## Fundamentals of Client-Server Architecture

Client-server architecture is a model where a client requests services or resources, and a server processes the request and sends a response.

### Key Components

1. Client: Sends requests (e.g., browser, Java application).
2. Server: Processes requests and provides responses.
3. Network: Enables communication between client and server.
4. Protocol: Defines communication rules (e.g., HTTP, TCP/IP).

### How It Works

1. Client sends a request.
2. Server receives and processes it.
3. Server interacts with the database if needed.
4. Server sends the response to the client.

### Types of Architecture

| Type   | Description                                            |
| ------ | ------------------------------------------------------ |
| 2-Tier | Client directly communicates with the database server. |
| 3-Tier | Client → Application Server → Database Server.         |
| N-Tier | Application is divided into multiple layers.           |

### JDBC Example

In a basic JDBC application:

- Client: Java application.
- Server: MySQL database server.
- Driver: MySQL JDBC Connector.
- Communication: Java application communicates with MySQL through JDBC.

Key takeaway: JDBC enables Java applications to communicate with database servers using the client-server architecture.
