## Servlet and JSP Introduction

### 1. Servlet

Servlet is a Java server-side technology used to handle client requests and generate dynamic responses.

- Runs inside a Servlet Container (e.g., Tomcat).
- Handles HTTP requests and responses.
- Used to implement server-side business logic.
- Commonly uses `HttpServlet`, `doGet()` and `doPost()`.

### 2. JSP (JavaServer Pages)

JSP is a server-side technology used to create dynamic web pages using HTML with Java-related features.

- Mainly used for presentation (UI).
- Allows dynamic content generation.
- JSP is internally translated into a Servlet by the container.
- Supports Expression Language (EL) and JSTL.

### 3. Servlet vs JSP

| Servlet                        | JSP                            |
| ------------------------------ | ------------------------------ |
| Java code-centric              | HTML-centric                   |
| Handles request processing     | Handles presentation           |
| Generates HTML using Java code | Embeds dynamic content in HTML |
| Written as `.java`             | Written as `.jsp`              |

### 4. How They Work Together

1. Client sends an HTTP request.
2. Servlet receives and processes the request.
3. Servlet calls business logic if required.
4. Servlet forwards data to JSP.
5. JSP generates dynamic HTML.
6. Server sends HTML response to the client.

### 5. Example

Consider a login application:

- Servlet validates username and password.
- JSP displays login success or failure.

Important: Servlets and JSP are traditional Java web technologies. In modern Spring Boot applications, Spring MVC controllers and template engines or frontend frameworks commonly handle these responsibilities.
