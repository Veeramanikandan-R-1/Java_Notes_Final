## DSA – Linked List: HashMap Applications

HashMap is not a Linked List itself. But **HashMap + Linked List** is a very important DSA combination.

The most important application is:

> **Copy/Clone a Linked List with Random Pointer**

---

## 1. Why do we need HashMap?

Consider a linked list where every node has:

```text
next   → next node
random → any random node
```

Example:

```text
A → B → C → null

A.random → C
B.random → A
C.random → B
```

If we simply create new nodes, we need to know:

> Original node `A` corresponds to which new node?

That's exactly what HashMap solves.

```text
Original Node → New Node
```

---

# 2. Clone Linked List with Random Pointer

### Node structure

```java
class Node {
    int data;
    Node next;
    Node random;

    Node(int data) {
        this.data = data;
    }
}
```

### Complete working example

```java
import java.util.HashMap;
import java.util.Map;

class Node {
    int data;
    Node next;
    Node random;

    Node(int data) {
        this.data = data;
    }
}

public class Main {

    public static Node cloneList(Node head) {

        if (head == null) {
            return null;
        }

        Map<Node, Node> map = new HashMap<>();

        // Step 1: Create clone nodes
        Node current = head;

        while (current != null) {
            map.put(current, new Node(current.data));
            current = current.next;
        }

        // Step 2: Connect next and random
        current = head;

        while (current != null) {

            Node clonedNode = map.get(current);

            clonedNode.next = map.get(current.next);
            clonedNode.random = map.get(current.random);

            current = current.next;
        }

        return map.get(head);
    }

    public static void printList(Node head) {

        Node current = head;

        while (current != null) {

            System.out.print(
                "Node: " + current.data +
                ", Random: " +
                (current.random != null
                    ? current.random.data
                    : "null")
            );

            System.out.println();

            current = current.next;
        }
    }

    public static void main(String[] args) {

        // Create original list
        Node first = new Node(1);
        Node second = new Node(2);
        Node third = new Node(3);

        first.next = second;
        second.next = third;

        first.random = third;
        second.random = first;
        third.random = second;

        System.out.println("Original:");
        printList(first);

        Node cloned = cloneList(first);

        System.out.println("\nCloned:");
        printList(cloned);
    }
}
```

Output:

```text
Original:
Node: 1, Random: 3
Node: 2, Random: 1
Node: 3, Random: 2

Cloned:
Node: 1, Random: 3
Node: 2, Random: 1
Node: 3, Random: 2
```

---

# 3. Understand the HashMap

After the first loop:

```java
map.put(current, new Node(current.data));
```

we have:

```text
Original       Clone
---------      ------
Node 1   --->  New Node 1
Node 2   --->  New Node 2
Node 3   --->  New Node 3
```

Then:

```java
clonedNode.random = map.get(current.random);
```

If:

```text
current = Node 1
current.random = Node 3
```

then:

```text
map.get(Node 3)
       ↓
New Node 3
```

So we can correctly connect:

```text
New Node 1
    |
    └── random → New Node 3
```

---

# 4. Complexity

For `N` nodes:

```text
Time  → O(N)
Space → O(N)
```

Why?

We traverse the linked list twice:

```text
O(N) + O(N) = O(N)
```

HashMap stores `N` mappings:

```text
Original Node → Cloned Node
```

so extra space is `O(N)`.

# 5. Another Important Application: Detect Cycle

HashMap/HashSet can also detect whether a linked list contains a cycle.

Example:

```text
1 → 2 → 3 → 4
        ↑     |
        |_____|
```

Using `HashSet`:

```java
import java.util.HashSet;
import java.util.Set;

class Node {
    int data;
    Node next;

    Node(int data) {
        this.data = data;
    }
}

public class Main {

    public static boolean hasCycle(Node head) {

        Set<Node> visited = new HashSet<>();

        Node current = head;

        while (current != null) {

            if (visited.contains(current)) {
                return true;
            }

            visited.add(current);
            current = current.next;
        }

        return false;
    }

    public static void main(String[] args) {

        Node first = new Node(1);
        Node second = new Node(2);
        Node third = new Node(3);

        first.next = second;
        second.next = third;

        // Create cycle
        third.next = second;

        System.out.println(hasCycle(first)); // true
    }
}
```

Here:

```text
Node → visited?
```

is what the `HashSet` tracks.

### Complexity

```text
Time  → O(N)
Space → O(N)
```

However, there is a more optimal solution:

**Floyd's Cycle Detection (Slow + Fast pointers)**

```text
Time  → O(N)
Space → O(1)
```

You should learn that immediately after this.

---

## Key takeaway

For **Linked List + HashMap/HashSet**, remember these two major patterns:

| Problem                   | Hashing technique          |
| ------------------------- | -------------------------- |
| Clone Random Pointer List | `HashMap<Original, Clone>` |
| Detect Cycle              | `HashSet<Node>`            |
| Find duplicate node       | `HashSet<Node>`            |
| Map node to information   | `HashMap<Node, Value>`     |

The most important interview problem here is **Clone Linked List with Random Pointer**, because it teaches the general pattern:

```text
Original Object → Corresponding New Object
```

That pattern appears in many object-copying and graph problems too.
