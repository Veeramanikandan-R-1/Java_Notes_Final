# DSA → Arrays

## 1. What is an Array?

An **array** stores multiple values of the **same type** in a fixed-size, contiguous memory structure.

```java
int[] nums = {10, 20, 30, 40, 50};
```

Indexes:

```text
Index:   0   1   2   3   4
Value:  10  20  30  40  50
```

Access:

```java
System.out.println(nums[2]); // 30
```

### Important properties

| Property         | Array                |
| ---------------- | -------------------- |
| Size             | Fixed                |
| Index            | 0-based              |
| Access by index  | O(1)                 |
| Search           | O(n)                 |
| Insert at end    | O(1) if space exists |
| Insert in middle | O(n)                 |
| Delete in middle | O(n)                 |
| Duplicate values | Allowed              |
| Same data type   | Yes                  |

---

# 2. Why is Array Access O(1)?

This is one of the most important DSA concepts.

Suppose:

```java
int[] nums = {10, 20, 30, 40, 50};
```

When you do:

```java
nums[3]
```

Java doesn't start from index `0` and search.

Conceptually:

```text
address = baseAddress + (index × elementSize)
```

Therefore, it can directly calculate where index `3` is.

So:

```java
nums[3]
```

is **O(1)**.

# 5. Traversing an Array

### Normal `for` loop

Most useful in DSA because you have the index.

```java
int[] nums = {10, 20, 30, 40};

for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}
```

### Enhanced `for` loop

```java
for (int num : nums) {
    System.out.println(num);
}
```

Use enhanced `for` when you **don't need the index**.

For DSA problems, the normal `for` loop is often more useful.

int target = 30;

        break;

**Time:** O(n)

Because in the worst case you may check every element.

# 7. Array Insertion

Arrays have a **fixed size**, so you cannot simply increase their size.

Suppose:

```text
[10, 20, 30, 40]
```

To insert `25` at index `2`, elements must shift:

```text
Before:
[10, 20, 30, 40]

Shift:
30 → 40
20 → 30

After:
[10, 20, 25, 30, 40]
```

That's why insertion in the middle is:

**O(n)**

In Java, `ArrayList` is normally used when you need a dynamically growing array.

---

# 8. Array Deletion

Suppose:

```text
[10, 20, 30, 40, 50]
```

Delete `30`.

Elements shift:

```text
[10, 20, 40, 50, 50]
```

Then logically reduce the size.

Again, shifting makes deletion **O(n)**.

# 9. Array vs ArrayList

This distinction is important for Java interviews.

| Array                    | ArrayList            |
| ------------------------ | -------------------- |
| Fixed size               | Dynamic size         |
| `int[]`                  | `ArrayList<Integer>` |
| Supports primitives      | Uses objects         |
| `.length`                | `.size()`            |
| Generally lower overhead | More flexible        |
| `nums[i]`                | `list.get(i)`        |

Example:

```java
int[] nums = new int[5];
```

vs

```java
ArrayList<Integer> nums = new ArrayList<>();
nums.add(10);
nums.add(20);
```

For **DSA**, you'll frequently solve problems using plain arrays such as `int[]`.

# 10. Most Important Array Patterns for DSA

Don't memorize hundreds of solutions.

Learn these patterns.

### Pattern 1 — Traversal

```text
for each element
    process element
```

Examples:

* Find maximum
* Find minimum
* Count elements
* Calculate sum

---

### Pattern 2 — Two Pointers

```text
left → →       ← ← right
```

Common for:

* Reverse array
* Two Sum in sorted array
* Remove duplicates
* Move zeros
* Container With Most Water

---

### Pattern 3 — Sliding Window

Maintain a window:

```text
[ left ........ right ]
```

Common for:

* Maximum sum subarray of size K
* Longest subarray/string satisfying condition
* Minimum/maximum window problems

---

### Pattern 4 — Prefix Sum

For:

```text
[2, 4, 1, 5, 3]
```

Prefix:

```text
[2, 6, 7, 12, 15]
```

Then range sums can be calculated efficiently.

---

### Pattern 5 — Hashing

Use:

```java
HashMap
HashSet
```

Common for:

* Two Sum
* Contains Duplicate
* Frequency counting
* Longest consecutive sequence

---

### Pattern 6 — Sorting + Array

Sometimes sorting transforms a difficult problem into a simple one.

Example:

```text
[3, 1, 4, 2]
```

After sorting:

```text
[1, 2, 3, 4]
```

Then use:

* Two pointers
* Binary search
* Greedy techniques

# 18. 1D vs 2D Arrays

### 1D

```java
int[] nums = {1, 2, 3};
```

### 2D

```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

Access:

```java
matrix[1][2]
```

Output:

```text
6
```

Traversal:

```java
for (int i = 0; i < matrix.length; i++) {

    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + " ");
    }

    System.out.println();
}
```

2D arrays become important for problems involving:

* Matrix traversal
* Spiral matrix
* Rotate matrix
* Set Matrix Zeroes
* Search in matrix
