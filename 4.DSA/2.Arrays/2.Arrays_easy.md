# 1. Find Maximum Element

### Problem

Find the largest number in an array.

### Example

```text
Input:  [10, 5, 25, 8, 15]

Output: 25
```

### DSA idea

Keep a `max` variable and compare every element.

```text
max = 10

5  → 5 > 10?  No
25 → 25 > 10? Yes → max = 25
8  → 8 > 25?  No
15 → 15 > 25? No
```

### Java

```java
public static int findMax(int[] arr) {

    int max = arr[0];

    for (int i = 1; i < arr.length; i++) {

        if (arr[i] > max) {
            max = arr[i];
        }
    }

    return max;
}
```

```text
Time:  O(n)
Space: O(1)
```

**Pattern:** Traversal

# 3. Find Second Largest

### Example

```text
Input:  [10, 5, 25, 8, 15]

Output: 15
```

Because:

```text
Largest        = 25
Second largest = 15
```

### DSA idea

Maintain two variables:

```text
largest
secondLargest
```

### Java

```java
public static int secondLargest(int[] arr) {

    int largest = Integer.MIN_VALUE;
    int secondLargest = Integer.MIN_VALUE;

    for (int num : arr) {

        if (num > largest) {

            secondLargest = largest;
            largest = num;

        } else if (num > secondLargest && num != largest) {

            secondLargest = num;
        }
    }

    return secondLargest;
}
```

### Example trace

```text
[10, 5, 25, 8, 15]

10 → largest = 10
5  → secondLargest = 5
25 → largest = 25
     secondLargest = 10
8  → nothing
15 → secondLargest = 15
```

```text
Output: 15
```

```text
Time:  O(n)
Space: O(1)
```

**Pattern:** Single traversal + maintain state

# 4. Reverse an Array

### Example

```text
Input:  [1, 2, 3, 4, 5]

Output: [5, 4, 3, 2, 1]
```

### DSA idea: Two Pointers

Use:

```text
left  → beginning
right → end
```

```text
[1, 2, 3, 4, 5]
 ↑           ↑
left        right
```

Swap them:

```text
[5, 2, 3, 4, 1]
```

Move pointers:

```text
   ↑       ↑
 left    right
```

Continue until they meet.

### Java

```java
public static void reverse(int[] arr) {

    int left = 0;
    int right = arr.length - 1;

    while (left < right) {

        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}
```

```text
Time:  O(n)
Space: O(1)
```

**Pattern:** Two Pointers

# 5. Check If Array Is Sorted

Assume ascending order.

### Example 1

```text
Input:  [1, 2, 3, 4, 5]

Output: true
```

### Example 2

```text
Input:  [1, 2, 5, 3, 4]

Output: false
```

### DSA idea

Compare each element with the previous element.

If:

```text
arr[i] < arr[i - 1]
```

the array is not sorted.

### Java

```java
public static boolean isSorted(int[] arr) {

    for (int i = 1; i < arr.length; i++) {

        if (arr[i] < arr[i - 1]) {
            return false;
        }
    }

    return true;
}
```

### Example

```text
[1, 2, 5, 3, 4]

1 → 2  ✓
2 → 5  ✓
5 → 3  ✗

Therefore: false
```

```text
Time:  O(n)
Space: O(1)
```

**Pattern:** Adjacent element comparison

# 6. Linear Search

### Problem

Find the index of a target element.

### Example

```text
Input:
arr = [10, 20, 30, 40]
target = 30

Output:
2
```

Remember arrays are zero-indexed:

```text
index:  0   1   2   3
        ↓   ↓   ↓   ↓
value: 10  20  30  40
                ↑
              target
```

### DSA idea

Check each element one by one.

### Java

```java
public static int linearSearch(int[] arr, int target) {

    for (int i = 0; i < arr.length; i++) {

        if (arr[i] == target) {
            return i;
        }
    }

    return -1;
}
```

If target doesn't exist:

```text
Output: -1
```

```text
Time:  O(n)
Space: O(1)
```

**Pattern:** Traversal

# 7. Count Frequency of Elements

### Problem

Count how many times each number occurs.

### Example

```text
Input:
[1, 2, 2, 3, 1, 2]
```

Output:

```text
1 → 2
2 → 3
3 → 1
```

### DSA idea: HashMap

We store:

```text
number → count
```

Initially:

```text
{}
```

Process `1`:

```text
{1=1}
```

Process `2`:

```text
{1=1, 2=1}
```

Process another `2`:

```text
{1=1, 2=2}
```

And so on.

### Java

```java
import java.util.HashMap;
import java.util.Map;

public static Map<Integer, Integer> countFrequency(int[] arr) {

    Map<Integer, Integer> map = new HashMap<>();

    for (int num : arr) {

        map.put(
            num,
            map.getOrDefault(num, 0) + 1
        );
    }

    return map;
}
```

### Important

Understand this line:

```java
map.getOrDefault(num, 0)
```

It means:

> "Give me the current count of `num`. If it doesn't exist, give me `0`."

Then:

```java
+ 1
```

increases the count.

```text
Time:  O(n) average
Space: O(n)
```

**Pattern:** HashMap / Frequency counting

# 8. Remove Duplicates From Sorted Array

### Important

The array must be **sorted**.

### Example

```text
Input:
[1, 1, 2, 2, 3, 3]

Output:
[1, 2, 3]
```

In the typical interview/LeetCode version, you modify the original array and return the number of unique elements.

### DSA idea: Two Pointers

Use:

```text
slow → position of last unique element
fast → scans the array
```

Example:

```text
[1, 1, 2, 2, 3]
 ↑  ↑
slow fast
```

When `fast` finds a new value, move `slow` and copy it.

### Java

```java
public static int removeDuplicates(int[] arr) {

    if (arr.length == 0) {
        return 0;
    }

    int slow = 0;

    for (int fast = 1; fast < arr.length; fast++) {

        if (arr[fast] != arr[slow]) {

            slow++;

            arr[slow] = arr[fast];
        }
    }

    return slow + 1;
}
```

Example:

```text
Input:
[1,1,2,2,3]

After processing:
[1,2,3,2,3]

returned length = 3
```

Only the first `3` elements matter:

```text
[1,2,3]
```

```text
Time:  O(n)
Space: O(1)
```

**Pattern:** Two Pointers

# 9. Move Zeros to End

### Example

```text
Input:
[0, 1, 0, 3, 12]

Output:
[1, 3, 12, 0, 0]
```

The important requirement is usually:

> Keep the relative order of non-zero elements.

So:

```text
1, 3, 12
```

must remain in that order.

### DSA idea

Use a pointer called `insertPos`.

It tells us:

> "Where should the next non-zero number go?"

### Java

```java
public static void moveZeroes(int[] arr) {

    int insertPos = 0;

    // Put all non-zero elements first
    for (int num : arr) {

        if (num != 0) {
            arr[insertPos] = num;
            insertPos++;
        }
    }

    // Fill remaining positions with zero
    while (insertPos < arr.length) {

        arr[insertPos] = 0;
        insertPos++;
    }
}
```

### Example

```text
Original:
[0,1,0,3,12]

Non-zero values:
1,3,12

Put them first:
[1,3,12,_,_]

Fill remaining:
[1,3,12,0,0]
```

```text
Time:  O(n)
Space: O(1)
```

**Pattern:** Two Pointers / In-place modification

# 10. Left / Right Rotate Array

This is a very common interview problem.

## Left Rotate

### Example

```text
Input:
[1, 2, 3, 4, 5]

k = 2
```

Move the first 2 elements to the end:

```text
[3, 4, 5, 1, 2]
```

### DSA idea: Reversal Algorithm

For left rotation by `k`:

```text
1. Reverse first k elements
2. Reverse remaining elements
3. Reverse entire array
```

For:

```text
[1,2,3,4,5]
k = 2
```

Step 1:

```text
[2,1,3,4,5]
```

Step 2:

```text
[2,1,5,4,3]
```

Step 3:

```text
[3,4,5,1,2]
```

### Java

```java
public static void leftRotate(int[] arr, int k) {

    int n = arr.length;

    k = k % n;

    reverse(arr, 0, k - 1);
    reverse(arr, k, n - 1);
    reverse(arr, 0, n - 1);
}

public static void reverse(int[] arr, int left, int right) {

    while (left < right) {

        int temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }
}
```

```text
Time:  O(n)
Space: O(1)
```
