# 21. 3Sum

### Problem

Find all unique triplets whose sum is `0`.

### Example

```text
Input:
[-1, 0, 1, 2, -1, -4]

Output:
[[-1, -1, 2], [-1, 0, 1]]
```

### Idea

1. Sort the array.
2. Fix one element.
3. Use two pointers for the remaining part.

```text
i → fixed element
left → next element
right → last element
```

If sum:

```text
< 0 → left++
> 0 → right--
= 0 → found triplet
```

### Full working example

```java
import java.util.*;

public class Main {

    public static List<List<Integer>> threeSum(int[] nums) {

        List<List<Integer>> result = new ArrayList<>();

        Arrays.sort(nums);

        for (int i = 0; i < nums.length - 2; i++) {

            // Skip duplicate fixed values
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;

            while (left < right) {

                int sum = nums[i] + nums[left] + nums[right];

                if (sum == 0) {

                    result.add(Arrays.asList(
                        nums[i],
                        nums[left],
                        nums[right]
                    ));

                    // Skip duplicates
                    while (left < right &&
                           nums[left] == nums[left + 1]) {
                        left++;
                    }

                    while (left < right &&
                           nums[right] == nums[right - 1]) {
                        right--;
                    }

                    left++;
                    right--;

                } else if (sum < 0) {

                    left++;

                } else {

                    right--;
                }
            }
        }

        return result;
    }

    public static void main(String[] args) {

        int[] nums = {-1, 0, 1, 2, -1, -4};

        System.out.println(threeSum(nums));
    }
}
```

Output:

```text
[[-1, -1, 2], [-1, 0, 1]]
```

**Time:** O(n²)
**Space:** O(1) auxiliary, excluding output

**Pattern:** Sorting + Two Pointers

# 22. Container With Most Water

### Problem

Find two lines that can hold the maximum amount of water.

### Example

```text
height = [1,8,6,2,5,4,8,3,7]

Output:
49
```

Area:

```text
width × minimum height
```

For indices `1` and `8`:

```text
width = 8 - 1 = 7
height = min(8,7) = 7

area = 7 × 7 = 49
```

### Key idea

Start from both ends.

```text
left → 0
right → n-1
```

Move the **shorter side**.

Why?

The shorter side limits the water level. Moving the taller side cannot increase the limiting height.

### Full working example

```java
public class Main {

    public static int maxArea(int[] height) {

        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {

            int width = right - left;

            int currentArea =
                    Math.min(height[left], height[right]) * width;

            maxArea = Math.max(maxArea, currentArea);

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxArea;
    }

    public static void main(String[] args) {

        int[] height = {1, 8, 6, 2, 5, 4, 8, 3, 7};

        System.out.println(maxArea(height));
    }
}
```

Output:

```text
49
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Two Pointers

# 23. Trapping Rain Water

### Problem

Given heights of bars, calculate how much rainwater can be trapped.

### Example

```text
Input:
[0,1,0,2,1,0,1,3,2,1,2,1]

Output:
6
```

### Core concept

Water above an index:

```text
min(maxLeft, maxRight) - currentHeight
```

Instead of creating left/right arrays, we can use two pointers.

### Full working example

```java
public class Main {

    public static int trap(int[] height) {

        int left = 0;
        int right = height.length - 1;

        int leftMax = 0;
        int rightMax = 0;

        int water = 0;

        while (left < right) {

            if (height[left] <= height[right]) {

                if (height[left] >= leftMax) {
                    leftMax = height[left];
                } else {
                    water += leftMax - height[left];
                }

                left++;

            } else {

                if (height[right] >= rightMax) {
                    rightMax = height[right];
                } else {
                    water += rightMax - height[right];
                }

                right--;
            }
        }

        return water;
    }

    public static void main(String[] args) {

        int[] height =
                {0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1};

        System.out.println(trap(height));
    }
}
```

Output:

```text
6
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Two Pointers

# 24. Subarray Sum Equals K

### Problem

Find the number of contiguous subarrays whose sum equals `k`.

### Example

```text
nums = [1,1,1]
k = 2
```

Subarrays:

```text
[1,1] → 2
[1,1] → 2
```

Output:

```text
2
```

### Key idea: Prefix Sum + HashMap

Suppose current prefix sum is:

```text
currentSum
```

We need an earlier prefix sum:

```text
currentSum - k
```

So:

```text
needed = currentSum - k
```

If we have seen that sum before, we found one or more valid subarrays.

### Full working example

```java
import java.util.*;

public class Main {

    public static int subarraySum(int[] nums, int k) {

        Map<Integer, Integer> map = new HashMap<>();

        // Important
        map.put(0, 1);

        int currentSum = 0;
        int count = 0;

        for (int num : nums) {

            currentSum += num;

            int needed = currentSum - k;

            count += map.getOrDefault(needed, 0);

            map.put(
                currentSum,
                map.getOrDefault(currentSum, 0) + 1
            );
        }

        return count;
    }

    public static void main(String[] args) {

        int[] nums = {1, 1, 1};
        int k = 2;

        System.out.println(subarraySum(nums, k));
    }
}
```

Output:

```text
2
```

**Time:** O(n) average
**Space:** O(n)

**Pattern:** Prefix Sum + HashMap

### Important

Remember:

```java
map.put(0, 1);
```

This handles subarrays that start from index `0`.

# 25. Longest Consecutive Sequence

### Problem

Find the length of the longest consecutive sequence.

### Example

```text
Input:
[100,4,200,1,3,2]

Sequence:
1,2,3,4

Output:
4
```

### Idea

Put everything into a `HashSet`.

Only start counting when:

```java
!set.contains(num - 1)
```

That means `num` is the **beginning** of a sequence.

### Full working example

```java
import java.util.*;

public class Main {

    public static int longestConsecutive(int[] nums) {

        Set<Integer> set = new HashSet<>();

        for (int num : nums) {
            set.add(num);
        }

        int longest = 0;

        for (int num : set) {

            // Start of sequence
            if (!set.contains(num - 1)) {

                int current = num;
                int length = 1;

                while (set.contains(current + 1)) {

                    current++;
                    length++;
                }

                longest = Math.max(longest, length);
            }
        }

        return longest;
    }

    public static void main(String[] args) {

        int[] nums = {100, 4, 200, 1, 3, 2};

        System.out.println(longestConsecutive(nums));
    }
}
```

Output:

```text
4
```

**Time:** O(n) average
**Space:** O(n)

**Pattern:** HashSet

# 26. Maximum Product Subarray

### Problem

Find the contiguous subarray with the maximum product.

### Example

```text
Input:
[2,3,-2,4]

Output:
6
```

Because:

```text
2 × 3 = 6
```

### Why is this harder than maximum sum?

Because negative numbers behave differently:

```text
negative × negative = positive
```

So we need to track both:

```text
maxProduct
minProduct
```

Example:

```text
[-2, 3, -4]

-2 × 3 = -6

-6 × -4 = 24
```

The previous **minimum** becomes the new maximum.

### Full working example

```java
public class Main {

    public static int maxProduct(int[] nums) {

        int maxProduct = nums[0];
        int minProduct = nums[0];

        int result = nums[0];

        for (int i = 1; i < nums.length; i++) {

            int num = nums[i];

            // Negative number swaps max/min
            if (num < 0) {

                int temp = maxProduct;
                maxProduct = minProduct;
                minProduct = temp;
            }

            maxProduct = Math.max(
                num,
                maxProduct * num
            );

            minProduct = Math.min(
                num,
                minProduct * num
            );

            result = Math.max(result, maxProduct);
        }

        return result;
    }

    public static void main(String[] args) {

        int[] nums = {2, 3, -2, 4};

        System.out.println(maxProduct(nums));
    }
}
```

Output:

```text
6
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Dynamic running state

# 27. Merge Intervals

### Problem

Merge overlapping intervals.

### Example

```text
Input:
[[1,3], [2,6], [8,10], [15,18]]

Output:
[[1,6], [8,10], [15,18]]
```

Because:

```text
[1,3]
[2,6]

overlap → [1,6]
```

### Key idea

First sort by starting time.

Then compare:

```text
current interval
      ↓
next interval
```

If:

```text
next.start <= current.end
```

they overlap.

### Full working example

```java
import java.util.*;

public class Main {

    public static int[][] merge(int[][] intervals) {

        if (intervals.length <= 1) {
            return intervals;
        }

        // Sort by start
        Arrays.sort(
            intervals,
            (a, b) -> Integer.compare(a[0], b[0])
        );

        List<int[]> result = new ArrayList<>();

        int start = intervals[0][0];
        int end = intervals[0][1];

        for (int i = 1; i < intervals.length; i++) {

            int currentStart = intervals[i][0];
            int currentEnd = intervals[i][1];

            if (currentStart <= end) {

                // Overlap
                end = Math.max(end, currentEnd);

            } else {

                // No overlap
                result.add(new int[]{start, end});

                start = currentStart;
                end = currentEnd;
            }
        }

        // Add last interval
        result.add(new int[]{start, end});

        return result.toArray(new int[result.size()][]);
    }

    public static void main(String[] args) {

        int[][] intervals = {
            {1, 3},
            {2, 6},
            {8, 10},
            {15, 18}
        };

        int[][] result = merge(intervals);

        System.out.println(Arrays.deepToString(result));
    }
}
```

Output:

```text
[[1, 6], [8, 10], [15, 18]]
```

**Time:** O(n log n)
**Space:** O(n) for result

**Pattern:** Sorting + Greedy

# 28. Rotate Array

### Problem

Rotate the array to the **right by `k` positions**.

### Example

```text
Input:
[1,2,3,4,5,6,7]

k = 3

Output:
[5,6,7,1,2,3,4]
```

### Reverse technique

Original:

```text
[1 2 3 4 5 6 7]
```

Reverse entire array:

```text
[7 6 5 4 3 2 1]
```

Reverse first `k`:

```text
[5 6 7 4 3 2 1]
```

Reverse remaining:

```text
[5 6 7 1 2 3 4]
```

### Full working example

```java
import java.util.*;

public class Main {

    public static void rotate(int[] nums, int k) {

        int n = nums.length;

        k = k % n;

        reverse(nums, 0, n - 1);

        reverse(nums, 0, k - 1);

        reverse(nums, k, n - 1);
    }

    public static void reverse(int[] nums, int left, int right) {

        while (left < right) {

            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;

            left++;
            right--;
        }
    }

    public static void main(String[] args) {

        int[] nums = {1, 2, 3, 4, 5, 6, 7};

        rotate(nums, 3);

        System.out.println(Arrays.toString(nums));
    }
}
```

Output:

```text
[5, 6, 7, 1, 2, 3, 4]
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Array reversal / Two pointers

⚠️ In production code, handle an empty array before `k % n`.

# 29. Find Minimum in Rotated Sorted Array

### Problem

Find the minimum element in a rotated sorted array.

### Example

```text
Input:
[4,5,6,7,0,1,2]

Output:
0
```

The original sorted array was:

```text
[0,1,2,4,5,6,7]
```

It was rotated.

### Key idea: Binary Search

Compare:

```text
nums[mid]
```

with:

```text
nums[right]
```

If:

```text
nums[mid] > nums[right]
```

the minimum must be on the **right**.

Otherwise, minimum is on the **left including mid**.

### Full working example

```java
public class Main {

    public static int findMin(int[] nums) {

        int left = 0;
        int right = nums.length - 1;

        while (left < right) {

            int mid = left + (right - left) / 2;

            if (nums[mid] > nums[right]) {

                left = mid + 1;

            } else {

                right = mid;
            }
        }

        return nums[left];
    }

    public static void main(String[] args) {

        int[] nums = {4, 5, 6, 7, 0, 1, 2};

        System.out.println(findMin(nums));
    }
}
```

Output:

```text
0
```

**Time:** O(log n)
**Space:** O(1)

**Pattern:** Binary Search

⚠️ This standard solution assumes **distinct values**.

# 30. Search in Rotated Sorted Array

### Problem

Search for a target in a rotated sorted array.

Return its index, otherwise `-1`.

### Example

```text
nums = [4,5,6,7,0,1,2]
target = 0

Output:
4
```

### Key idea

At any point, **at least one half is sorted**.

Example:

```text
[4,5,6,7,0,1,2]
 ↑     ↑     ↑
left  mid   right
```

If:

```text
nums[left] <= nums[mid]
```

then the left half is sorted.

Otherwise, the right half is sorted.

Then determine whether the target belongs to that sorted half.

### Full working example

```java
public class Main {

    public static int search(int[] nums, int target) {

        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {

            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            }

            // Left half is sorted
            if (nums[left] <= nums[mid]) {

                if (nums[left] <= target &&
                    target < nums[mid]) {

                    right = mid - 1;

                } else {

                    left = mid + 1;
                }

            } else {

                // Right half is sorted
                if (nums[mid] < target &&
                    target <= nums[right]) {

                    left = mid + 1;

                } else {

                    right = mid - 1;
                }
            }
        }

        return -1;
    }

    public static void main(String[] args) {

        int[] nums = {4, 5, 6, 7, 0, 1, 2};

        int target = 0;

        System.out.println(search(nums, target));
    }
}
```

Output:

```text
4
```

**Time:** O(log n)
**Space:** O(1)

**Pattern:** Modified Binary Search

⚠️ This standard solution assumes **distinct values**.
