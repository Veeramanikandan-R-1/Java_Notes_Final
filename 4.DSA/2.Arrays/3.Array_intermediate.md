# 11. Two Sum

### Problem

Given an array and a target, find **two indices** whose values add up to the target.

### Example

```text
Input:
nums = [2, 7, 11, 15]
target = 9

2 + 7 = 9

Output:
[0, 1]
```

### Approach: HashMap

Store:

```text
number → index
```

For each number:

```text
needed = target - current
```

Check whether `needed` already exists.

### Full working example

```java
import java.util.*;

public class Main {

    public static int[] twoSum(int[] nums, int target) {

        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {

            int current = nums[i];
            int needed = target - current;

            if (map.containsKey(needed)) {
                return new int[]{map.get(needed), i};
            }

            map.put(current, i);
        }

        return new int[]{};
    }

    public static void main(String[] args) {

        int[] nums = {2, 7, 11, 15};
        int target = 9;

        int[] result = twoSum(nums, target);

        System.out.println(Arrays.toString(result));
    }
}
```

Output:

```text
[0, 1]
```

**Time:** O(n) average
**Space:** O(n)

**Pattern:** HashMap lookup

# 12. Best Time to Buy and Sell Stock

### Problem

You can buy once and sell once.

Find the **maximum profit**.

### Example

```text
prices = [7, 1, 5, 3, 6, 4]

Buy at 1
Sell at 6

Profit = 6 - 1 = 5
```

Output:

```text
5
```

### Idea

Keep track of:

```text
minimum price seen so far
maximum profit so far
```

### Best Time to Buy and Sell Stock

You are given an array of stock prices, where each element represents the stock price on that day.

You can:

* **Buy once**
* **Sell once**
* You must **buy before selling**

Find the **maximum profit** you can make.

**Example:**

```text
prices = [7, 1, 5, 3, 6, 4]

Buy at 1
Sell at 6

Profit = 6 - 1 = 5
```

**Output:**

```text
5
```

If no profit is possible, return `0`.

### Full working example

```java
public class Main {

    public static int maxProfit(int[] prices) {

        int minPrice = Integer.MAX_VALUE;
        int maxProfit = 0;

        for (int price : prices) {

            minPrice = Math.min(minPrice, price);

            int profit = price - minPrice;

            maxProfit = Math.max(maxProfit, profit);
        }

        return maxProfit;
    }

    public static void main(String[] args) {

        int[] prices = {7, 1, 5, 3, 6, 4};

        System.out.println(maxProfit(prices));
    }
}
```

Output:

```text
5
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Greedy / running minimum

# 13. Kadane's Algorithm — Maximum Subarray

### Problem

Find the contiguous subarray having the maximum sum.

### Example

```text
nums = [-2,1,-3,4,-1,2,1,-5,4]

Best subarray:
[4,-1,2,1]

Sum = 6
```

Output:

```text
6
```

### Core idea

At every number ask:

> Should I continue the existing subarray or start a new one?

```text
currentSum = max(current number,
                 currentSum + current number)
```

### Full working example

```java
public class Main {

    public static int maxSubArray(int[] nums) {

        int currentSum = nums[0];
        int maxSum = nums[0];

        for (int i = 1; i < nums.length; i++) {

            currentSum = Math.max(
                nums[i],
                currentSum + nums[i]
            );

            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }

    public static void main(String[] args) {

        int[] nums = {-2, 1, -3, 4, -1, 2, 1, -5, 4};

        System.out.println(maxSubArray(nums));
    }
}
```

Output:

```text
6
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Kadane / dynamic running state

### Interview point

Don't initialize `maxSum = 0`.

For:

```text
[-5, -2, -8]
```

answer should be:

```text
-2
```

That's why we start with `nums[0]`.

# 14. Majority Element

### Problem

Find the element appearing **more than n/2 times**.

### Example

```text
nums = [2,2,1,1,1,2,2]

2 appears 4 times

Output:
2
```

### Approach: Boyer-Moore Voting Algorithm

Think of different numbers cancelling each other:

```text
same candidate → count++
different      → count--
count == 0     → choose new candidate
```

### Full working example

```java
public class Main {

    public static int majorityElement(int[] nums) {

        int candidate = 0;
        int count = 0;

        for (int num : nums) {

            if (count == 0) {
                candidate = num;
            }

            if (num == candidate) {
                count++;
            } else {
                count--;
            }
        }

        return candidate;
    }

    public static void main(String[] args) {

        int[] nums = {2, 2, 1, 1, 1, 2, 2};

        System.out.println(majorityElement(nums));
    }
}
```

Output:

```text
2
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Boyer-Moore Voting

⚠️ This solution assumes a majority element **is guaranteed to exist**. If it isn't, verify the candidate with a second pass.

# 15. Missing Number

### Problem

Array contains numbers from `0` to `n`, with exactly one number missing.

### Example

```text
nums = [3,0,1]

Expected:
0,1,2,3

Missing:
2
```

Output:

```text
2
```

### Approach: XOR

Important XOR properties:

```text
x ^ x = 0
x ^ 0 = x
```

So matching numbers cancel.

### Full working example

```java
public class Main {

    public static int missingNumber(int[] nums) {

        int result = nums.length;

        for (int i = 0; i < nums.length; i++) {

            result ^= i;
            result ^= nums[i];
        }

        return result;
    }

    public static void main(String[] args) {

        int[] nums = {3, 0, 1};

        System.out.println(missingNumber(nums));
    }
}
```

Output:

```text
2
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** XOR

# 16. Find the Duplicate Number

### Problem

Array contains numbers `1` to `n`, with one number duplicated.

### Example

```text
nums = [1,3,4,2,2]

Duplicate = 2
```

### Approach: Floyd's Cycle Detection

This is an important interview trick.

Treat the array like a linked list:

```text
index → nums[index]
```

The duplicate creates a cycle.

Use:

```text
slow → one step
fast → two steps
```

### Full working example

```java
public class Main {

    public static int findDuplicate(int[] nums) {

        int slow = nums[0];
        int fast = nums[0];

        // Find meeting point
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);

        // Find entrance of cycle
        slow = nums[0];

        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }

        return slow;
    }

    public static void main(String[] args) {

        int[] nums = {1, 3, 4, 2, 2};

        System.out.println(findDuplicate(nums));
    }
}
```

Output:

```text
2
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Floyd's Cycle Detection

⚠️ This depends on the standard constraints: values `1..n`, array length `n+1`, and at least one duplicate.

# 17. Merge Sorted Arrays

### Problem

Given two sorted arrays, merge them into one sorted array.

### Example

```text
arr1 = [1,3,5]
arr2 = [2,4,6]

Output:
[1,2,3,4,5,6]
```

### Approach: Two Pointers

```text
i → arr1
j → arr2
```

Compare:

```text
arr1[i] vs arr2[j]
```

Take the smaller one.

### Full working example

```java
import java.util.*;

public class Main {

    public static int[] mergeSortedArrays(int[] a, int[] b) {

        int[] result = new int[a.length + b.length];

        int i = 0;
        int j = 0;
        int k = 0;

        while (i < a.length && j < b.length) {

            if (a[i] <= b[j]) {
                result[k++] = a[i++];
            } else {
                result[k++] = b[j++];
            }
        }

        while (i < a.length) {
            result[k++] = a[i++];
        }

        while (j < b.length) {
            result[k++] = b[j++];
        }

        return result;
    }

    public static void main(String[] args) {

        int[] a = {1, 3, 5};
        int[] b = {2, 4, 6};

        int[] result = mergeSortedArrays(a, b);

        System.out.println(Arrays.toString(result));
    }
}
```

Output:

```text
[1, 2, 3, 4, 5, 6]
```

**Time:** O(n + m)
**Space:** O(n + m)

**Pattern:** Two pointers

# 18. Intersection of Two Arrays

There are **two common versions**.

## Version A — Unique Intersection

Example:

```text
nums1 = [1,2,2,1]
nums2 = [2,2]

Output:
[2]
```

Use `HashSet`.

### Full working example

```java
import java.util.*;

public class Main {

    public static int[] intersection(int[] nums1, int[] nums2) {

        Set<Integer> set1 = new HashSet<>();

        for (int num : nums1) {
            set1.add(num);
        }

        Set<Integer> result = new HashSet<>();

        for (int num : nums2) {

            if (set1.contains(num)) {
                result.add(num);
            }
        }

        return result.stream()
                .mapToInt(Integer::intValue)
                .toArray();
    }

    public static void main(String[] args) {

        int[] nums1 = {1, 2, 2, 1};
        int[] nums2 = {2, 2};

        System.out.println(
            Arrays.toString(intersection(nums1, nums2))
        );
    }
}
```

Output:

```text
[2]
```

**Time:** O(n + m) average
**Space:** O(n)

---

## Version B — Intersection With Duplicates

Example:

```text
nums1 = [1,2,2,1]
nums2 = [2,2]

Output:
[2,2]
```

Use a frequency `HashMap`.

```java
Map<Integer, Integer> map = new HashMap<>();
```

This version is often called **Intersection of Two Arrays II**.

**Interview tip:** Always check whether the question wants **unique values** or **duplicates preserved**.

# 19. Sort Colors

### Problem

Array contains only:

```text
0 → red
1 → white
2 → blue
```

Sort them **in-place**.

### Example

```text
Input:
[2,0,2,1,1,0]

Output:
[0,0,1,1,2,2]
```

### Approach: Dutch National Flag

Maintain three regions:

```text
0 ... low-1     → 0
low ... mid-1   → 1
mid ... high    → unknown
high+1 ... end  → 2
```

### Full working example

```java
import java.util.*;

public class Main {

    public static void sortColors(int[] nums) {

        int low = 0;
        int mid = 0;
        int high = nums.length - 1;

        while (mid <= high) {

            if (nums[mid] == 0) {

                swap(nums, low, mid);

                low++;
                mid++;

            } else if (nums[mid] == 1) {

                mid++;

            } else {

                swap(nums, mid, high);

                high--;
            }
        }
    }

    public static void swap(int[] nums, int i, int j) {

        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }

    public static void main(String[] args) {

        int[] nums = {2, 0, 2, 1, 1, 0};

        sortColors(nums);

        System.out.println(Arrays.toString(nums));
    }
}
```

Output:

```text
[0, 0, 1, 1, 2, 2]
```

**Time:** O(n)
**Space:** O(1)

**Pattern:** Three pointers / Dutch National Flag

### Important

When `nums[mid] == 2`, we **do not increment `mid`**.

Why?

Because the element swapped from `high` into `mid` has not been checked yet.

# 20. Product of Array Except Self

### Problem

For every index, return the product of all other elements.

### Example

```text
Input:
[1,2,3,4]

Output:
[24,12,8,6]
```

Because:

```text
index 0 → 2 × 3 × 4 = 24
index 1 → 1 × 3 × 4 = 12
index 2 → 1 × 2 × 4 = 8
index 3 → 1 × 2 × 3 = 6
```

### Important restriction

Usually the problem says:

> Do not use division.

### Approach

Use:

```text
prefix product
+
suffix product
```

First pass:

```text
result[i] = product of elements before i
```

Second pass:

```text
result[i] *= product of elements after i
```

### Full working example

```java
import java.util.*;

public class Main {

    public static int[] productExceptSelf(int[] nums) {

        int n = nums.length;

        int[] result = new int[n];

        // Prefix
        int prefix = 1;

        for (int i = 0; i < n; i++) {

            result[i] = prefix;

            prefix *= nums[i];
        }

        // Suffix
        int suffix = 1;

        for (int i = n - 1; i >= 0; i--) {

            result[i] *= suffix;

            suffix *= nums[i];
        }

        return result;
    }

    public static void main(String[] args) {

        int[] nums = {1, 2, 3, 4};

        int[] result = productExceptSelf(nums);

        System.out.println(Arrays.toString(result));
    }
}
```

Output:

```text
[24, 12, 8, 6]
```

**Time:** O(n)
**Space:** O(1) **auxiliary space**, excluding the output array.
