## DSA – Strings: Interview Problems

Since you already know Java basics and are moving toward **Spring Boot/full-stack**, you don't need to learn every String trick. Focus on the patterns that repeatedly appear in coding interviews.

### 1. Reverse a String

**Pattern:** Two pointers / `StringBuilder`

```java
public class Main {
    public static void main(String[] args) {
        String str = "hello";

        String reversed = new StringBuilder(str).reverse().toString();

        System.out.println(reversed); // olleh
    }
}
```

**Time:** O(n)
**Space:** O(n)

without reverse

### 2. Check Palindrome

A palindrome reads the same forward and backward.

```java
public class Main {
    public static void main(String[] args) {
        String str = "madam";

        int left = 0;
        int right = str.length() - 1;

        boolean isPalindrome = true;

        while (left < right) {
            if (str.charAt(left) != str.charAt(right)) {
                isPalindrome = false;
                break;
            }

            left++;
            right--;
        }

        System.out.println(isPalindrome); // true
    }
}
```

**Pattern:** Two pointers
**Time:** O(n)
**Space:** O(1)

> ⭐ Very important interview problem.

### 3. Count Character Frequency

Example:

```text
Input:  "banana"

Output:
b -> 1
a -> 3
n -> 2
```

```java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        String str = "banana";

        Map<Character, Integer> frequency = new HashMap<>();

        for (char ch : str.toCharArray()) {
            frequency.put(ch, frequency.getOrDefault(ch, 0) + 1);
        }

        System.out.println(frequency);
    }
}
```

**Pattern:** HashMap
**Time:** O(n)
**Space:** O(k), where `k` = unique characters

> ⭐ Extremely important because this pattern is reused in many problems.

### 4. First Non-Repeating Character

```text
Input:  "swiss"

Output: 'w'
```

```java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        String str = "swiss";

        Map<Character, Integer> frequency = new HashMap<>();

        for (char ch : str.toCharArray()) {
            frequency.put(ch, frequency.getOrDefault(ch, 0) + 1);
        }

        for (char ch : str.toCharArray()) {
            if (frequency.get(ch) == 1) {
                System.out.println(ch);
                return;
            }
        }
    }
}
```

**Pattern:** Frequency Map + second traversal
**Time:** O(n)
**Space:** O(k)

> ⭐ Very common interview question.

### 5. Check Anagram

Two strings are anagrams if they contain the same characters with the same frequencies.

```text
Input:
"listen"
"silent"

Output:
true
```

```java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        String s1 = "listen";
        String s2 = "silent";

        if (s1.length() != s2.length()) {
            System.out.println(false);
            return;
        }

        Map<Character, Integer> map = new HashMap<>();

        for (char ch : s1.toCharArray()) {
            map.put(ch, map.getOrDefault(ch, 0) + 1);
        }

        for (char ch : s2.toCharArray()) {
            map.put(ch, map.get(ch) - 1);
        }

        boolean isAnagram = true;

        for (int count : map.values()) {
            if (count != 0) {
                isAnagram = false;
                break;
            }
        }

        System.out.println(isAnagram);
    }
}
```

**Pattern:** HashMap / frequency counting
**Time:** O(n)
**Space:** O(k)

> ⭐⭐⭐ Must know.

### 6. Remove Duplicate Characters

```text
Input:  "programming"

Output: "progamin"
```

```java
import java.util.HashSet;
import java.util.Set;

public class Main {
    public static void main(String[] args) {
        String str = "programming";

        Set<Character> seen = new HashSet<>();
        StringBuilder result = new StringBuilder();

        for (char ch : str.toCharArray()) {
            if (seen.add(ch)) {
                result.append(ch);
            }
        }

        System.out.println(result);
    }
}
```

**Pattern:** HashSet
**Time:** O(n)
**Space:** O(k)

### 7. Find Duplicate Characters

```text
Input: "programming"

Output:
r
g
m
```

```java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        String str = "programming";

        Map<Character, Integer> map = new HashMap<>();

        for (char ch : str.toCharArray()) {
            map.put(ch, map.getOrDefault(ch, 0) + 1);
        }

        for (Map.Entry<Character, Integer> entry : map.entrySet()) {
            if (entry.getValue() > 1) {
                System.out.println(entry.getKey());
            }
        }
    }
}
```

### 8. Reverse Words in a Sentence

```text
Input:
"I love Java"

Output:
"Java love I"
```

```java
public class Main {
    public static void main(String[] args) {
        String str = "I love Java";

        String[] words = str.split(" ");

        StringBuilder result = new StringBuilder();

        for (int i = words.length - 1; i >= 0; i--) {
            result.append(words[i]);

            if (i != 0) {
                result.append(" ");
            }
        }

        System.out.println(result);
    }
}
```

**Pattern:** String splitting + traversal

### 9. Longest Substring Without Repeating Characters

This is a **very important advanced String problem**.

```text
Input:  "abcabcbb"

Output: 3

Longest substring = "abc"
```

Use **Sliding Window + HashSet**.

```java
import java.util.HashSet;
import java.util.Set;

public class Main {
    public static void main(String[] args) {
        String str = "abcabcbb";

        Set<Character> set = new HashSet<>();

        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < str.length(); right++) {

            while (set.contains(str.charAt(right))) {
                set.remove(str.charAt(left));
                left++;
            }

            set.add(str.charAt(right));

            maxLength = Math.max(maxLength, right - left + 1);
        }

        System.out.println(maxLength); // 3
    }
}
```

**Pattern:** Sliding Window
**Time:** O(n)
**Space:** O(k)

> ⭐⭐⭐ Very important for product-company interviews.

### 10. Valid Parentheses

Although technically a **String + Stack** problem, you should know it.

```text
Input:  "({[]})"

Output: true
```

```java
import java.util.Stack;

public class Main {
    public static void main(String[] args) {
        String str = "({[]})";

        Stack<Character> stack = new Stack<>();

        for (char ch : str.toCharArray()) {

            if (ch == '(' || ch == '{' || ch == '[') {
                stack.push(ch);
            } else {

                if (stack.isEmpty()) {
                    System.out.println(false);
                    return;
                }

                char top = stack.pop();

                if ((ch == ')' && top != '(') ||
                    (ch == '}' && top != '{') ||
                    (ch == ']' && top != '[')) {

                    System.out.println(false);
                    return;
                }
            }
        }

        System.out.println(stack.isEmpty());
    }
}
```

**Pattern:** Stack
**Time:** O(n)
**Space:** O(n)

# Interview Pattern You Should Master

For **String DSA**, don't memorize 50 problems. Master these patterns:

| Pattern        | Problems                                |
| -------------- | --------------------------------------- |
| Two Pointers   | Reverse, Palindrome                     |
| HashMap        | Frequency, Anagram, First Non-Repeating |
| HashSet        | Remove duplicates                       |
| Sliding Window | Longest substring                       |
| Stack          | Valid parentheses                       |
| StringBuilder  | Efficient string modification           |
| Sorting        | Anagram / grouping problems             |
