## DSA – Hashing: HashMap Applications

Since you already know JavaScript/React, think of Java `HashMap` as roughly equivalent to a JavaScript `Map`.

### 1. What is a HashMap?

A `HashMap<K, V>` stores **key → value** pairs.

```java
HashMap<String, Integer> map = new HashMap<>();

map.put("Alice", 25);
map.put("Bob", 30);

System.out.println(map.get("Alice")); // 25
```

Typical complexity:

| Operation       | Average |
| --------------- | ------: |
| `put()`         |    O(1) |
| `get()`         |    O(1) |
| `containsKey()` |    O(1) |
| `remove()`      |    O(1) |

# Main HashMap Applications in DSA

These are the important patterns you should learn.

### 1. Frequency Counting

**Problem:** Count how many times each number appears.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        int[] nums = {1, 2, 2, 3, 1, 2, 4};

        HashMap<Integer, Integer> frequency = new HashMap<>();

        for (int num : nums) {
            frequency.put(num, frequency.getOrDefault(num, 0) + 1);
        }

        System.out.println(frequency);
    }
}
```

Output:

```text
{1=2, 2=3, 3=1, 4=1}
```

### Key pattern

```java
map.put(key, map.getOrDefault(key, 0) + 1);
```

This pattern is **extremely important in DSA**.

# 2. Find Duplicate

**Problem:** Find whether an array contains duplicates.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        int[] nums = {10, 20, 30, 20};

        HashMap<Integer, Integer> map = new HashMap<>();

        for (int num : nums) {

            if (map.containsKey(num)) {
                System.out.println("Duplicate: " + num);
                return;
            }

            map.put(num, 1);
        }

        System.out.println("No duplicates");
    }
}
```

Output:

```text
Duplicate: 20
```

However, for **only checking duplicates**, `HashSet` is more appropriate:

```java
Set<Integer> set = new HashSet<>();
```

Use `HashMap` when you need associated information such as frequency/index.

# 3. Two Sum — Very Important

**Problem:** Find two numbers whose sum equals `target`.

Example:

```text
nums = [2, 7, 11, 15]
target = 9

2 + 7 = 9
```

### HashMap approach

Store:

```text
number → index
```

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        int[] nums = {2, 7, 11, 15};
        int target = 9;

        HashMap<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {

            int required = target - nums[i];

            if (map.containsKey(required)) {
                System.out.println(
                    "Indexes: " + map.get(required) + ", " + i
                );
                return;
            }

            map.put(nums[i], i);
        }
    }
}
```

Output:

```text
Indexes: 0, 1
```

### Why HashMap?

Without HashMap:

```text
Check every pair → O(n²)
```

With HashMap:

```text
Lookup required value → O(1)
Overall → O(n)
```

This is one of the most important HashMap DSA patterns.

# 4. First Non-Repeating Character

**Problem:**

```text
"swiss"
```

Find the first character that occurs only once.

Frequency:

```text
s → 3
w → 1
i → 1
```

Answer:

```text
w
```

### Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        String str = "swiss";

        HashMap<Character, Integer> map = new HashMap<>();

        // Count frequency
        for (char ch : str.toCharArray()) {
            map.put(ch, map.getOrDefault(ch, 0) + 1);
        }

        // Find first character with frequency 1
        for (char ch : str.toCharArray()) {
            if (map.get(ch) == 1) {
                System.out.println("First non-repeating: " + ch);
                return;
            }
        }
    }
}
```

Output:

```text
First non-repeating: w
```

### Important pattern

This is a **two-pass HashMap pattern**:

```text
Pass 1 → build frequency
Pass 2 → find answer
```

# 5. Character/Element Mapping

HashMap is useful when you need to associate one thing with another.

For example:

```text
Employee ID → Employee name
```

```java
HashMap<Integer, String> employees = new HashMap<>();

employees.put(101, "John");
employees.put(102, "David");
employees.put(103, "Sam");

System.out.println(employees.get(102));
```

Output:

```text
David
```

In DSA this becomes:

```text
value → index
value → frequency
character → count
character → index
number → number
```

# 6. Store Last Seen Index

This is heavily used with **sliding window** problems.

Example:

**Longest substring without repeating characters**

```text
abcabcbb
```

HashMap:

```text
character → last index
```

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        String s = "abcabcbb";

        HashMap<Character, Integer> map = new HashMap<>();

        int left = 0;
        int maxLength = 0;

        for (int right = 0; right < s.length(); right++) {

            char ch = s.charAt(right);

            if (map.containsKey(ch)) {
                left = Math.max(left, map.get(ch) + 1);
            }

            map.put(ch, right);

            maxLength = Math.max(maxLength, right - left + 1);
        }

        System.out.println(maxLength);
    }
}
```

Output:

```text
3
```

Because:

```text
abc
```

is the longest substring without repeating characters.

### Important pattern

```java
map.put(ch, right);
```

means:

> Remember the **latest index** where this character appeared.

# 7. Grouping / Categorization

HashMap can map one key to multiple values.

For example:

```text
character → list of words
```

This is useful for **Group Anagrams**.

```java
HashMap<String, List<String>> map = new HashMap<>();

map.computeIfAbsent("aet", k -> new ArrayList<>())
   .add("eat");

map.computeIfAbsent("aet", k -> new ArrayList<>())
   .add("tea");
```

Result conceptually:

```text
"aet" → ["eat", "tea"]
```

This pattern is very important:

```java
map.computeIfAbsent(key, k -> new ArrayList<>()).add(value);
```

# The 5 HashMap patterns you should memorize

For DSA, these are more important than simply knowing the API.

### Pattern 1 — Frequency

```java
map.put(x, map.getOrDefault(x, 0) + 1);
```

Used for:

* Frequency count
* Majority element
* Anagrams
* Duplicate analysis

### Pattern 2 — Existence

```java
if (map.containsKey(x)) {
    // found
}
```

### Pattern 3 — Value → Index

```java
map.put(value, index);
```

Used for:

* Two Sum
* Pair problems
* Last occurrence

### Pattern 4 — Last Seen Index

```java
map.put(character, index);
```

Used heavily with:

* Sliding Window
* Longest substring problems

### Pattern 5 — Key → List

```java
map.computeIfAbsent(key, k -> new ArrayList<>())
   .add(value);
```

Used for:

* Grouping
* Group Anagrams
* Categorization problems

## HashMap vs HashSet

A simple way to remember:

```text
HashSet
   ↓
"I only care whether it exists"

HashMap
   ↓
"I need information associated with it"
```

Example:

```java
Set<Integer> set = new HashSet<>();
```

> Have I seen `10`?

Whereas:

```java
Map<Integer, Integer> map = new HashMap<>();
```

> How many times did I see `10`?

or:

> At which index did I see `10`?

## DSA Interview Recognition Trick

When you see these words in a problem, immediately consider `HashMap`:

```text
frequency
count
duplicate
unique
first occurrence
last occurrence
index
pair
complement
seen before
group
mapping
```

The most important progression for you should be:

**Frequency Count → Two Sum → First Non-Repeating Character → Longest Substring → Group Anagrams → Subarray Sum Equals K.**

The last one, **Subarray Sum Equals K**, is where HashMap becomes particularly powerful because it combines hashing with **prefix sums**.
