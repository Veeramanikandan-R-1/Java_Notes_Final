## Linear Search in a Sorted Array

Linear search checks each element one by one until the target is found. Even if the array is sorted, linear search works the same way as it does on an unsorted array.

### Java example (fully working)

```
public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40, 50};
        int target = 30;

        int result = -1;

        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == target) {
                result = i;
                break;
            }

            // Optimization for sorted arrays
            if (arr[i] > target) {
                break;
            }
        }

        if (result != -1) {
            System.out.println("Found at index: " + result);
        } else {
            System.out.println("Not found");
        }
    }
}
```

### How it works

For `target = 30`:

- Index 0 → `10`, continue.
- Index 1 → `20`, continue.
- Index 2 → `30`, found; stop.

Output: `Found at index: 2`

Why check `arr[i] > target`?

Because the array is sorted in ascending order, once an element exceeds the target, the target cannot appear later. So we can stop early.

### Complexity

- Best case: \\(O(1)\\) — target is the first element.
- Worst case: \\(O(n)\\) — target is last or absent.
- Space complexity: \\(O(1)\\) — only a few extra variables.

DSA interview tip: For a sorted array, consider binary search, which takes \\(O(\log n)\\) time in the worst case.
