## Selection Sort

Definition: Selection Sort repeatedly finds the smallest element in the unsorted portion and swaps it with the first unsorted element.

### Full working Java code

```
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {5, 3, 8, 2, 1};

        for (int i = 0; i < arr.length - 1; i++) {
            int minIndex = i;

            for (int j = i + 1; j < arr.length; j++) {
                if (arr[j] < arr[minIndex]) {
                    minIndex = j;
                }
            }

            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }

        System.out.println(Arrays.toString(arr));
    }
}
```

Output: `[1, 2, 3, 5, 8]`

### Selection Sort vs Bubble Sort

| Feature     | Selection Sort                            | Bubble Sort                                    |
| ----------- | ----------------------------------------- | ---------------------------------------------- |
| Approach    | Finds the minimum and swaps once per pass | Compares adjacent elements and swaps as needed |
| Swaps       | At most \\(n-1\\)                         | Can be many                                    |
| Comparisons | \\(O(n^2)\\)                              | \\(O(n^2)\\)                                   |
| Space       | \\(O(1)\\)                                | \\(O(1)\\)                                     |
| Stable?     | No, generally                             | Yes, with `>` comparison                       |

Key difference: Selection Sort minimizes swaps; Bubble Sort moves elements through repeated adjacent swaps.

## Selection Sort

Selection Sort repeatedly finds the smallest element in the unsorted portion of an array and swaps it with the first element of that portion.

### How it works

Initial array: `[5, 3, 8, 2, 1]`

Pass 1: `i = 0`

- Assume `5` is the minimum (`minIndex = 0`).
- Compare it with `3`, `8`, `2`, and `1`.
- The smallest element is `1`, at index `4`.
- Swap `arr[0]` and `arr[4]`.

Array: `[1, 3, 8, 2, 5]`

Pass 2: `i = 1`

- The first element, `1`, is already sorted.
- Find the minimum from `[3, 8, 2, 5]`.
- The minimum is `2`, at index `3`.
- Swap `arr[1]` and `arr[3]`.

Array: `[1, 2, 8, 3, 5]`

Pass 3: `i = 2`

- The sorted portion is `[1, 2]`.
- Find the minimum from `[8, 3, 5]`.
- The minimum is `3`, at index `3`.
- Swap `arr[2]` and `arr[3]`.

Array: `[1, 2, 3, 8, 5]`

Pass 4: `i = 3`

- The sorted portion is `[1, 2, 3]`.
- Find the minimum from `[8, 5]`.
- The minimum is `5`, at index `4`.
- Swap `arr[3]` and `arr[4]`.

Array: `[1, 2, 3, 5, 8]`

Final output:

```
[1, 2, 3, 5, 8]
```

### Important code logic

```
int minIndex = i;

for (int j = i + 1; j < arr.length; j++) {
    if (arr[j] < arr[minIndex]) {
        minIndex = j;
    }
}

int temp = arr[i];
arr[i] = arr[minIndex];
arr[minIndex] = temp;
```

- `minIndex = i`: Initially assumes the first unsorted element is the minimum.
- Inner `for` loop: Searches the remaining unsorted elements for a smaller value.
- `minIndex = j`: Updates the index whenever a smaller element is found.
- `temp` and swap statements: Place the minimum element at the current position.

### Complexity

- Best-case time: \\(O(n^2)\\)
- Average-case time: \\(O(n^2)\\)
- Worst-case time: \\(O(n^2)\\)
- Auxiliary space: \\(O(1)\\)

Remember: Selection Sort performs at most \\(n-1\\) passes and makes at most \\(n-1\\) swaps. Unlike Insertion Sort, it searches the entire unsorted portion for the minimum before swapping.
