# Merge Sort in Java

## 1. What is Merge Sort?

Merge Sort is a sorting algorithm that uses the Divide and Conquer technique.

It works in three steps:

1. Divide: Split the array into smaller subarrays until each contains only one element.
2. Conquer: Merge the subarrays back together in sorted order.
3. Combine: Continue merging until the entire array becomes sorted.

Unlike Quick Sort, which partitions elements around a pivot, Merge Sort divides the array into halves and then merges sorted halves.

## 2. How Merge Sort Works

Consider this array:

```
int[] arr = {38, 12, 27, 43, 9, 31, 18};
```

### Step 1: Divide the array

Keep splitting the array into smaller parts.

```
[38, 12, 27, 43, 9, 31, 18]

          /                 \
[38, 12, 27, 43]          [9, 31, 18]

       /       \              /      \
[38, 12]    [27, 43]       [9, 31]  [18]

  /   \       /   \          /   \
[38] [12]   [27] [43]       [9] [31]
```

Every single-element array is already sorted.

### Step 2: Merge in sorted order

Compare elements from each pair and merge them in ascending order.

```
[38] + [12]  → [12, 38]
[27] + [43]  → [27, 43]
[9]  + [31]  → [9, 31]
```

Continue merging the sorted subarrays:

```
[12, 38] + [27, 43]
→ [12, 27, 38, 43]

[9, 31] + [18]
→ [9, 18, 31]
```

### Step 3: Final merge

Merge the two sorted subarrays:

```
[12, 27, 38, 43] + [9, 18, 31]
```

Compare the first available elements and pick the smaller one each time:

```
9 → 12 → 18 → 27 → 31 → 38 → 43
```

Final sorted array:

```
[9, 12, 18, 27, 31, 38, 43]
```

## 3. Complete Java Implementation

This implementation uses two methods:

- `mergeSort()` — divides the array recursively.
- `merge()` — combines two sorted subarrays.

```
import java.util.Arrays;

public class Main {

    static void mergeSort(int[] arr, int left, int right) {

        // Base condition: one or zero elements
        if (left >= right) {
            return;
        }

        int mid = left + (right - left) / 2;

        // Sort left half
        mergeSort(arr, left, mid);

        // Sort right half
        mergeSort(arr, mid + 1, right);

        // Merge both sorted halves
        merge(arr, left, mid, right);
    }

    static void merge(int[] arr, int left, int mid, int right) {

        int n1 = mid - left + 1;
        int n2 = right - mid;

        int[] leftArr = new int[n1];
        int[] rightArr = new int[n2];

        // Copy elements into temporary arrays
        for (int i = 0; i < n1; i++) {
            leftArr[i] = arr[left + i];
        }

        for (int j = 0; j < n2; j++) {
            rightArr[j] = arr[mid + 1 + j];
        }

        int i = 0;
        int j = 0;
        int k = left;

        // Compare and merge in sorted order
        while (i < n1 && j < n2) {

            if (leftArr[i] <= rightArr[j]) {
                arr[k] = leftArr[i];
                i++;
            } else {
                arr[k] = rightArr[j];
                j++;
            }

            k++;
        }

        // Copy remaining elements from left array
        while (i < n1) {
            arr[k] = leftArr[i];
            i++;
            k++;
        }

        // Copy remaining elements from right array
        while (j < n2) {
            arr[k] = rightArr[j];
            j++;
            k++;
        }
    }

    public static void main(String[] args) {

        int[] arr = {38, 12, 27, 43, 9, 31, 18};

        mergeSort(arr, 0, arr.length - 1);

        System.out.println(Arrays.toString(arr));
    }
}
```

Output:

```
[9, 12, 18, 27, 31, 38, 43]
```

## 4. Understanding the Important Parts

### A. `mergeSort()` method

```
int mid = left + (right - left) / 2;

mergeSort(arr, left, mid);
mergeSort(arr, mid + 1, right);

merge(arr, left, mid, right);
```

- `mid` calculates the middle index.
- The first recursive call sorts the left half.
- The second recursive call sorts the right half.
- `merge()` combines both sorted halves.

The condition `if (left >= right)` stops recursion when the subarray contains zero or one element.

### B. `merge()` method

```
while (i < n1 && j < n2) {
    if (leftArr[i] <= rightArr[j]) {
        arr[k] = leftArr[i];
        i++;
    } else {
        arr[k] = rightArr[j];
        j++;
    }
    k++;
}
```

Here:

- `i` tracks the current element in the left temporary array.
- `j` tracks the current element in the right temporary array.
- `k` tracks the position where the next sorted element is written in the original array.

The smaller element is copied into the original array first.

Why do we need the two remaining `while` loops?

The first comparison loop stops when either temporary array is exhausted. The other array may still contain elements, so we must copy those remaining elements into the original array.

## 5. Time and Space Complexity

| Case    | Time Complexity |
| ------- | --------------- |
| Best    | O(n log n)      |
| Average | O(n log n)      |
| Worst   | O(n log n)      |

Space complexity: O(n) auxiliary space for the temporary arrays.

Merge Sort maintains O(n log n) time complexity even when the input is already sorted or in reverse order.

## 6. Quick Sort vs Merge Sort

| Feature      | Quick Sort                       | Merge Sort                   |
| ------------ | -------------------------------- | ---------------------------- |
| Approach     | Partition around a pivot         | Divide into halves and merge |
| Best time    | O(n log n)                       | O(n log n)                   |
| Average time | O(n log n)                       | O(n log n)                   |
| Worst time   | O(n²)                            | O(n log n)                   |
| Extra space  | O(log n) average recursion stack | O(n) for arrays              |
| Stable       | No, in the usual implementation  | Yes, with stable merging     |
| In-place     | Generally yes                    | Generally no, for arrays     |

## 7. Important Interview Points

1. Merge Sort uses Divide and Conquer.
2. It recursively divides the array until each subarray contains one element.
3. The `merge()` method combines two sorted subarrays.
4. Its time complexity is O(n log n) in all three cases.
5. Standard array-based Merge Sort requires O(n) auxiliary space.
6. Merge Sort is stable when equal elements are merged in their original relative order. Using `<=` for the left-side comparison helps preserve that order.

Remember: Quick Sort focuses on partitioning around a pivot; Merge Sort focuses on dividing the array and merging sorted subarrays.
