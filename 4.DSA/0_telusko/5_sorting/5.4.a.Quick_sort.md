# Quick Sort in Java

## 1. What is Quick Sort?

Quick Sort is a sorting algorithm that uses the Divide and Conquer technique.

It works by selecting an element called a pivot and rearranging the array:

- Elements smaller than the pivot move to the left.
- Elements greater than the pivot move to the right.
- The pivot reaches its correct sorted position.
- Recursively sort the left and right subarrays.

## 2. How Quick Sort Works

Consider the following array:

```
int[] arr = {8, 3, 1, 7, 0, 10, 2};
```

We will use the last element as the pivot.

Step 1: First partition

```
Array: [8, 3, 1, 7, 0, 10, 2]
Pivot: 2
```

Move elements smaller than 2 to the left.

- Smaller elements: 1, 0
- Greater elements: 8, 3, 7, 10

After partitioning:

```
[1, 0, 2, 7, 8, 10, 3]
       ↑
     Pivot
```

Pivot `2` is now in its correct sorted position (index 2).

Step 2: Sort the left subarray

```
[1, 0]
```

Pivot = 0

After partitioning:

```
[0, 1, 2, 7, 8, 10, 3]
```

Step 3: Sort the right subarray

```
[7, 8, 10, 3]
```

Pivot = 3

After partitioning:

```
[0, 1, 2, 3, 8, 10, 7]
```

Step 4: Continue recursively

Sort the remaining subarray:

```
[8, 10, 7]
```

Pivot = 7

After partitioning:

```
[0, 1, 2, 3, 7, 10, 8]
```

Continue sorting `[10, 8]`.

Final sorted array:

```
[0, 1, 2, 3, 7, 8, 10]
```

## 3. Complete Java Implementation

We use the Lomuto Partition Scheme, where the last element is selected as the pivot.

```
import java.util.Arrays;

public class Main {

    static void quickSort(int[] arr, int low, int high) {

        if (low < high) {

            // Get pivot's correct position
            int pivotIndex = partition(arr, low, high);

            // Sort left subarray
            quickSort(arr, low, pivotIndex - 1);

            // Sort right subarray
            quickSort(arr, pivotIndex + 1, high);
        }
    }

    static int partition(int[] arr, int low, int high) {

        int pivot = arr[high];
        int i = low - 1;

        for (int j = low; j < high; j++) {

            if (arr[j] < pivot) {

                i++;

                int temp = arr[i];
                arr[i] = arr[j];
                arr[j] = temp;
            }
        }

        // Place pivot in its correct position
        int temp = arr[i + 1];
        arr[i + 1] = arr[high];
        arr[high] = temp;

        return i + 1;
    }

    public static void main(String[] args) {

        int[] arr = {8, 3, 1, 7, 0, 10, 2};

        quickSort(arr, 0, arr.length - 1);

        System.out.println(Arrays.toString(arr));
    }
}
```

Output:

```
[0, 1, 2, 3, 7, 8, 10]
```

## 4. Understanding the Partition Method

This is the most important part of Quick Sort.

```
int pivot = arr[high];
int i = low - 1;

for (int j = low; j < high; j++) {

    if (arr[j] < pivot) {

        i++;

        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }
}
```

What do `i` and `j` represent?

- `i` → Tracks the position where the next smaller element should be placed.
- `j` → Iterates through the array and compares elements with the pivot.

After the loop:

```
int temp = arr[i + 1];
arr[i + 1] = arr[high];
arr[high] = temp;

return i + 1;
```

We swap the pivot with the element at `i + 1`.

Now the pivot is in its correct sorted position.

Important: We exclude the pivot from subsequent recursive calls because it is already in its final position.

## 5. Time and Space Complexity

| Case    | Time Complexity | Reason                                |
| ------- | --------------- | ------------------------------------- |
| Best    | O(n log n)      | Pivot divides array into equal halves |
| Average | O(n log n)      | Reasonably balanced partitions        |
| Worst   | O(n²)           | Highly unbalanced partitions          |

Space Complexity:

- Average: O(log n) – recursive call stack.
- Worst: O(n) – highly unbalanced recursion.
- Partition operation: O(1) auxiliary space.

## 6. Important Interview Points

1. Quick Sort uses Divide and Conquer.
2. It is generally an in-place sorting algorithm.
3. It is not a stable sorting algorithm.
4. Pivot selection affects performance.
5. Worst case occurs when partitions are repeatedly unbalanced.
6. Randomized pivot selection helps reduce the likelihood of worst-case performance.

## 7. Quick Sort vs Merge Sort

| Feature      | Quick Sort         | Merge Sort                |
| ------------ | ------------------ | ------------------------- |
| Technique    | Divide and Conquer | Divide and Conquer        |
| Best time    | O(n log n)         | O(n log n)                |
| Average time | O(n log n)         | O(n log n)                |
| Worst time   | O(n²)              | O(n log n)                |
| Extra space  | O(log n) average   | O(n) for arrays           |
| Stable       | No                 | Yes                       |
| In-place     | Generally yes      | Generally no (for arrays) |

Remember:

- Quick Sort → Select pivot, partition, recursively sort.
- Merge Sort → Divide into halves, recursively sort, merge.

Interview tip: Focus on understanding the `partition()` method, especially how `i`, `j`, and `pivot` work. This is the core of Quick Sort.
