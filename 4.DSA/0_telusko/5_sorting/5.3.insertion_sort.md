## Insertion Sort

Definition: Insertion Sort builds a sorted portion of the array one element at a time by inserting each element into its correct position.

### How it works

Consider the array: `[5, 3, 8, 2, 1]`

1. Start with `5` as the sorted portion.
2. Take `3`; shift `5` right and insert `3` → `[3, 5, 8, 2, 1]`
3. Take `8`; it is already in the correct position → `[3, 5, 8, 2, 1]`
4. Take `2`; shift larger elements right and insert `2` → `[2, 3, 5, 8, 1]`
5. Take `1`; shift all larger elements right and insert `1` → `[1, 2, 3, 5, 8]`

### Full working Java code

```
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {5, 3, 8, 2, 1};

        for (int i = 1; i < arr.length; i++) {
            int key = arr[i];
            int j = i - 1;

            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }

            arr[j + 1] = key;
        }

        System.out.println(Arrays.toString(arr));
    }
}
```

Output: `[1, 2, 3, 5, 8]`

### Important points

- `key`: The element to insert into the sorted portion.
- `j`: Checks elements to the left of the key.
- `while`: Shifts larger elements one position to the right.
- `arr[j + 1] = key`: Inserts the key in its correct position.

### Time and space complexity

| Case                        | Complexity   |
| --------------------------- | ------------ |
| Best case (already sorted)  | \\(O(n)\\)   |
| Average case                | \\(O(n^2)\\) |
| Worst case (reverse sorted) | \\(O(n^2)\\) |
| Auxiliary space             | \\(O(1)\\)   |

Key difference: Unlike Selection Sort, which finds the minimum each pass, Insertion Sort inserts each element into an already-sorted portion. It is efficient for small or nearly sorted arrays and is stable when using `arr[j] > key`.

## Insertion Sort

Your code implements Insertion Sort, not Selection Sort. It sorts an array by taking one element at a time and inserting it into its correct position in the already-sorted portion.

### How it works

Initial array: `[5, 3, 8, 2, 1]`

Pass 1: `i = 1`, `key = 3`

- Compare `3` with `5`.
- Since `5 > 3`, shift `5` one position to the right.
- Insert `3` at index `0`.

Array: `[3, 5, 8, 2, 1]`

Pass 2: `i = 2`, `key = 8`

- Compare `8` with `5`.
- Since `5 < 8`, no shifting is required.

Array: `[3, 5, 8, 2, 1]`

Pass 3: `i = 3`, `key = 2`

- Compare `2` with `8`, `5`, and `3`.
- All these elements are greater than `2`, so shift them one position to the right.
- Insert `2` at index `0`.

Array: `[2, 3, 5, 8, 1]`

Pass 4: `i = 4`, `key = 1`

- Compare `1` with `8`, `5`, `3`, and `2`.
- Shift all four elements one position to the right.
- Insert `1` at index `0`.

Array: `[1, 2, 3, 5, 8]`

### Important code logic

```
int key = arr[i];
int j = i - 1;

while (j >= 0 && arr[j] > key) {
    arr[j + 1] = arr[j];
    j--;
}

arr[j + 1] = key;
```

- `key`: Stores the element to be inserted.
- `j = i - 1`: Starts comparing with the element immediately to the left.
- `arr[j] > key`: Checks whether the current element is greater than the key. If true, shift it right.
- `arr[j + 1] = key`: Inserts the key into its correct position.

### Complexity

- Best-case time: \\(O(n)\\) — array is already sorted.
- Average-case time: \\(O(n^2)\\).
- Worst-case time: \\(O(n^2)\\) — array is sorted in reverse order.
- Auxiliary space: \\(O(1)\\) — sorting is done in place.

Remember: Insertion Sort inserts each element into the correct position in the sorted portion. Selection Sort finds the minimum element in the unsorted portion and swaps it into position.
