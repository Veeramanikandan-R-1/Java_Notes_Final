## Tree in DSA

A Tree is a non-linear data structure that stores elements in a hierarchical relationship using nodes connected by edges.

### 1. Important Terminologies

| Term    | Meaning                                                   |
| ------- | --------------------------------------------------------- |
| Root    | Topmost node of the tree                                  |
| Parent  | A node that has child nodes                               |
| Child   | A node connected below another node                       |
| Leaf    | A node with no children                                   |
| Edge    | Connection between two nodes                              |
| Subtree | A node and its descendants                                |
| Height  | Number of edges on the longest path from a node to a leaf |
| Depth   | Number of edges from the root to a node                   |

### 2. Types of Trees

- General Tree: A node can have any number of children.
- Binary Tree: Each node can have at most two children.
- Binary Search Tree (BST): Left subtree values are smaller than the node; right subtree values are greater, assuming distinct values.
- Balanced Tree: Maintains a controlled height to support efficient operations, such as AVL trees.
- Heap: A complete binary tree that follows a min-heap or max-heap property.

### 3. Binary Tree — Own Implementation in Java

Each node contains data and references to its left and right children.

```
class Node {
    int data;
    Node left;
    Node right;

    Node(int data) {
        this.data = data;
    }
}

public class Main {
    public static void main(String[] args) {
        Node root = new Node(10);

        root.left = new Node(5);
        root.right = new Node(20);

        root.left.left = new Node(3);
        root.left.right = new Node(7);

        System.out.println(root.data);           // 10
        System.out.println(root.left.data);      // 5
        System.out.println(root.right.data);     // 20
        System.out.println(root.left.left.data); // 3
    }
}
```

This creates a binary tree manually. It is not automatically a BST; the ordering rules must be maintained when inserting nodes.

### 4. Tree Traversals

Traversal means visiting every node in a specific order.

Consider the tree constructed in the code above.

| Traversal   | Order               | Output        |
| ----------- | ------------------- | ------------- |
| Preorder    | Root → Left → Right | `10 5 3 7 20` |
| Inorder     | Left → Root → Right | `3 5 7 10 20` |
| Postorder   | Left → Right → Root | `3 7 5 20 10` |
| Level order | Level by level      | `10 5 20 3 7` |

For a BST, inorder traversal produces values in sorted order, assuming distinct values.

### 5. Time Complexity

For a tree with `n` nodes:

| Operation                       | Complexity |
| ------------------------------- | ---------- |
| Traverse all nodes              | O(n)       |
| Search in a general binary tree | O(n)       |
| Search in a balanced BST        | O(log n)   |
| Search in a skewed BST          | O(n)       |

### Key takeaway

A tree is the foundational data structure for understanding Binary Search Trees, AVL Trees, Heaps, Tries, and Tree Traversals. For DSA practice, learn binary tree implementation and traversals first, then move to BST insertion, search, and deletion.
