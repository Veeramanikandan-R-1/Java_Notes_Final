# Dynamic Stack in Java (DSA)

## 1. What is a Dynamic Stack?

A Dynamic Stack is a stack whose capacity automatically increases when it becomes full.

It follows LIFO (Last In, First Out), just like a normal stack.

For example, suppose the initial capacity is `2`.

Initially:

```
Array:    [10, 20]
Size:       2
Capacity:   2
```

When you push `30`, the array is full. The stack creates a larger array, copies the existing elements, and inserts the new value.

```
Before expansion: [10, 20]
After expansion:  [10, 20, 30, _]
Capacity:          4
```

A common approach is to double the capacity whenever the array becomes full.

## 2. Complete Java Implementation

This implementation uses an array and automatically expands its capacity.

```
import java.util.Arrays;

class DynamicStack {

    private int[] arr;
    private int top;
    private int capacity;

    public DynamicStack() {
        capacity = 2;
        arr = new int[capacity];
        top = 0; // Number of elements in the stack
    }

    private void expand() {
        capacity *= 2;

        int[] newArr = new int[capacity];

        System.arraycopy(arr, 0, newArr, 0, top);

        arr = newArr;
    }

    public void push(int value) {
        if (top == capacity) {
            expand();
        }

        arr[top] = value;
        top++;
    }

    public int pop() {
        if (top == 0) {
            throw new IllegalStateException("Stack is empty");
        }

        int value = arr[--top];
        arr[top] = 0;

        return value;
    }

    public int peek() {
        if (top == 0) {
            throw new IllegalStateException("Stack is empty");
        }

        return arr[top - 1];
    }

    public boolean isEmpty() {
        return top == 0;
    }

    public int size() {
        return top;
    }

    public int getCapacity() {
        return capacity;
    }

    public void display() {
        System.out.println(
            Arrays.toString(Arrays.copyOf(arr, top))
        );
    }
}

public class Main {

    public static void main(String[] args) {

        DynamicStack stack = new DynamicStack();

        stack.push(10);
        stack.push(20);

        stack.display();
        System.out.println("Capacity: " + stack.getCapacity());

        stack.push(30); // Triggers expansion

        stack.display();
        System.out.println("Capacity: " + stack.getCapacity());

        System.out.println("Popped: " + stack.pop());
        System.out.println("Top: " + stack.peek());
        System.out.println("Size: " + stack.size());
    }
}
```

Output:

```
[10, 20]
Capacity: 2
[10, 20, 30]
Capacity: 4
Popped: 30
Top: 20
Size: 2
```

## 3. Understand the Important Logic

### A. How does expansion work?

```
private void expand() {
    capacity *= 2;

    int[] newArr = new int[capacity];

    System.arraycopy(arr, 0, newArr, 0, top);

    arr = newArr;
}
```

1. Double the capacity.
2. Create a new, larger array.
3. Copy the existing stack elements into it.
4. Make `arr` reference the new array.

The old array becomes eligible for garbage collection when no references to it remain.

### B. Why use `top == capacity`?

```
if (top == capacity) {
    expand();
}
```

Here, `top` represents the number of elements, not the index of the top element.

For a capacity of `2`:

- After one push: `top = 1`
- After two pushes: `top = 2` — the array is full.
- Before the third push, expand the array.

### C. What is the complexity?

| Operation                      | Time complexity       |
| ------------------------------ | --------------------- |
| `push()`                       | O(1) amortized        |
| `push()` when expansion occurs | O(n)                  |
| `pop()`                        | O(1)                  |
| `peek()`                       | O(1)                  |
| `expand()`                     | O(n)                  |
| Space                          | O(n) for capacity `n` |

Why is `push()` O(1) amortized? Most pushes take constant time. Although occasional expansions take O(n), doubling the capacity makes the average cost per push O(1) over a sequence of operations.

## 4. Interview Points

- A dynamic stack automatically grows when full.
- Doubling capacity is a common strategy, not the only possible strategy.
- `System.arraycopy()` copies elements efficiently.
- `top` tracks the current number of elements in this implementation.
- A dynamic stack avoids fixed-capacity overflow, but it can still fail if memory allocation is unsuccessful.

Remember: A dynamic stack is not a different stack principle. It still follows LIFO; only its storage capacity grows automatically.

## with shrink

To implement shrink functionality in your dynamic stack, reduce the array capacity when the stack becomes sufficiently empty.

A common approach is to shrink the capacity to half when the number of elements becomes one-quarter or less of the capacity. This avoids repeatedly expanding and shrinking when elements are pushed and popped around the same threshold.

## Complete Java implementation (expand + shrink)

```

import java.util.Arrays;

class DynamicStack {

    private int[] arr;
    private int top;
    private int capacity;

    private static final int INITIAL_CAPACITY = 2;

    public DynamicStack() {
        capacity = INITIAL_CAPACITY;
        arr = new int[capacity];
        top = 0;
    }

    private void expand() {
        capacity *= 2;
        arr = Arrays.copyOf(arr, capacity);
    }

    private void shrink() {
        if (capacity > INITIAL_CAPACITY && top <= capacity / 4) {
            capacity = Math.max(INITIAL_CAPACITY, capacity / 2);
            arr = Arrays.copyOf(arr, capacity);
        }
    }

    public void push(int value) {
        if (top == capacity) {
            expand();
        }

        arr[top++] = value;
    }

    public int pop() {
        if (top == 0) {
            throw new IllegalStateException("Stack is empty");
        }

        int value = arr[--top];
        arr[top] = 0;

        shrink();

        return value;
    }

    public int peek() {
        if (top == 0) {
            throw new IllegalStateException("Stack is empty");
        }

        return arr[top - 1];
    }

    public int size() {
        return top;
    }

    public int getCapacity() {
        return capacity;
    }

    public void display() {
        System.out.println(Arrays.toString(Arrays.copyOf(arr, top)));
    }
}

public class Main {

    public static void main(String[] args) {

        DynamicStack stack = new DynamicStack();

        // Expand
        for (int i = 1; i <= 8; i++) {
            stack.push(i);
        }

        stack.display();
        System.out.println("Capacity: " + stack.getCapacity());

        // Pop elements and shrink automatically
        while (stack.size() > 0) {
            System.out.println("Popped: " + stack.pop());
            System.out.println("Size: " + stack.size()
                    + ", Capacity: " + stack.getCapacity());
        }
    }
}

```

## How shrinking works

Suppose the stack has a capacity of `8`.

| Number of elements (`top`) | Capacity before pop | Shrink condition after pop | Resulting capacity |
| -------------------------- | ------------------- | -------------------------- | ------------------ |
| 3                          | 8                   | `top = 2`, which is ≤ 2    | 4                  |
| 1                          | 4                   | `top = 0`, which is ≤ 1    | 2                  |
| 0                          | 2                   | Minimum capacity reached   | 2                  |

The `shrink()` method is called after every successful `pop()`.

```
if (capacity > INITIAL_CAPACITY && top <= capacity / 4) {
    capacity = Math.max(INITIAL_CAPACITY, capacity / 2);
    arr = Arrays.copyOf(arr, capacity);
}
```

- `top <= capacity / 4` checks whether the stack is sufficiently empty.
- `capacity / 2` halves the capacity.
- `Math.max()` prevents the capacity from going below the initial capacity of `2`.
- `Arrays.copyOf()` resizes the array while preserving the existing elements.

Complexity: `pop()` remains O(1) amortized, although a pop that triggers shrinking takes O(n) time.
