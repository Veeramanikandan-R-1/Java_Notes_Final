## Abstract Data Type (ADT) in DSA

### 1. What is an Abstract Data Type?

An Abstract Data Type (ADT) defines what operations a data structure supports, not how those operations are implemented.

It describes the data and its behavior while hiding implementation details.

Example: A Stack ADT supports `push()`, `pop()`, and `peek()`. It can be implemented using an array or a linked list.

### 2. Common ADTs

| ADT   | Main operations             | Example use case         |
| ----- | --------------------------- | ------------------------ |
| Stack | `push`, `pop`, `peek`       | Undo operation           |
| Queue | `enqueue`, `dequeue`        | Task scheduling          |
| List  | `add`, `get`, `remove`      | Managing a list of users |
| Set   | `add`, `contains`, `remove` | Storing unique values    |
| Map   | `put`, `get`, `remove`      | Key-value lookup         |

### 3. ADT vs Data Structure

| ADT                                   | Data structure                                 |
| ------------------------------------- | ---------------------------------------------- |
| Defines what operations are available | Defines how data is stored and operations work |
| Focuses on behavior                   | Focuses on implementation                      |
| Example: Stack                        | Example: Array-based stack                     |

### 4. Java example — Stack ADT

Here, an interface defines the Stack ADT, and an array provides its implementation.

```
interface StackADT {
    void push(int value);
    int pop();
    int peek();
    boolean isEmpty();
}

class ArrayStack implements StackADT {
    private final int[] arr = new int[5];
    private int top = -1;

    public void push(int value) {
        if (top == arr.length - 1) {
            throw new IllegalStateException("Stack is full");
        }
        arr[++top] = value;
    }

    public int pop() {
        if (isEmpty()) {
            throw new IllegalStateException("Stack is empty");
        }
        return arr[top--];
    }

    public int peek() {
        if (isEmpty()) {
            throw new IllegalStateException("Stack is empty");
        }
        return arr[top];
    }

    public boolean isEmpty() {
        return top == -1;
    }
}

public class Main {
    public static void main(String[] args) {
        StackADT stack = new ArrayStack();

        stack.push(10);
        stack.push(20);

        System.out.println(stack.peek()); // 20
        System.out.println(stack.pop());  // 20
        System.out.println(stack.pop());  // 10
        System.out.println(stack.isEmpty()); // true
    }
}
```

Key point: The caller uses the `StackADT` interface without needing to know how the array stores the elements.

### 5. Important interview points

- An ADT is a logical specification of data and its operations.
- A data structure is the concrete implementation of that specification.
- The same ADT can have multiple implementations with different time and space complexities.
- In Java, interfaces are a common way to represent ADT contracts, though ADTs are a broader concept than interfaces.

Remember: ADT = What to do; Data structure = How to do it.
