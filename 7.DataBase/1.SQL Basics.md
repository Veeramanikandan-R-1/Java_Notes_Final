Since your goal is **Java + Spring Boot**, SQL CRUD is important because Spring Boot applications commonly use SQL databases through **JPA/Hibernate/JDBC**.

# Database – SQL Basics

## 1. CRUD

CRUD means:

| Operation  | SQL      | Purpose       |
| ---------- | -------- | ------------- |
| **C**reate | `INSERT` | Add data      |
| **R**ead   | `SELECT` | Retrieve data |
| **U**pdate | `UPDATE` | Modify data   |
| **D**elete | `DELETE` | Remove data   |

We'll use a simple `employees` table.

---

# 2. Create Database & Table

```sql
CREATE DATABASE company_db;

USE company_db;

CREATE TABLE employees (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    age INT,
    department VARCHAR(50),
    salary DECIMAL(10,2)
);
```

Example data:

```text
id | name    | age | department | salary
---+---------+-----+------------+--------
1  | Arun    | 25  | IT         | 50000
2  | Bala    | 30  | HR         | 45000
3  | Kumar   | 28  | IT         | 60000
4  | Ravi    | 35  | Finance    | 70000
```

---

# 3. CREATE → INSERT

### Insert one row

```sql
INSERT INTO employees
(id, name, age, department, salary)
VALUES
(1, 'Arun', 25, 'IT', 50000);
```

### Insert multiple rows

```sql
INSERT INTO employees
(id, name, age, department, salary)
VALUES
(2, 'Bala', 30, 'HR', 45000),
(3, 'Kumar', 28, 'IT', 60000),
(4, 'Ravi', 35, 'Finance', 70000);
```

---

# 4. READ → SELECT

### Get everything

```sql
SELECT * FROM employees;
```

### Get specific columns

```sql
SELECT name, salary
FROM employees;
```

### Get one employee

```sql
SELECT *
FROM employees
WHERE id = 2;
```

### Multiple conditions

```sql
SELECT *
FROM employees
WHERE department = 'IT'
AND salary > 50000;
```

### OR

```sql
SELECT *
FROM employees
WHERE department = 'IT'
OR department = 'HR';
```

---

# 5. UPDATE

Always be careful with `UPDATE`.

```sql
UPDATE employees
SET salary = 65000
WHERE id = 3;
```

Now Kumar's salary becomes `65000`.

### Update multiple columns

```sql
UPDATE employees
SET age = 29,
    salary = 68000
WHERE id = 3;
```

### ⚠️ Important

Don't accidentally do:

```sql
UPDATE employees
SET salary = 65000;
```

This updates **every employee**.

For real applications, the `WHERE` condition is usually essential.

---

# 6. DELETE

### Delete one record

```sql
DELETE FROM employees
WHERE id = 4;
```

### ⚠️ Dangerous

```sql
DELETE FROM employees;
```

This deletes **all rows** from the table.

# 7. Important Practice Queries

These are the SQL queries you should be comfortable with before moving deeper into Spring Boot.

### Q1. Find employees with salary > 50,000

```sql
SELECT *
FROM employees
WHERE salary > 50000;
```

### Q2. Find IT employees

```sql
SELECT *
FROM employees
WHERE department = 'IT';
```

### Q3. Find employees aged between 25 and 30

```sql
SELECT *
FROM employees
WHERE age BETWEEN 25 AND 30;
```

### Q4. Find employees whose name starts with `A`

```sql
SELECT *
FROM employees
WHERE name LIKE 'A%';
```

`%` = any number of characters.

Examples:

```sql
LIKE 'A%'     -- starts with A
LIKE '%n'     -- ends with n
LIKE '%ru%'   -- contains ru
```

### Q5. Sort by salary

Ascending:

```sql
SELECT *
FROM employees
ORDER BY salary ASC;
```

Descending:

```sql
SELECT *
FROM employees
ORDER BY salary DESC;
```

### Q6. Get highest salary

```sql
SELECT MAX(salary)
FROM employees;
```

### Q7. Get lowest salary

```sql
SELECT MIN(salary)
FROM employees;
```

### Q8. Get average salary

```sql
SELECT AVG(salary)
FROM employees;
```

### Q9. Count employees

```sql
SELECT COUNT(*)
FROM employees;
```

### Q10. Get employees from IT or HR

```sql
SELECT *
FROM employees
WHERE department IN ('IT', 'HR');
```

# 8. GROUP BY — Very Important

Find the number of employees in each department:

```sql
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department;
```

Result:

```text
department | employee_count
-----------+---------------
IT         | 2
HR         | 1
Finance    | 1
```

Average salary by department:

```sql
SELECT department, AVG(salary) AS average_salary
FROM employees
GROUP BY department;
```

---

# 9. HAVING

`WHERE` filters **rows before grouping**.

`HAVING` filters **groups after GROUP BY**.

Example:

```sql
SELECT department, AVG(salary) AS average_salary
FROM employees
GROUP BY department
HAVING AVG(salary) > 50000;
```

Remember:

```text
WHERE   → filter rows
GROUP BY → create groups
HAVING  → filter groups
```

---

# 10. LIMIT

Get the top 2 highest-paid employees:

```sql
SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 2;
```

---

# 11. SQL CRUD Flow

Think of a Spring Boot REST API:

```text
React
  ↓
REST API
  ↓
Spring Boot
  ↓
JPA/Hibernate
  ↓
SQL Database
```

The CRUD mapping is:

```text
POST   /employees       → INSERT
GET    /employees       → SELECT
GET    /employees/1     → SELECT WHERE id = 1
PUT    /employees/1     → UPDATE
DELETE /employees/1     → DELETE
```

This connection between **REST CRUD → Java → Database CRUD** is very important for your Spring Boot goal.
