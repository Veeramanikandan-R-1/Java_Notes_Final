## **7 Steps to Connect JDBC (Java Database Connectivity)**

1. **Load/Register Driver** – Load the JDBC driver (optional in modern JDBC).
   ```
   Class.forName("com.mysql.cj.jdbc.Driver");
   ```
2. **Establish Connection** – Connect Java application to the database.
   ```
   Connection con = DriverManager.getConnection(url, username, password);
   ```
3. **Create Statement** – Create a statement to execute SQL queries.
   ```
   Statement stmt = con.createStatement();
   ```
4. **Execute Query** – Execute SQL statements.
   ```
   ResultSet rs = stmt.executeQuery("SELECT * FROM users");
   ```
5. **Process Result** – Retrieve data from the ResultSet.
   ```
   while (rs.next()) {
       System.out.println(rs.getString("name"));
   }
   ```
6. **Close ResultSet and Statement** – Release resources.
   ```
   rs.close();
   stmt.close();
   ```
7. **Close Connection** – Close the database connection.
   ```
   con.close();
   ```

**JDBC Flow:**

`Load Driver → Establish Connection → Create Statement → Execute Query → Process Result → Close Statement/ResultSet → Close Connection`

**Note:** In real-world applications, prefer `PreparedStatement` over `Statement` to prevent SQL injection and use *try-with-resources* for automatic resource management.
