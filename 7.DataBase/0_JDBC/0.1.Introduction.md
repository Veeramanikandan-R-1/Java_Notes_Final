## JDBC (Java Database Connectivity)

JDBC is a Java API that allows Java applications to communicate with relational databases such as MySQL, PostgreSQL and Oracle.

### 1. Why JDBC?

Using JDBC, Java applications can:

- Connect to databases.
- Execute SQL queries.
- Perform CRUD operations (Create, Read, Update, Delete).
- Manage database transactions.

### 2. How JDBC works

JDBC acts as a bridge between Java applications and databases.

1. Java Application – Contains business logic.
2. JDBC API – Provides standard interfaces to interact with databases.
3. JDBC Driver – Converts JDBC calls into database-specific communication.
4. Database – Executes SQL queries and returns results.

### 3. Important JDBC components

| Component           | Purpose                            |
| ------------------- | ---------------------------------- |
| `DriverManager`     | Establishes database connections   |
| `Connection`        | Represents database connection     |
| `Statement`         | Executes SQL queries               |
| `PreparedStatement` | Executes parameterized SQL queries |
| `CallableStatement` | Executes stored procedures         |
| `ResultSet`         | Stores SELECT query results        |
| `SQLException`      | Handles database exceptions        |

### 4. JDBC execution steps

1. Load JDBC driver (usually automatic).
2. Establish database connection.
3. Create Statement / PreparedStatement.
4. Execute SQL query.
5. Process ResultSet.
6. Close resources.

### 5. JDBC vs Spring JDBC vs Spring Data JPA

| Feature        | JDBC              | Spring JDBC  | Spring Data JPA |
| -------------- | ----------------- | ------------ | --------------- |
| SQL            | Manual            | Manual       | Often generated |
| Boilerplate    | High              | Reduced      | Low             |
| Object mapping | Manual            | Simplified   | ORM             |
| Main component | PreparedStatement | JdbcTemplate | JpaRepository   |

### 6. Important interview points

- JDBC is an API, not a database.
- JDBC drivers enable communication with specific databases.
- `PreparedStatement` helps prevent SQL injection.
- `executeQuery()` is used for SELECT.
- `executeUpdate()` is used for INSERT, UPDATE and DELETE.
- JDBC is the foundation for higher-level database access technologies.

Remember: JDBC provides low-level database connectivity. Spring JDBC simplifies JDBC, while Spring Data JPA provides a higher-level ORM-based approach.

---

Why do we need JDBC?

Java applications need to communicate with databases to store, retrieve, update and delete data.

JDBC provides a standard API to establish database connections and execute SQL queries.

Key benefits:

- Database connectivity.
- Supports CRUD operations.
- Supports transaction management.
- Works with multiple databases using different JDBC drivers.
- Reduces database-specific implementation complexity.

In simple words: JDBC acts as a bridge between Java applications and databases.

## Steps involved in JDBC (High Level)

1. Load/Register Driver – Register the database JDBC driver (usually automatic).
2. Establish Connection – Connect Java application to the database using `DriverManager`.
3. Create Statement – Create `Statement` or `PreparedStatement` to execute SQL.
4. Execute Query – Execute SQL using `executeQuery()`, `executeUpdate()` or `execute()`.
5. Process Result – Retrieve and process data using `ResultSet` (for SELECT).
6. Close Resources – Close `ResultSet`, `Statement` and `Connection`.

Remember: Connect → Create Statement → Execute → Process Result → Close Resources.
