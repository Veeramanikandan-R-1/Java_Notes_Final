# Creating a JDBC application using Core Java + MySQL

Let's implement a simple JDBC application without Spring Boot first. This helps you understand how JDBC actually works internally.

We'll create a Java application that inserts and retrieves users from MySQL.

## 1. Create a Maven project

Create a Maven Java project with this structure:

```
jdbc-demo/
 ├── src/
 │    └── main/
 │         └── java/
 │              └── Main.java
 └── pom.xml
```

## 2. Add JDBC Driver dependency

Add MySQL Connector/J to `pom.xml`.

```
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <version>9.5.0</version>
</dependency>
```

This driver allows Java to communicate with MySQL.

## 3. Create database and table

Execute in MySQL:

```
CREATE DATABASE jdbc_demo;

USE jdbc_demo;

CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100),
    email VARCHAR(100)
);
```

## 4. Register JDBC Driver

```
Class.forName("com.mysql.cj.jdbc.Driver");
```

- Loads the MySQL JDBC driver.
- Modern JDBC drivers are generally registered automatically, so this step is optional.

## 5. Establish database connection

```
Connection con = DriverManager.getConnection(
    "jdbc:mysql://localhost:3306/jdbc_demo",
    "root",
    "your_password"
);
```

- `DriverManager` manages database connections.
- `getConnection()` establishes a connection.
- `Connection` represents the active database connection.

## 6. Create PreparedStatement

```
String sql = "INSERT INTO users (name, email) VALUES (?, ?)";

PreparedStatement ps = con.prepareStatement(sql);

ps.setString(1, "Arun");
ps.setString(2, "arun@gmail.com");
```

- `PreparedStatement` executes parameterized SQL.
- `?` represents a placeholder.
- `setString()` supplies the parameter values.

## 7. Execute SQL query

For INSERT, UPDATE and DELETE, use `executeUpdate()`.

```
int rows = ps.executeUpdate();

System.out.println(rows + " record inserted");
```

For SELECT, use `executeQuery()`.

```
String sql = "SELECT * FROM users";

Statement st = con.createStatement();

ResultSet rs = st.executeQuery(sql);

while (rs.next()) {
    System.out.println(rs.getInt("id"));
    System.out.println(rs.getString("name"));
    System.out.println(rs.getString("email"));
}
```

- `ResultSet` holds the retrieved records.
- `rs.next()` moves the cursor to the next row.
- `getInt()` and `getString()` retrieve column values.

## 8. Close resources

```
rs.close();
st.close();
con.close();
```

Closing resources is important to avoid connection and memory leaks.

## 9. Complete working example

Instead of manually closing resources, use try-with-resources, which automatically closes them.

`Main.java`

```
import java.sql.*;

public class Main {

    public static void main(String[] args) {

        String url = "jdbc:mysql://localhost:3306/jdbc_demo";
        String username = "root";
        String password = "your_password";

        // INSERT
        String insertSql =
            "INSERT INTO users (name, email) VALUES (?, ?)";

        try (
            Connection con =
                DriverManager.getConnection(url, username, password);

            PreparedStatement ps = con.prepareStatement(insertSql)
        ) {

            ps.setString(1, "Arun");
            ps.setString(2, "arun@gmail.com");

            int rows = ps.executeUpdate();

            System.out.println(rows + " record inserted");

        } catch (SQLException e) {
            e.printStackTrace();
        }

        // SELECT
        String selectSql = "SELECT * FROM users";

        try (
            Connection con =
                DriverManager.getConnection(url, username, password);

            Statement st = con.createStatement();

            ResultSet rs = st.executeQuery(selectSql)
        ) {

            while (rs.next()) {
                System.out.println("ID: " + rs.getInt("id"));
                System.out.println("Name: " + rs.getString("name"));
                System.out.println("Email: " + rs.getString("email"));
            }

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

## 10. Important JDBC methods – Quick revision

| Method               | Purpose                        |
| -------------------- | ------------------------------ |
| `getConnection()`    | Establish connection           |
| `prepareStatement()` | Create PreparedStatement       |
| `executeQuery()`     | Execute SELECT                 |
| `executeUpdate()`    | Execute INSERT, UPDATE, DELETE |
| `execute()`          | Execute general SQL            |
| `next()`             | Move to next ResultSet row     |
| `close()`            | Close resources                |

Overall JDBC flow:

`Driver → Connection → Statement → Execute SQL → ResultSet → Close Resources`
