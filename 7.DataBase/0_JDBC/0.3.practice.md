# Create a JDBC Application in VS Code (Linux) – End-to-End

We'll create a complete Java JDBC application using Maven + MySQL in VS Code.

By the end, you'll be able to:

- Create a Maven Java project.
- Configure MySQL database connectivity.
- Add the JDBC driver.
- Establish a database connection.
- Perform CRUD operations (Create, Read, Update, Delete).
- Run and test the application from VS Code.

We'll use JDK 21, Maven and MySQL.

## 5. Add MySQL JDBC Dependency

Open `pom.xml`.

Add the MySQL Connector/J dependency inside the `dependencies` section.

```
<dependencies>

    <dependency>
        <groupId>com.mysql</groupId>
        <artifactId>mysql-connector-j</artifactId>
        <version>9.7.0</version>
    </dependency>

</dependencies>
```

Also ensure your Maven compiler is configured for Java 21. Add this under the `project` element if you don't already have equivalent configuration:

```
<properties>
    <maven.compiler.release>21</maven.compiler.release>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
</properties>
```

Why do we need MySQL Connector/J?

- JDBC is a standard Java API.
- MySQL Connector/J is the MySQL-specific JDBC driver.
- It translates JDBC calls into a protocol MySQL understands.

Maven downloads the driver automatically when you build the project.&#x20;

## 6. Create Database Connection Class

Create a new Java class:

`src/main/java/com/example/DBConnection.java`

```
package com.example;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

public class DBConnection {

    private static final String URL =
        "jdbc:mysql://localhost:3306/jdbc_demo";

    private static final String USER = "jdbc_user";

    private static final String PASSWORD = "jdbc123";

    public static Connection getConnection() throws SQLException {

        return DriverManager.getConnection(
            URL,
            USER,
            PASSWORD
        );
    }
}
```

Understanding the connection URL:

```
jdbc:mysql://localhost:3306/jdbc_demo
```

| Part      | Meaning            |
| --------- | ------------------ |
| jdbc      | JDBC protocol      |
| mysql     | Database type      |
| localhost | Database server    |
| 3306      | MySQL default port |
| jdbc_demo | Database name      |

Note: This is a learning example. In real applications, keep database credentials in environment variables or external configuration rather than hardcoding them.

## 8. Implement CRUD Operations Using JDBC

Now let's implement actual database operations.

Create a new class:

`src/main/java/com/example/UserDAO.java`

DAO stands for Data Access Object. It separates database-related logic from application logic.

```
package com.example;

import java.sql.*;

public class UserDAO {

    // CREATE
    public void createUser(String name, String email) {

        String sql = "INSERT INTO users (name, email) VALUES (?, ?)";

        try (Connection con = DBConnection.getConnection();
             PreparedStatement ps = con.prepareStatement(sql)) {

            ps.setString(1, name);
            ps.setString(2, email);

            int rows = ps.executeUpdate();

            System.out.println(rows + " user inserted");

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    // READ
    public void getUsers() {

        String sql = "SELECT * FROM users";

        try (Connection con = DBConnection.getConnection();
             PreparedStatement ps = con.prepareStatement(sql);
             ResultSet rs = ps.executeQuery()) {

            while (rs.next()) {

                System.out.println(
                    rs.getInt("id") + " | " +
                    rs.getString("name") + " | " +
                    rs.getString("email")
                );
            }

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    // UPDATE
    public void updateUser(int id, String name) {

        String sql = "UPDATE users SET name = ? WHERE id = ?";

        try (Connection con = DBConnection.getConnection();
             PreparedStatement ps = con.prepareStatement(sql)) {

            ps.setString(1, name);
            ps.setInt(2, id);

            int rows = ps.executeUpdate();

            System.out.println(rows + " user updated");

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }

    // DELETE
    public void deleteUser(int id) {

        String sql = "DELETE FROM users WHERE id = ?";

        try (Connection con = DBConnection.getConnection();
             PreparedStatement ps = con.prepareStatement(sql)) {

            ps.setInt(1, id);

            int rows = ps.executeUpdate();

            System.out.println(rows + " user deleted");

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
```

### Important JDBC methods

| Method               | Purpose                       |
| -------------------- | ----------------------------- |
| `getConnection()`    | Establish database connection |
| `prepareStatement()` | Create SQL statement          |
| `setString()`        | Set String parameter          |
| `setInt()`           | Set Integer parameter         |
| `executeUpdate()`    | INSERT, UPDATE, DELETE        |
| `executeQuery()`     | SELECT                        |
| `next()`             | Move to next result row       |
| `getString()`        | Retrieve String column        |
| `getInt()`           | Retrieve Integer column       |

Why PreparedStatement instead of Statement?

- Supports parameterized SQL queries.
- Helps prevent SQL injection.
- Allows parameter binding.
- Makes repeated execution more convenient.

## 9. Execute CRUD Operations

Replace `App.java` with:

```
package com.example;

public class App {

    public static void main(String[] args) {

        UserDAO userDAO = new UserDAO();

        // CREATE
        userDAO.createUser("Arun", "arun@gmail.com");
        userDAO.createUser("Mani", "mani@gmail.com");

        // READ
        System.out.println("\nUsers:");
        userDAO.getUsers();

        // UPDATE
        userDAO.updateUser(1, "Arun Kumar");

        // READ
        System.out.println("\nAfter Update:");
        userDAO.getUsers();

        // DELETE
        userDAO.deleteUser(2);

        // READ
        System.out.println("\nAfter Delete:");
        userDAO.getUsers();
    }
}
```

Execute:

```
mvn clean compile exec:java \
-Dexec.mainClass="com.example.App"
```

## 11. Understand the Overall JDBC Execution Flow

This is the important part to understand from a Java developer's perspective.

Java Application

App.java / UserDAO.java

JDBC API

MySQL JDBC Driver

MySQL Connector/J

Database protocol

MySQL Database

jdbc_demo → users table

Execution steps:

1. Java application requests a database connection.
2. DriverManager uses the registered MySQL driver.
3. MySQL driver establishes the connection.
4. Java creates a PreparedStatement.
5. SQL query executes against MySQL.
6. Database returns the result.
7. Java processes the ResultSet.
8. Resources are closed using try-with-resources.

## 12. Common Errors and Solutions

| Error                         | Possible reason                            |
| ----------------------------- | ------------------------------------------ |
| `No suitable driver found`    | MySQL Connector/J dependency missing       |
| `Access denied for user`      | Incorrect username/password or permissions |
| `Communications link failure` | MySQL server is not running                |
| `Unknown database`            | Database not created                       |
| `Connection refused`          | Incorrect host or port                     |
| `Table doesn't exist`         | Table not created in the selected database |

Check MySQL service:

```
sudo systemctl status mysql
```

Restart if necessary:

```
sudo systemctl restart mysql
```

| Connection Pooling | HikariCP                                            |

How this connects to Spring Boot:

In a traditional JDBC application, you manually manage connections, statements and result sets. In Spring Boot, tools such as `JdbcTemplate` simplify much of this boilerplate.
