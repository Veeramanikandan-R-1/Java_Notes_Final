**JPQL (Java Persistence Query Language)** is an object-oriented query language used in JPA/Hibernate to query database entities instead of directly querying database tables.

### **Example**

Assume you have a `Product` entity:

```
@Entity
public class Product {
    @Id
    private int id;
    private String name;
    private double price;
}
```

**1. SQL query:**

```
SELECT * FROM product WHERE price > 1000;
```

**2. JPQL query:**

```
SELECT p FROM Product p WHERE p.price > 1000
```

### **Using JPQL in Spring Data JPA**

```
@Query("SELECT p FROM Product p WHERE p.price > :price")
List<Product> findExpensiveProducts(@Param("price") double price);
```

### **JPQL vs SQL**

| JPQL                          | SQL                                 |
| ----------------------------- | ----------------------------------- |
| Works with entities           | Works with tables                   |
| Uses class and property names | Uses table and column names         |
| Database independent          | Database dependent (dialect/syntax) |
| Uses entity relationships     | Uses table relationships            |

**Key takeaway:** JPQL queries Java entities and their properties, while SQL queries database tables and columns.
