# Hibernate – Introduction (Java)

Hibernate is an open-source Java ORM (Object-Relational Mapping) framework used to interact with relational databases without writing SQL queries for every database operation.

It maps Java objects (classes) to database tables and Java object properties to table columns.

## 1. Why do we need Hibernate?

When using JDBC:

- We write SQL queries manually.
- We manage database connections.
- We convert database records into Java objects manually.
- We handle CRUD operations using JDBC code.

Hibernate simplifies these tasks.

Without Hibernate (JDBC):

```
String sql = "INSERT INTO users(name, email) VALUES (?, ?)";

PreparedStatement ps = connection.prepareStatement(sql);
ps.setString(1, "Arun");
ps.setString(2, "arun@gmail.com");

ps.executeUpdate();
```

With Hibernate:

```
User user = new User();
user.setName("Arun");
user.setEmail("arun@gmail.com");

session.persist(user);
```

Hibernate generates and executes the required SQL.

## 2. How Hibernate works

1. Create a Java entity class.
2. Map the entity class to a database table.
3. Configure Hibernate with database connection details.
4. Hibernate manages the mapping between Java objects and database records.
5. Perform CRUD operations using Hibernate APIs.
6. Hibernate generates SQL queries and communicates with the database.

## 3. Important Hibernate concepts

| Concept        | Purpose                                 |
| -------------- | --------------------------------------- |
| ORM            | Maps Java objects to database tables    |
| Entity         | Java class mapped to a database table   |
| SessionFactory | Creates Hibernate sessions              |
| Session        | Used to interact with the database      |
| Transaction    | Manages database transactions           |
| HQL            | Hibernate Query Language                |
| Criteria API   | Builds queries programmatically         |
| Annotations    | Define entity and relationship mappings |

## 4. Hibernate vs JDBC

| JDBC                                  | Hibernate                      |
| ------------------------------------- | ------------------------------ |
| SQL queries written manually          | SQL generated automatically    |
| Manual object mapping                 | Automatic object mapping       |
| More boilerplate code                 | Less boilerplate code          |
| Database-specific SQL may be required | Database portability is easier |
| Manual CRUD implementation            | ORM-based CRUD operations      |

## 5. Hibernate vs JPA vs Spring Data JPA

- JPA: Java specification that defines ORM standards.
- Hibernate: ORM framework and one of the most popular JPA implementations.
- Spring Data JPA: Spring abstraction that simplifies database operations using repositories, commonly backed by Hibernate.

Important: JPA is a specification; Hibernate is an implementation; Spring Data JPA simplifies working with JPA.

## 6. Where is Hibernate used?

- Enterprise Java applications.
- Spring Boot applications.
- REST APIs.
- Applications requiring database CRUD operations.
- Applications with complex database relationships.
