# Create a Basic Hibernate Java Application in VS Code (Linux)

We will create a standalone Java + Hibernate + MySQL application using Maven.

The goal is to understand Hibernate without introducing Spring Boot or Spring Data JPA yet.

## 1. What we are going to build

A simple Student Management Application that performs CRUD operations using Hibernate.

Features:

1. Insert a student.
2. Fetch a student by ID.
3. Fetch all students.
4. Update student details.
5. Delete a student.

Make sure you have the following installed:

## 3. Create a Maven project

Open your Linux terminal and execute:

```
mkdir hibernate-practice
cd hibernate-practice

mvn archetype:generate \
-DgroupId=com.example \
-DartifactId=hibernate-practice \
-DarchetypeArtifactId=maven-archetype-quickstart \
-DinteractiveMode=false
```

Open the generated project in VS Code:

```
cd hibernate-practice
code .
```

The project will have a structure similar to this:

```

hibernate-practice/
├── pom.xml
└── src/
    └── main/
        ├── java/
        │   └── com/
        │       └── example/
        │           ├── Main.java
        │           └── entity/
        │               └── Student.java
        └── resources/
            └── hibernate.cfg.xml

```

We will use the following structure:

- `Student.java` – Entity class.
- `hibernate.cfg.xml` – Hibernate and database configuration.
- `Main.java` – Application entry point and CRUD operations.
- `pom.xml` – Maven dependencies.

Note: Run the Maven archetype command from the parent directory, not from inside a directory already named `hibernate-practice`.

## 6. Create the Entity class

Create:

`src/main/java/com/example/entity/Student.java`

```

package com.example.entity;

import jakarta.persistence.*;

@Entity
@Table(name = "students")
public class Student {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String name;

    private String email;

    public Student() {
    }

    public Student(String name, String email) {
        this.name = name;
        this.email = email;
    }

    public Long getId() {
        return id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }

    @Override
    public String toString() {
        return "Student{id=" + id +
                ", name='" + name +
                "', email='" + email + "'}";
    }
}

```

Important annotations:

| Annotation        | Purpose                             |
| ----------------- | ----------------------------------- |
| `@Entity`         | Marks class as a database entity    |
| `@Table`          | Specifies the database table name   |
| `@Id`             | Defines primary key                 |
| `@GeneratedValue` | Automatically generates primary key |
| `@Column`         | Configures database column          |

Notice that we use `jakarta.persistence` because modern Hibernate uses Jakarta Persistence.

## 7. Configure Hibernate

Create:

`src/main/resources/hibernate.cfg.xml`

```

<?xml version="1.0" encoding="UTF-8"?>

<!DOCTYPE hibernate-configuration PUBLIC
    "-//Hibernate/Hibernate Configuration DTD 3.0//EN"
    "https://hibernate.org/dtd/hibernate-configuration-3.0.dtd">

<hibernate-configuration>
    <session-factory>

        <!-- Database connection -->
        <property name="hibernate.connection.driver_class">
            com.mysql.cj.jdbc.Driver
        </property>

        <property name="hibernate.connection.url">
            jdbc:mysql://localhost:3306/hibernate_db
        </property>

        <property name="hibernate.connection.username">
            hibernate_user
        </property>

        <property name="hibernate.connection.password">
            Hibernate@123
        </property>

        <!-- Hibernate configuration -->
        <property name="hibernate.hbm2ddl.auto">
            update
        </property>

        <property name="hibernate.show_sql">
            true
        </property>

        <property name="hibernate.format_sql">
            true
        </property>

        <!-- Entity mapping -->
        <mapping class="com.example.entity.Student"/>

    </session-factory>
</hibernate-configuration>

```

Replace the username and password if you used different credentials.

Important configuration properties:

| Property              | Purpose                                       |
| --------------------- | --------------------------------------------- |
| `connection.url`      | Database URL                                  |
| `connection.username` | Database username                             |
| `connection.password` | Database password                             |
| `hbm2ddl.auto=update` | Automatically creates or updates table schema |
| `show_sql=true`       | Displays generated SQL                        |
| `format_sql=true`     | Formats generated SQL                         |

For this practice project, `update` is convenient. Avoid using it as a production schema-management strategy.

## 8. Create Main.java with CRUD operations

Create:

`src/main/java/com/example/Main.java`

```

package com.example;

import com.example.entity.Student;

import org.hibernate.Session;
import org.hibernate.SessionFactory;
import org.hibernate.cfg.Configuration;

import java.util.List;

public class Main {

    public static void main(String[] args) {

        // Create SessionFactory
        try (SessionFactory factory = new Configuration()
                .configure("hibernate.cfg.xml")
                .buildSessionFactory()) {

            // CREATE
            Student student = new Student(
                    "Arun",
                    "arun@gmail.com"
            );

            factory.inTransaction(session -> {
                session.persist(student);
            });

            Long studentId = student.getId();

            System.out.println("Student created: " + studentId);

            // READ BY ID
            factory.inTransaction(session -> {
                Student result = session.find(Student.class, studentId);
                System.out.println("Fetched: " + result);
            });

            // READ ALL
            factory.inTransaction(session -> {
                List<Student> students =
                        session.createSelectionQuery(
                                "FROM Student", Student.class
                        ).getResultList();

                System.out.println("All students:");

                students.forEach(System.out::println);
            });

            // UPDATE
            factory.inTransaction(session -> {
                Student result = session.find(Student.class, studentId);

                if (result != null) {
                    result.setName("Arun Kumar");
                    result.setEmail("arunkumar@gmail.com");
                }
            });

            System.out.println("Student updated");

            // DELETE
            factory.inTransaction(session -> {
                Student result = session.find(Student.class, studentId);

                if (result != null) {
                    session.remove(result);
                }
            });

            System.out.println("Student deleted");

        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

```

## 9. Understand the important Hibernate APIs

| API                      | Purpose                                  |
| ------------------------ | ---------------------------------------- |
| `Configuration`          | Loads Hibernate configuration            |
| `SessionFactory`         | Creates Hibernate sessions               |
| `Session`                | Interacts with database                  |
| `persist()`              | Inserts a new entity                     |
| `find()`                 | Fetches entity using primary key         |
| `createSelectionQuery()` | Executes a SELECT query                  |
| `remove()`               | Deletes an entity                        |
| `inTransaction()`        | Executes operations within a transaction |

Important concepts:

- `SessionFactory` is generally created once and reused throughout the application.
- `Session` represents a unit of work with the database.
- A transaction ensures database operations are committed or rolled back together.
- When an entity is managed by a Session, Hibernate automatically detects its changes. This is called dirty checking.


To verify each operation individually, temporarily comment out the DELETE section and run the application again.

## 12. Understand the complete execution flow

1. `Main.java` loads `hibernate.cfg.xml`.
2. Hibernate reads database connection details.
3. Hibernate creates a `SessionFactory`.
4. `SessionFactory` creates a `Session`.
5. You perform CRUD operations using Hibernate APIs.
6. Hibernate generates SQL queries.
7. MySQL executes those queries.
8. Transactions are committed.
9. `SessionFactory` is closed.
