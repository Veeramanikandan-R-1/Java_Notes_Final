# Spring Boot – Swagger / OpenAPI

## 1. What is OpenAPI?

OpenAPI is a standard specification used to describe REST APIs, including endpoints, HTTP methods, request bodies, parameters, and responses.

Swagger is a set of tools that work with OpenAPI. For example, Swagger UI displays your API documentation in an interactive web page where you can test endpoints.

OpenAPI

The API description/specification, usually available as JSON or YAML.

Swagger UI

A browser-based interface to read and test API documentation.

For a React developer, think of OpenAPI as a machine-readable API contract that can also help generate client code.

## 2. Add OpenAPI documentation to Spring Boot

We'll use Spring Boot 3.x or 4.x with springdoc-openapi. The exact dependency version must be compatible with your Spring Boot version.

In your `pom.xml`, add this dependency inside `<dependencies>`:

```
<dependency>
    <groupId>org.springdoc</groupId>
    <artifactId>springdoc-openapi-starter-webmvc-ui</artifactId>
    <version>2.8.17</version>
</dependency>
```

This is a commonly used Spring Boot 3-compatible version. For Spring Boot 4, verify the compatible springdoc release before using it; do not assume every 2.x version supports Boot 4.

Correction for your project: Your `pom.xml` uses Spring Boot 4.0.8, so use the springdoc 3.0.x line rather than `2.8.17`. For example, use `3.0.3`, which is in the Boot 4.0-compatible line.&#x20;

## 3. Full working example

Assume your package is `com.practice.demo`.

### `ProductController.java`

```
package com.practice.demo;

import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.Parameter;
import io.swagger.v3.oas.annotations.tags.Tag;
import io.swagger.v3.oas.annotations.responses.ApiResponse;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/products")
@Tag(name = "Products", description = "Product management APIs")
public class ProductController {

    @GetMapping("/{id}")
    @Operation(
        summary = "Get product by ID",
        description = "Returns a product using its ID"
    )
    @ApiResponse(
        responseCode = "200",
        description = "Product retrieved successfully"
    )
    @ApiResponse(
        responseCode = "404",
        description = "Product not found"
    )
    public ResponseEntity<String> getProduct(
        @Parameter(description = "Unique product ID")
        @PathVariable Long id
    ) {
        if (id != 1L) {
            return ResponseEntity.notFound().build();
        }

        return ResponseEntity.ok(
            "{\"id\":1,\"name\":\"Laptop\"}"
        );
    }
}
```

This is a small demonstration; a real application would typically return a Java DTO instead of a JSON string.

### Optional: `OpenApiConfig.java`

Use this class to add API-wide information.

```
package com.practice.demo;

import io.swagger.v3.oas.annotations.OpenAPIDefinition;
import io.swagger.v3.oas.annotations.info.Info;
import org.springframework.context.annotation.Configuration;

@Configuration
@OpenAPIDefinition(
    info = @Info(
        title = "Product API",
        version = "1.0",
        description = "Documentation for Product REST APIs"
    )
)
public class OpenApiConfig {
}
```

No extra configuration is required for the default Swagger UI or OpenAPI endpoints when using the appropriate springdoc starter.&#x20;

## 5. Important annotations to remember

| Annotation           | Purpose                                    |
| -------------------- | ------------------------------------------ |
| `@Tag`               | Groups related API endpoints               |
| `@Operation`         | Documents an endpoint's purpose            |
| `@Parameter`         | Documents a path or query parameter        |
| `@ApiResponse`       | Documents possible HTTP responses          |
| `@Schema`            | Documents DTO fields and their constraints |
| `@OpenAPIDefinition` | Defines API-wide metadata                  |

Interview takeaway: Springdoc automatically generates OpenAPI documentation from Spring controllers and models. Swagger UI displays that documentation and lets developers test endpoints without needing a separate tool such as Postman.
