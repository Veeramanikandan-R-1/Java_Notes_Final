# Spring Boot REST APIs — CRUD

A REST API allows your React application to communicate with the backend using HTTP.

```text
React
  ↓ HTTP Request
Controller
  ↓
Service
  ↓
Repository
  ↓
Database
```

For now, we'll focus on the **Controller/API layer**.

---

## 1. Controller

`@RestController` tells Spring:

> This class handles HTTP API requests and returns data directly, usually as JSON.

```java
@RestController
@RequestMapping("/api/users")
public class UserController {

    @GetMapping
    public String getUsers() {
        return "All users";
    }
}
```

Request:

```text
GET /api/users
```

Response:

```text
All users
```

### Important annotations

| Annotation        | Purpose                     |
| ----------------- | --------------------------- |
| `@RestController` | Creates REST API controller |
| `@RequestMapping` | Common URL prefix           |
| `@GetMapping`     | GET                         |
| `@PostMapping`    | POST                        |
| `@PutMapping`     | PUT                         |
| `@DeleteMapping`  | DELETE                      |

# 2. ResponseEntity

`ResponseEntity` allows you to control:

* Response body
* HTTP status code
* Headers

Example:

```java
return ResponseEntity.ok(user);
```

Equivalent to:

```text
HTTP 200 OK
Body: user
```

Other common responses:

```java
ResponseEntity.ok(user);                 // 200
ResponseEntity.status(201).body(user);   // 201
ResponseEntity.noContent().build();      // 204
ResponseEntity.notFound().build();       // 404
ResponseEntity.badRequest().build();     // 400
```

---

# 3. HTTP Status Codes

You should know these well for REST API development.

| Code                        | Meaning                        | Typical usage            |
| --------------------------- | ------------------------------ | ------------------------ |
| `200 OK`                    | Success                        | GET, successful PUT      |
| `201 Created`               | Resource created               | POST                     |
| `204 No Content`            | Success, no body               | DELETE                   |
| `400 Bad Request`           | Invalid request                | Invalid input            |
| `401 Unauthorized`          | Authentication required/failed | Login/JWT                |
| `403 Forbidden`             | No permission                  | Authorization            |
| `404 Not Found`             | Resource doesn't exist         | User not found           |
| `409 Conflict`              | Conflict                       | Duplicate resource       |
| `500 Internal Server Error` | Server error                   | Unexpected backend error |

# 4. `@RequestBody`

Used when data comes inside the **HTTP request body**.

React:

```javascript
fetch("/api/users", {
    method: "POST",
    headers: {
        "Content-Type": "application/json"
    },
    body: JSON.stringify({
        name: "John",
        email: "john@gmail.com"
    })
});
```

Spring:

```java
@PostMapping
public ResponseEntity<User> createUser(@RequestBody User user) {
    return ResponseEntity.status(201).body(user);
}
```

JSON:

```json
{
    "name": "John",
    "email": "john@gmail.com"
}
```

Spring automatically converts:

```text
JSON → Java User object
```

This is handled by Jackson.

---

# 5. `@PathVariable`

Used when the value is part of the URL.

Request:

```text
GET /api/users/10
```

Controller:

```java
@GetMapping("/{id}")
public ResponseEntity<User> getUser(@PathVariable Long id) {
    // id = 10
}
```

Think:

```text
/api/users/{id}
             ↑
       PathVariable
```

Best for identifying a **specific resource**.

---

# 6. `@RequestParam`

Used for query parameters.

Request:

```text
GET /api/users?page=1&size=10
```

Controller:

```java
@GetMapping
public ResponseEntity<String> getUsers(
        @RequestParam int page,
        @RequestParam int size) {

    return ResponseEntity.ok(
        "Page: " + page + ", Size: " + size
    );
}
```

Think:

```text
/api/users?page=1&size=10
            ↑
       RequestParam
```

Usually used for:

* Filtering
* Searching
* Pagination
* Sorting

Example:

```text
GET /api/users?name=John
GET /api/users?page=1&size=20
```

---

# 7. `@RequestHeader`

Used to read HTTP headers.

Request:

```text
Authorization: Bearer abc123
```

Controller:

```java
@GetMapping
public String getUsers(
        @RequestHeader("Authorization") String authorization) {

    return authorization;
}
```

Commonly used for:

* JWT tokens
* Authorization
* Custom headers
* API versions

# 8. Complete CRUD Example

Let's create a simple **User REST API**.

### `User.java`

```java
package com.example.demo;

public class User {

    private Long id;
    private String name;
    private String email;

    public User() {
    }

    public User(Long id, String name, String email) {
        this.id = id;
        this.name = name;
        this.email = email;
    }

    public Long getId() {
        return id;
    }

    public void setId(Long id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }
}
```

### `UserController.java`

```java
package com.example.demo;

import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.ArrayList;
import java.util.List;

@RestController
@RequestMapping("/api/users")
public class UserController {

    private final List<User> users = new ArrayList<>();

    // CREATE
    @PostMapping
    public ResponseEntity<User> createUser(
            @RequestBody User user) {

        user.setId((long) (users.size() + 1));
        users.add(user);

        return ResponseEntity
                .status(201)
                .body(user);
    }

    // READ ALL
    @GetMapping
    public ResponseEntity<List<User>> getUsers() {

        return ResponseEntity.ok(users);
    }

    // READ ONE
    @GetMapping("/{id}")
    public ResponseEntity<User> getUser(
            @PathVariable Long id) {

        return users.stream()
                .filter(user -> user.getId().equals(id))
                .findFirst()
                .map(ResponseEntity::ok)
                .orElse(ResponseEntity.notFound().build());
    }

    // UPDATE
    @PutMapping("/{id}")
    public ResponseEntity<User> updateUser(
            @PathVariable Long id,
            @RequestBody User updatedUser) {

        for (User user : users) {

            if (user.getId().equals(id)) {

                user.setName(updatedUser.getName());
                user.setEmail(updatedUser.getEmail());

                return ResponseEntity.ok(user);
            }
        }

        return ResponseEntity.notFound().build();
    }

    // DELETE
    @DeleteMapping("/{id}")
    public ResponseEntity<Void> deleteUser(
            @PathVariable Long id) {

        boolean removed = users.removeIf(
                user -> user.getId().equals(id)
        );

        if (!removed) {
            return ResponseEntity.notFound().build();
        }

        return ResponseEntity.noContent().build();
    }
}
```

This is a **fully working CRUD controller**, although it stores data in memory rather than a database.

# 9. API Summary

| Operation | HTTP     | URL             | Input                            |
| --------- | -------- | --------------- | -------------------------------- |
| Create    | `POST`   | `/api/users`    | `@RequestBody`                   |
| Get all   | `GET`    | `/api/users`    | —                                |
| Get one   | `GET`    | `/api/users/10` | `@PathVariable`                  |
| Update    | `PUT`    | `/api/users/10` | `@PathVariable` + `@RequestBody` |
| Delete    | `DELETE` | `/api/users/10` | `@PathVariable`                  |

## The 3 request-value annotations you must remember

```text
@PathVariable
    ↓
/users/10
        ↑
     value in URL path


@RequestParam
    ↓
/users?page=1
        ↑
    query parameter


@RequestBody
    ↓
POST /users

{
   "name": "John"
}
        ↑
    request body
```

And:

```text
@RequestHeader
      ↓
Authorization: Bearer xxx
      ↑
   HTTP header
```

### Interview-level summary

> **`@PathVariable` gets values from the URL path, `@RequestParam` gets query parameters, `@RequestBody` converts request JSON into a Java object, and `@RequestHeader` reads HTTP headers. `ResponseEntity` lets us control the response body, status code, and headers.**
