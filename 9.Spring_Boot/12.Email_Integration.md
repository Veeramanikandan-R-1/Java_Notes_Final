# Spring Boot – Email Integration

## 1. Core concepts

| Concept           | Purpose                                                                  |
| ----------------- | ------------------------------------------------------------------------ |
| Spring Mail       | Spring's abstraction for sending emails from Java applications.          |
| SMTP              | Protocol used to send emails through a mail server, such as Gmail SMTP.  |
| JavaMailSender    | Spring interface used to send email messages.                            |
| SimpleMailMessage | Sends plain-text emails.                                                 |
| MimeMessageHelper | Supports HTML emails and attachments.                                    |
| OTP               | One-Time Password sent through email for verification or authentication. |

Typical flow:

Controller — receives request

EmailService — prepares email

JavaMailSender — sends via SMTP

Recipient's inbox

## 2. Add the dependency

For a Spring Boot 3.x project, add this inside `pom.xml`:

```
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-mail</artifactId>
</dependency>
```

Use your project's existing Spring Boot parent/BOM to manage the dependency version.

## 3. Configure SMTP

For Gmail, enable 2-Step Verification and generate a Google App Password. Do not use your normal Gmail password.

Add the following to `src/main/resources/application.properties`:

```
spring.mail.host=smtp.gmail.com
spring.mail.port=587
spring.mail.username=${MAIL_USERNAME}
spring.mail.password=${MAIL_PASSWORD}

spring.mail.properties.mail.smtp.auth=true
spring.mail.properties.mail.smtp.starttls.enable=true
```

Set these environment variables before running the application:

- `MAIL_USERNAME` — your Gmail address.
- `MAIL_PASSWORD` — your Google App Password.

Keep credentials outside your source code and Git repository.

## 4. Implement the Email Service

Create `service/EmailService.java`.

```
package com.springapp.demo.service;

import org.springframework.mail.SimpleMailMessage;
import org.springframework.mail.javamail.JavaMailSender;
import org.springframework.stereotype.Service;

@Service
public class EmailService {

    private final JavaMailSender mailSender;

    public EmailService(JavaMailSender mailSender) {
        this.mailSender = mailSender;
    }

    public void sendEmail(String to, String subject, String body) {
        SimpleMailMessage message = new SimpleMailMessage();

        message.setTo(to);
        message.setSubject(subject);
        message.setText(body);

        mailSender.send(message);
    }
}
```

Important concepts:

- `@Service` registers the class as a Spring bean.
- `JavaMailSender` is injected through constructor injection.
- `SimpleMailMessage` creates a plain-text email.
- `mailSender.send()` sends the email through the configured SMTP server.

## 5. Create an OTP Email Service

Create `service/OtpService.java`.

```
package com.springapp.demo.service;

import java.security.SecureRandom;

import org.springframework.stereotype.Service;

@Service
public class OtpService {

    private final EmailService emailService;
    private final SecureRandom random = new SecureRandom();

    public OtpService(EmailService emailService) {
        this.emailService = emailService;
    }

    public void sendOtp(String email) {
        String otp = String.format(
            "%06d", random.nextInt(1_000_000)
        );

        emailService.sendEmail(
            email,
            "Your verification OTP",
            "Your OTP is: " + otp
                + "\nIt is valid for 5 minutes."
        );

        // Demo only: store the OTP securely with expiry
        // before implementing OTP verification.
    }
}
```

This generates a six-digit OTP using `SecureRandom` and emails it.

Security note: This is only the sending portion of OTP integration. Before using it for authentication, store the OTP securely with a five-minute expiry, implement verification and one-time use, limit resend/verification attempts, and never return the OTP in an API response or log it. The five-minute validity is currently only stated in the email; it is not enforced by this demo.

## 6. Create the REST Controller

Create `controller/EmailController.java`.

```
package com.springapp.demo.controller;

import com.springapp.demo.service.EmailService;
import com.springapp.demo.service.OtpService;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/email")
public class EmailController {

    private final EmailService emailService;
    private final OtpService otpService;

    public EmailController(
            EmailService emailService,
            OtpService otpService) {
        this.emailService = emailService;
        this.otpService = otpService;
    }

    @PostMapping("/send")
    public ResponseEntity<String> sendEmail(
            @RequestParam String to) {

        emailService.sendEmail(
            to,
            "Welcome",
            "Your email integration is working!"
        );

        return ResponseEntity.ok("Email sent successfully");
    }

    @PostMapping("/send-otp")
    public ResponseEntity<String> sendOtp(
            @RequestParam String email) {

        otpService.sendOtp(email);

        return ResponseEntity.ok("OTP email requested");
    }
}
```

Make sure both service classes and the controller are under the same root package as `DemoApplication.java`, so Spring Boot can discover them.

## 8. Interview questions

Q1. What is SMTP?

SMTP (Simple Mail Transfer Protocol) is the protocol used to send email from an application to a mail server.

Q2. What is `JavaMailSender`?

It is Spring's interface for sending emails. Spring Boot configures its implementation using the mail properties.

Q3. `SimpleMailMessage` vs `MimeMessage`?

- `SimpleMailMessage`: plain-text emails.
- `MimeMessage`: HTML content, attachments and richer email formats, usually with `MimeMessageHelper`.

Q4. How should OTP verification work in production?

1. Generate an unpredictable OTP.
2. Store a protected representation with an expiration timestamp.
3. Email the OTP.
4. Verify the submitted OTP and expiration.
5. Invalidate it after successful verification.
6. Apply rate limits and attempt limits.

Q5. What happens if the SMTP server fails?

`mailSender.send()` can throw a mail-related exception. Handle it with appropriate exception handling, logging that excludes secrets, and a suitable API error response. For reliable high-volume delivery, consider a queue and retry strategy.

Remember: The controller handles HTTP requests, the service contains email/OTP logic, `JavaMailSender` sends messages, and SMTP connects your application to the email provider.
