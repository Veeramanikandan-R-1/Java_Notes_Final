The easiest way to fix a CORS error in Spring Boot is using `@CrossOrigin` or global CORS configuration.

### **1. Using @CrossOrigin (Simple)**

Add this annotation to your controller:

```
@RestController
@RequestMapping("/api/products")
@CrossOrigin(origins = "http://localhost:5173")
public class ProductController {

    @GetMapping
    public String getProducts() {
        return "Product List";
    }
}
```

### **2. Global CORS Configuration (Recommended)**

Create `CorsConfig.java`:

```
@Configuration
public class CorsConfig {

    @Bean
    public WebMvcConfigurer corsConfigurer() {
        return new WebMvcConfigurer() {

            @Override
            public void addCorsMappings(CorsRegistry registry) {
                registry.addMapping("/**")
                    .allowedOrigins("http://localhost:5173")
                    .allowedMethods("*")
                    .allowedHeaders("*");
            }
        };
    }
}
```

### **Key points**

- `allowedOrigins()` – Specifies which frontend domains can access the backend.
- `allowedMethods()` – Allows GET, POST, PUT, DELETE, etc.
- `allowedHeaders()` – Allows request headers.
- If using Spring Security, enable CORS using `.cors(Customizer.withDefaults())` in `SecurityFilterChain`.

**Note:** Replace `5173` with your actual React/Vite frontend port.
