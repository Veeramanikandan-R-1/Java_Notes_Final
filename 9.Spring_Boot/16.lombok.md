### Lombok Library in Java (Spring Boot)

Lombok is a Java library that reduces boilerplate code by automatically generating common methods during compilation using annotations.

Without Lombok, we manually write:

- Getters and Setters
- Constructors
- `toString()`
- `equals()` and `hashCode()`

### 1. Add Lombok dependency

Add this to `pom.xml`:

```
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
</dependency>
```

### 2. Without Lombok

```
public class Student {

    private int id;
    private String name;

    public Student() {}

    public Student(int id, String name) {
        this.id = id;
        this.name = name;
    }

    public int getId() {
        return id;
    }

    public void setId(int id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}
```

### 3. With Lombok

```
import lombok.*;

@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
@ToString
public class Student {

    private int id;
    private String name;
}
```

Lombok generates the corresponding methods automatically.

### 4. Important Lombok annotations

| Annotation                 | Purpose                                                              |
| -------------------------- | -------------------------------------------------------------------- |
| `@Getter`                  | Generates getter methods                                             |
| `@Setter`                  | Generates setter methods                                             |
| `@ToString`                | Generates `toString()`                                               |
| `@NoArgsConstructor`       | Generates no-argument constructor                                    |
| `@AllArgsConstructor`      | Generates constructor with all fields                                |
| `@RequiredArgsConstructor` | Generates constructor for required fields                            |
| `@Data`                    | Combines getters, setters, `toString()`, `equals()` and `hashCode()` |
| `@Builder`                 | Provides builder pattern                                             |
| `@Slf4j`                   | Generates SLF4J logger                                               |

### 5. Example using @Data

```
@Data
public class Student {
    private int id;
    private String name;
}
```

Instead of writing multiple methods, one annotation generates them.

Important: In IntelliJ IDEA or VS Code, configure Lombok support/annotation processing if needed for IDE recognition.

### In short

Lombok reduces repetitive Java code, improves readability and makes development faster.

Interview point: Lombok uses compile-time annotation processing to generate boilerplate code. It does not eliminate the need for Java methods; it generates them automatically.

add below lines inside plugins element in pom.xml to avoid error of "The error indicates Lombok’s annotation processor isn’t running during compilation."

```
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <configuration>
        <annotationProcessorPaths>
            <path>
                <groupId>org.projectlombok</groupId>
                <artifactId>lombok</artifactId>
                <version>1.18.42</version>
            </path>
        </annotationProcessorPaths>
    </configuration>
</plugin>
```
