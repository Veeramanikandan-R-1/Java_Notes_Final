# Spring Boot – Actuator: Health Checks & Monitoring

## 1. What is Spring Boot Actuator?

Spring Boot Actuator provides production-ready endpoints to monitor your application's health, metrics, and operational status without building everything manually.

For a React developer, think of it as a backend monitoring API that your monitoring dashboard or infrastructure can call.

- Health check: Is the application running and healthy?
- Metrics: How much memory is being used? How many requests are processed?
- Monitoring: Help tools detect problems and alert your team.

## 2. Add the dependency

Add this inside `<dependencies>` in your `pom.xml`:

```
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
```

Your Spring Boot parent manages the dependency version, so you normally don't specify one separately.

## 3. Configure Actuator

Open `src/main/resources/application.properties` and add:

```
spring.application.name=demo

# Expose selected Actuator endpoints over HTTP
management.endpoints.web.exposure.include=health,info,metrics

# Show health details for local learning only
management.endpoint.health.show-details=always

# Application information
management.info.env.enabled=true
info.app.name=Demo Application
info.app.version=1.0.0
```

`show-details=always` is useful while learning, but avoid exposing detailed health information publicly in production.

## 4. Run and test the health check

Start your application and open these URLs.

Health status

`GET /actuator/health`

Example response:

```
{
  "status": "UP"
}
```

`UP` means the health contributors report the application as healthy.

Metrics

`GET /actuator/metrics`

Lists available metrics, such as JVM memory and HTTP request metrics.

Application information

`GET /actuator/info`

Returns configured application metadata.

Base URL: `http://localhost:8080`

You can also test from Git Bash:

```
curl http://localhost:8080/actuator/health
```

## 5. How does health checking work?

Monitoring tool / Kubernetes

Calls the health endpoint

Spring Boot Actuator

Checks application and configured health contributors

UP

Healthy

DOWN

Unhealthy

Important distinction:

- `/actuator/health` reports overall application health.
- `/actuator/health/liveness` indicates whether the application is alive and should continue running.
- `/actuator/health/readiness` indicates whether it is ready to receive traffic.

Liveness and readiness probes are especially useful when deploying Spring Boot applications to Kubernetes.

## 6. Interview points

| Question                          | Short answer                                                                                               |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Why Actuator?                     | Production monitoring and management endpoints.                                                            |
| What does `UP` mean?              | Configured health contributors report healthy status.                                                      |
| Does Actuator monitor a database? | It can when the relevant database integration and health contributor are configured.                       |
| Is Actuator secured by default?   | Only selected endpoints are exposed by default; secure any additional exposed endpoints appropriately.     |
| Does Actuator provide dashboards? | It provides endpoints and metrics; tools such as Prometheus and Grafana can collect and visualize metrics. |

Practice task: Add Actuator to your existing project and verify `/actuator/health` and `/actuator/metrics`.
