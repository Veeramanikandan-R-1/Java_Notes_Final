# Spring Boot + Spring JDBC + H2 Database (Simple CRUD)

Let's create a simple Product Management application using:

- Spring Boot – Application framework.
- Spring JDBC – To execute SQL queries.
- H2 – In-memory database.
- JdbcTemplate – To simplify JDBC operations.

We'll implement basic CRUD operations: Create, Read, Update and Delete.

## 2. Maven dependencies

Add these dependencies to `pom.xml`:

```
<dependencies>
    <!-- Spring Web -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>

    <!-- Spring JDBC -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-jdbc</artifactId>
    </dependency>

    <!-- H2 Database -->
    <dependency>
        <groupId>com.h2database</groupId>
        <artifactId>h2</artifactId>
        <scope>runtime</scope>
    </dependency>
</dependencies>
```

Use the Spring Boot parent/version generated by Spring Initializr; it manages compatible dependency versions.

```
spring.h2.console.path=/h2-console

# Show SQL queries
spring.sql.init.mode=always
```

We are using an in-memory database. Data will be lost when the application stops.

## 6. Create Repository using JdbcTemplate

ProductRepository.java

This is where we execute database operations.

```
package com.example.demo.repository;

import java.util.List;

import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Repository;

import com.example.demo.model.Product;

@Repository
public class ProductRepository {

    private final JdbcTemplate jdbcTemplate;

    public ProductRepository(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    // CREATE
    public int addProduct(Product product) {

        String sql = """
            INSERT INTO products (prod_id, name, price)
            VALUES (?, ?, ?)
        """;

        return jdbcTemplate.update(
            sql,
            product.getProdId(),
            product.getName(),
            product.getPrice()
        );
    }

    // READ ALL
    public List<Product> getProducts() {

        String sql = "SELECT * FROM products";

        return jdbcTemplate.query(sql, (rs, rowNum) ->
            new Product(
                rs.getInt("prod_id"),
                rs.getString("name"),
                rs.getDouble("price")
            )
        );
    }

    // READ BY ID
    public Product getProduct(int id) {

        String sql = "SELECT * FROM products WHERE prod_id = ?";

        return jdbcTemplate.queryForObject(sql, (rs, rowNum) ->
            new Product(
                rs.getInt("prod_id"),
                rs.getString("name"),
                rs.getDouble("price")
            ), id);
    }

    // UPDATE
    public int updateProduct(Product product) {

        String sql = """
            UPDATE products
            SET name = ?, price = ?
            WHERE prod_id = ?
        """;

        return jdbcTemplate.update(
            sql,
            product.getName(),
            product.getPrice(),
            product.getProdId()
        );
    }

    // DELETE
    public int deleteProduct(int id) {

        String sql = "DELETE FROM products WHERE prod_id = ?";

        return jdbcTemplate.update(sql, id);
    }
}
```

## 7. Create REST Controller

ProductController.java

```
package com.example.demo.controller;

import java.util.List;

import org.springframework.web.bind.annotation.*;

import com.example.demo.model.Product;
import com.example.demo.repository.ProductRepository;

@RestController
@RequestMapping("/products")
public class ProductController {

    private final ProductRepository repository;

    public ProductController(ProductRepository repository) {
        this.repository = repository;
    }

    @PostMapping
    public String addProduct(@RequestBody Product product) {
        repository.addProduct(product);
        return "Product added successfully";
    }

    @GetMapping
    public List<Product> getProducts() {
        return repository.getProducts();
    }

    @GetMapping("/{id}")
    public Product getProduct(@PathVariable int id) {
        return repository.getProduct(id);
    }

    @PutMapping
    public String updateProduct(@RequestBody Product product) {
        int rows = repository.updateProduct(product);
        return rows > 0 ? "Product updated" : "Product not found";
    }

    @DeleteMapping("/{id}")
    public String deleteProduct(@PathVariable int id) {
        int rows = repository.deleteProduct(id);
        return rows > 0 ? "Product deleted" : "Product not found";
    }
}
```

## 12. Important concepts to understand

| Concept            | Purpose                                  |
| ------------------ | ---------------------------------------- |
| JdbcTemplate       | Simplifies JDBC operations               |
| DataSource         | Provides database connections            |
| HikariCP           | Manages connection pooling               |
| RowMapper          | Converts database rows into Java objects |
| `query()`          | Retrieves multiple records               |
| `queryForObject()` | Retrieves a single record                |
| `update()`         | Executes INSERT, UPDATE and DELETE       |
| `schema.sql`       | Creates database tables                  |

Important: Spring Boot automatically configures `DataSource`, HikariCP and `JdbcTemplate` when the JDBC starter and H2 dependency are present.

For your next practice step, try adding a separate `ProductService` layer between the Controller and Repository. This will give you a more standard Spring Boot layered architecture.
