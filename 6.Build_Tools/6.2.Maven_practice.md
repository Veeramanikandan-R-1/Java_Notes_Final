## 1. Check Java and Maven

Open **CMD / PowerShell**:

```bash
java -version
mvn -version
```

You should see Java 21 (or another installed JDK) and Maven information.

If `mvn` is not recognized, Maven needs to be installed/configured.

Here’s the simplest way to install **Apache Maven on Windows**:

1. **Install Java/JDK first.** Maven requires a JDK. Open Command Prompt and check:

   ```cmd
   java -version
   ```

   If Java isn’t installed, install a current JDK first.

2. **Download Maven** from the official [Apache Maven download page](https://maven.apache.org/download.cgi?utm_source=chatgpt.com). Download the **Binary zip archive**, for example `apache-maven-x.x.x-bin.zip`.

3. **Extract the ZIP** somewhere permanent, for example:

   ```text
   C:\Program Files\Apache\maven
   ```

   Inside it you should see folders such as `bin`, `conf`, and `lib`.

4. **Set environment variables.** Search Windows for **“Edit the system environment variables”** → **Environment Variables**. Under **System variables**, create:

   ```text
   Variable name: MAVEN_HOME
   Variable value: C:\Program Files\Apache\maven
   ```

   Then edit the `Path` variable and add:

   ```text
   %MAVEN_HOME%\bin
   ```

   Also make sure `JAVA_HOME` points to your JDK installation, such as:

   ```text
   JAVA_HOME=C:\Program Files\Java\jdk-21
   ```

5. **Verify Maven.** Close any existing Command Prompt/PowerShell windows, open a new one, and run:

   ```cmd
   mvn -version
   ```

   You should see output containing the Maven version, Java version, and Maven home directory.

If you get **`'mvn' is not recognized as an internal or external command`**, the Maven `bin` directory hasn't been added to `Path` correctly.

# 3. Understand `pom.xml`

Initially, keep it simple:

```xml
<?xml version="1.0" encoding="UTF-8"?>

<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
         https://maven.apache.org/xsd/maven-4.0.0.xsd">

    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example</groupId>
    <artifactId>maven-basic-demo</artifactId>
    <version>1.0-SNAPSHOT</version>

    <properties>
        <maven.compiler.source>21</maven.compiler.source>
        <maven.compiler.target>21</maven.compiler.target>
    </properties>

</project>
```

Don't worry about every XML line yet.

Focus on:

```xml
<groupId>com.example</groupId>
<artifactId>maven-basic-demo</artifactId>
<version>1.0-SNAPSHOT</version>
```

# 4. Create a simple Java application

Create:

```text
src/main/java/com/example/App.java
```

```java
package com.example;

public class App {

    public static void main(String[] args) {

        int a = 10;
        int b = 20;

        int result = add(a, b);

        System.out.println("Result = " + result);
    }

    public static int add(int a, int b) {
        return a + b;
    }
}
```

Run it from IntelliJ first.

Expected:

```text
Result = 30
```

# 6. Add a dependency — this is the important practice

Now let's actually experience why Maven is useful.

Add **JUnit** to your `pom.xml`:

```xml
<dependencies>

    <dependency>
        <groupId>org.junit.jupiter</groupId>
        <artifactId>junit-jupiter</artifactId>
        <version>5.12.2</version>
        <scope>test</scope>
    </dependency>

</dependencies>
```

Now Maven automatically downloads JUnit.

This is the Maven equivalent of:

```bash
npm install <package>
```

# 7. Create a test

Create:

```text
src/test/java/com/example/AppTest.java
```

```java
package com.example;

import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertEquals;

class AppTest {

    @Test
    void shouldAddTwoNumbers() {

        int result = App.add(10, 20);

        assertEquals(30, result);
    }
}
```

Now run:

```bash
mvn test
```

You should see that the test passes.

This is the basic Maven workflow you'll repeatedly use in Spring Boot.
