
## using VS code

Yes. You can create and practice a **Maven Java project directly in VS Code**. Since you're learning Spring Boot, this is a good setup.

## 1. Install VS Code extensions

In VS Code → **Extensions**, install:

* **Extension Pack for Java** — Microsoft
* **Maven for Java** — Microsoft

The Java extension pack gives you Java language support, debugging, testing, etc.

---

## 2. Make sure Java works

Open **VS Code Terminal**:

**Terminal → New Terminal**

Run:

```bash
java -version
```

and:

```bash
javac -version
```

Both should work.

Then:

```bash
mvn -version
```

⚠️ Since you previously got **`mvn is not recognized`**, Maven still needs to be installed/configured before this will work.

---

# 3. Create Maven project in VS Code

Once Maven is working:

Press:

```text
Ctrl + Shift + P
```

Search:

```text
Maven: Create Maven Project
```

Select it.

Then VS Code will ask for:

### Archetype

Choose:

```text
maven-archetype-quickstart
```

Then choose the latest version offered.

Enter:

```text
groupId:
com.example
```

Then:

```text
artifactId:
maven-basic-demo
```

Choose a folder where you want to create the project.

---

# 4. Your project will look like

```text
maven-basic-demo/
│
├── pom.xml
│
└── src/
    ├── main/
    │   └── java/
    │       └── com/example/App.java
    │
    └── test/
        └── java/
            └── com/example/AppTest.java
```

This is the **standard Maven structure**.

---

# 5. Open `pom.xml`

You'll see something similar to:

```xml
<project>
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example</groupId>
    <artifactId>maven-basic-demo</artifactId>
    <version>1.0-SNAPSHOT</version>

    <properties>
        <maven.compiler.source>21</maven.compiler.source>
        <maven.compiler.target>21</maven.compiler.target>
    </properties>

    <dependencies>
        ...
    </dependencies>
</project>
```

For now, focus on:

```text
groupId
artifactId
version
dependencies
```

---

# 6. Create your Java code

Open:

```text
src/main/java/com/example/App.java
```

Replace it with:

```java
package com.example;

public class App {

    public static void main(String[] args) {

        System.out.println("Hello Maven!");

    }
}
```

You can run it using VS Code's **Run** button.

---

# 7. Now practice Maven from VS Code terminal

This is the important part.

From the directory containing `pom.xml`:

```bash
mvn compile
```

Then:

```bash
mvn test
```

Then:

```bash
mvn package
```

Finally:

```bash
mvn clean
```

You can also run:

```bash
mvn clean package
```

---

## 8. What you should understand

Your workflow is:

```text
VS Code
   ↓
pom.xml
   ↓
Maven
   ↓
Dependencies
   ↓
Compile
   ↓
Test
   ↓
Package
   ↓
target/
```

For your **Spring Boot goal**, this is enough Maven knowledge to start with.

running maven project

If you mean **how to run a Java file in VS Code**, there are two ways.

### 1. Run directly — easiest

Suppose you have:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

In VS Code:

1. Open `Main.java`
2. Make sure it has `main()`
3. Click **Run** ▶️ above `main()`

Or right-click the file → **Run Java**.

---

### 2. Run from terminal

Navigate to the folder containing the file:

```bash
cd path/to/your/folder
```

Compile:

```bash
javac Main.java
```

Run:

```bash
java Main
```

Notice:

```bash
javac Main.java   # compile
java Main         # run
```

You **don't** write:

```bash
java Main.java
```

when using the traditional compile/run approach.

---

### For your Maven project

If your project is:

```text
maven-basic-demo
├── pom.xml
└── src
    └── main
        └── java
            └── com/example/App.java
```

You can simply click **Run Java** in VS Code.

Or use Maven to build:

```bash
mvn compile
```

Maven compiles the project, but **Maven isn't normally how you run an arbitrary Java class**. In Spring Boot, you'll usually run the application class using VS Code/IDE or:

```bash
mvn spring-boot:run
```

### Simple rule to remember

```text
Normal Java:
javac → compile
java  → run

Maven:
mvn compile → compile project
mvn test    → run tests
mvn package → build JAR
```

For your current Maven practice, **use the VS Code ▶ Run button for `App.java`, and use the terminal for `mvn compile/test/package`**.
