## Advanced Java — Multithreading: Thread Examples

Since you already know Java basics, focus on **how threads are created, started, executed, and coordinated**. This is important for Spring Boot because web applications handle many requests concurrently.

### 1. What is a Thread?

A **thread** is a lightweight unit of execution inside a process.

Think:

```text
Java Application (Process)
│
├── Thread 1 → Task A
├── Thread 2 → Task B
└── Thread 3 → Task C
```

Multiple threads can execute tasks concurrently.

---

# 2. Creating a Thread — Extending `Thread`

The simplest example:

```java
class MyThread extends Thread {

    @Override
    public void run() {
        System.out.println("Thread is running");
    }
}

public class Main {

    public static void main(String[] args) {

        MyThread thread = new MyThread();

        thread.start();
    }
}
```

Output:

```text
Thread is running
```

### Important

You write the task inside:

```java
run()
```

But you should normally call:

```java
thread.start();
```

**NOT:**

```java
thread.run();
```

Why?

```text
start()
  ↓
Creates a new thread
  ↓
JVM executes run()
```

Whereas:

```text
run()
  ↓
Normal method call
  ↓
Runs on main thread
```

# 3. Multiple Threads

```java
class MyThread extends Thread {

    private String name;

    MyThread(String name) {
        this.name = name;
    }

    @Override
    public void run() {

        for (int i = 1; i <= 3; i++) {
            System.out.println(name + " - " + i);
        }
    }
}

public class Main {

    public static void main(String[] args) {

        MyThread t1 = new MyThread("Thread A");
        MyThread t2 = new MyThread("Thread B");

        t1.start();
        t2.start();
    }
}
```

Possible output:

```text
Thread A - 1
Thread B - 1
Thread A - 2
Thread B - 2
Thread B - 3
Thread A - 3
```

The order is **not guaranteed**.

You might get:

```text
Thread B - 1
Thread B - 2
Thread A - 1
Thread A - 2
Thread B - 3
Thread A - 3
```

This is because the JVM/OS scheduler decides when each thread gets CPU time.

# 4. Creating Thread using `Runnable`

This is generally preferred over extending `Thread`.

```java
class MyTask implements Runnable {

    @Override
    public void run() {
        System.out.println("Task is running");
    }
}

public class Main {

    public static void main(String[] args) {

        Runnable task = new MyTask();

        Thread thread = new Thread(task);

        thread.start();
    }
}
```

Here:

```text
Runnable
   ↓
Defines the task

Thread
   ↓
Executes the task
```

This is a good separation of **task vs execution mechanism**.

---

# 5. Runnable with Lambda

Because `Runnable` is a functional interface, you can write:

```java
public class Main {

    public static void main(String[] args) {

        Runnable task = () -> {
            System.out.println("Task is running");
        };

        Thread thread = new Thread(task);

        thread.start();
    }
}
```

Or even shorter:

```java
public class Main {

    public static void main(String[] args) {

        new Thread(() -> {
            System.out.println("Hello from thread");
        }).start();
    }
}
```

You'll commonly see this style in Java code.

# 6. `Thread.sleep()`

Used when you want a thread to pause temporarily.

```java
public class Main {

    public static void main(String[] args) {

        Thread thread = new Thread(() -> {

            for (int i = 1; i <= 5; i++) {

                System.out.println(i);

                try {
                    Thread.sleep(1000);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        });

        thread.start();
    }
}
```

Output appears approximately one second apart:

```text
1
2
3
4
5
```

### Important

`Thread.sleep()`:

* pauses the **current thread**
* does not stop the entire application
* throws `InterruptedException`
* does **not release intrinsic locks** held by the thread

---

# 7. `Thread.currentThread()`

Gets the currently executing thread.

```java
public class Main {

    public static void main(String[] args) {

        Thread thread = new Thread(() -> {

            System.out.println(
                "Running in: " +
                Thread.currentThread().getName()
            );
        });

        thread.setName("Worker-1");

        thread.start();
    }
}
```

Output:

```text
Running in: Worker-1
```

You can also get the main thread:

```java
System.out.println(Thread.currentThread().getName());
```

Usually:

```text
main
```

# 8. `join()` — Wait for Another Thread

This is **very important for interviews**.

Suppose:

```text
Main Thread
   │
   ├── starts Worker
   │
   ├── continues...
   │
   └── needs Worker result
```

Use `join()`.

```java
public class Main {

    public static void main(String[] args)
            throws InterruptedException {

        Thread worker = new Thread(() -> {

            System.out.println("Worker started");

            try {
                Thread.sleep(2000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }

            System.out.println("Worker finished");
        });

        worker.start();

        worker.join();

        System.out.println("Main finished");
    }
}
```

Output:

```text
Worker started
Worker finished
Main finished
```

### Meaning

```java
worker.join();
```

means:

> "Main thread, wait until `worker` finishes."

# 9. Thread Name

You can assign meaningful names:

```java
Thread thread = new Thread(
    () -> System.out.println("Working")
);

thread.setName("Payment-Thread");

thread.start();
```

Or:

```java
Thread thread = new Thread(
    () -> System.out.println("Working"),
    "Payment-Thread"
);
```

Naming threads is very useful when debugging production applications.

# 10. Thread Priority

Java supports priorities from:

```text
1 → MIN_PRIORITY
5 → NORM_PRIORITY
10 → MAX_PRIORITY
```

Example:

```java
Thread thread = new Thread(() -> {
    System.out.println("Running");
});

thread.setPriority(Thread.MAX_PRIORITY);

thread.start();
```

**Interview point:** Priority is only a scheduling hint. Do **not** rely on it for correctness.

# 11. `isAlive()`

Checks whether a thread has started and has not yet terminated.

```java
public class Main {

    public static void main(String[] args)
            throws InterruptedException {

        Thread thread = new Thread(() -> {
            try {
                Thread.sleep(1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });

        System.out.println(thread.isAlive());

        thread.start();

        System.out.println(thread.isAlive());

        thread.join();

        System.out.println(thread.isAlive());
    }
}
```

Typical output:

```text
false
true
false
```

# 12. Thread Lifecycle

Know this for interviews:

```text
NEW
 │
 │ start()
 ↓
RUNNABLE
 │
 ├── running
 ├── waiting for CPU
 │
 ├── BLOCKED
 ├── WAITING
 └── TIMED_WAITING
 │
 ↓
TERMINATED
```

Example:

```java
Thread thread = new Thread(...);
```

Initially:

```text
NEW
```

After:

```java
thread.start();
```

it becomes eligible to run.

After `run()` finishes:

```text
TERMINATED
```

### Java's actual `Thread.State`

```text
NEW
RUNNABLE
BLOCKED
WAITING
TIMED_WAITING
TERMINATED
```

# 13. Important: `start()` vs `run()`

This is one of the most common interview questions.

### `start()`

```java
thread.start();
```

Creates/schedules a new thread and eventually invokes `run()` on that thread.

### `run()`

```java
thread.run();
```

Just a normal method call.

Example:

```java
public class Main {

    public static void main(String[] args) {

        Thread thread = new Thread(() -> {
            System.out.println(
                Thread.currentThread().getName()
            );
        });

        thread.run();
    }
}
```

Output:

```text
main
```

Because `run()` did **not** create a new thread.

With:

```java
thread.start();
```

you'll see the thread's own name (typically `Thread-0` if unnamed).

---

# 14. One Important Rule

A thread can be started **only once**.

```java
Thread thread = new Thread(() -> {
    System.out.println("Hello");
});

thread.start();
thread.start(); // ❌ IllegalThreadStateException
```

Once a thread terminates, you cannot restart the same `Thread` object.

Create a new `Thread` instead.

# Quick Revision

| Concept                | Purpose                    |
| ---------------------- | -------------------------- |
| `Thread`               | Represents a thread        |
| `Runnable`             | Represents a task          |
| `start()`              | Starts a new thread        |
| `run()`                | Contains task logic        |
| `sleep()`              | Pause current thread       |
| `join()`               | Wait for another thread    |
| `currentThread()`      | Get current thread         |
| `isAlive()`            | Check thread status        |
| `setName()`            | Give thread a name         |
| `setPriority()`        | Set scheduling priority    |
| `InterruptedException` | Thread interruption signal |

### Interview mental model

```text
Runnable = WHAT should be done?

Thread = WHO executes it?

start() = Start execution on another thread

run() = Actual task code

sleep() = Pause current thread

join() = Wait for another thread
```
