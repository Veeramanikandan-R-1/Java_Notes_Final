In JUnit 5, assertions are used to verify whether the actual result matches the expected result in a unit test.

Import assertions using:

```
import static org.junit.jupiter.api.Assertions.*;
```

## Important JUnit 5 assertion methods

| Assertion             | Purpose                               | Example                                                         |
| --------------------- | ------------------------------------- | --------------------------------------------------------------- |
| `assertEquals()`      | Checks equality                       | `assertEquals(3, result);`                                      |
| `assertNotEquals()`   | Checks inequality                     | `assertNotEquals(5, result);`                                   |
| `assertTrue()`        | Checks condition is true              | `assertTrue(age >= 18);`                                        |
| `assertFalse()`       | Checks condition is false             | `assertFalse(age < 18);`                                        |
| `assertNull()`        | Checks value is null                  | `assertNull(user);`                                             |
| `assertNotNull()`     | Checks value is not null              | `assertNotNull(user);`                                          |
| `assertSame()`        | Checks same object reference          | `assertSame(obj1, obj2);`                                       |
| `assertNotSame()`     | Checks different object references    | `assertNotSame(obj1, obj2);`                                    |
| `assertArrayEquals()` | Compares array contents               | `assertArrayEquals(arr1, arr2);`                                |
| `assertThrows()`      | Checks expected exception             | `assertThrows(ArithmeticException.class, () -> divide(10, 0));` |
| `assertAll()`         | Executes multiple assertions together | Groups multiple checks                                          |
| `assertTimeout()`     | Checks execution time limit           | Verifies execution finishes within a duration                   |

## Working example

Assume your `App.java` has an `add()` method.

```

package com.example;

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

class AppTest {

    @Test
    void testAssertions() {
        App app = new App();

        int result = app.add(1, 2);

        assertEquals(3, result);
        assertNotEquals(5, result);
        assertTrue(result > 0);
        assertFalse(result < 0);
        assertNotNull(app);
    }
}

```

Run it with:

```
mvn test -Dtest=AppTest
```

## Important concepts

1\. `assertEquals(expected, actual)`

```
assertEquals(3, app.add(1, 2));
```

The test passes if the result is `3`.

2\. `assertThrows()`

Use it to verify exception handling.

```
assertThrows(ArithmeticException.class, () -> {
    int result = 10 / 0;
});
```

The test passes if the expected exception is thrown.

3\. `assertAll()`

Use it to check multiple conditions. Unlike separate assertions, it reports all failures within the group.

```
assertAll(
    () -> assertEquals(3, app.add(1, 2)),
    () -> assertTrue(app.add(2, 3) > 0),
    () -> assertNotNull(app)
);
```

4\. `assertSame()` vs `assertEquals()`

- `assertEquals()` checks whether values are equal.
- `assertSame()` checks whether two references point to the exact same object.

For interview preparation, prioritize `assertEquals()`, `assertTrue()`, `assertFalse()`, `assertNull()`, `assertNotNull()`, `assertThrows()`, and `assertAll()`.
