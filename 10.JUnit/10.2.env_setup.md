In VS Code terminal, run this command to create a Maven project for practicing JUnit 5 unit testing.

### 1. Create Maven project

```
mvn archetype:generate -DgroupId=com.example -DartifactId=junit-practice -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false
```

### 2. Open the project in VS Code

```
cd junit-practice
code .
```

### 3. Add JUnit 5 dependency

In `pom.xml`, add the following inside the `<dependencies>` section. Remove the default JUnit dependency if it already exists.

```
<dependency>
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter</artifactId>
    <version>5.12.2</version>
    <scope>test</scope>
</dependency>
```

Also add this plugin inside the `<build><plugins>` section to run JUnit 5 tests:
Add the <build> section after </dependencies> inside <plugins> and before </project> in your pom.xml.

```
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-surefire-plugin</artifactId>
    <version>3.5.2</version>
</plugin>
```

### 4. Create a test class

Project structure:

```
junit-practice/
 └── src/
     ├── main/java/com/example/
     │   └── App.java
     └── test/java/com/example/
         └── AppTest.java
```

Example `AppTest.java`:

```
package com.example;

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.assertEquals;

class AppTest {

    @Test
    void testAddition() {
        int result = 10 + 20;
        assertEquals(30, result);
    }
}
```

### 5. Run the tests

From the project root:

```
mvn test
```

VS Code tip: Install the Extension Pack for Java to get Java test discovery and debugging support.

---

To run a single JUnit test file using Maven, use `-Dtest` with the test class name.

### 1. Run one test class

```
mvn test -Dtest=AppTest
```

### 2. Run a specific test method

```
mvn test -Dtest=AppTest#testAddition
```

### 3. Run multiple test classes

```
mvn test -Dtest=AppTest,UserServiceTest
```

Note: Run these commands from the directory containing your `pom.xml`. Use the test class name without `.java`.

For your project, the simplest command is:

```
mvn test -Dtest=AppTest
```
