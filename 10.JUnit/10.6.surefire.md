## Maven Surefire Plugin in JUnit

Maven Surefire Plugin runs unit tests during Maven's `test` phase. It detects test classes, executes them, and generates test reports.

### 1. How it works

When you run:

```
mvn test
```

Maven executes the lifecycle up to the `test` phase, where Surefire runs your unit tests.

### 2. Configure Surefire in `pom.xml`

Add this inside `<project>`, after `<dependencies>`:

```
<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-surefire-plugin</artifactId>
            <version>3.5.2</version>
        </plugin>
    </plugins>
</build>
```

For JUnit 5, use a compatible Surefire version and include the JUnit Jupiter test dependency.

### 3. Important commands

| Command                              | Purpose                             |
| ------------------------------------ | ----------------------------------- |
| `mvn test`                           | Run all discovered tests            |
| `mvn clean test`                     | Clean and run all tests             |
| `mvn test -Dtest=AppTest`            | Run one test class                  |
| `mvn test -Dtest=AppTest#testAdd`    | Run one test method                 |
| `mvn -DskipTests package`            | Package without executing tests     |
| `mvn -Dmaven.test.skip=true package` | Skip test compilation and execution |

### 4. Where are the reports?

After running tests, check:

```
target/
 └── surefire-reports/
     ├── com.example.AppTest.txt
     └── TEST-com.example.AppTest.xml
```

These reports contain test results, including passed tests, failures, and errors.

Interview point: Surefire is for running tests during Maven's test phase. The Maven Failsafe Plugin is commonly used for integration tests, often during the `integration-test` and `verify` phases.
